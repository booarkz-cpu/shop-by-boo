# Установка и эксплуатация — v21.5.1

Актуальная пошаговая инструкция: [Установка и эксплуатация](docs/ru/DEPLOYMENT_CURRENT.md). Общий каталог: [DOCUMENTATION.md](DOCUMENTATION.md).

Стабильный канал текущего ядра не подтверждает полный перенос функций или production E2E. Реальные платежи открыты с момента установки; администратор может остановить их аварийной кнопкой. Используйте текущие три агента: YooKassa, Platega, RollyPay; прежние агенты не принимают новые покупки.

Предыдущая редакция сохранена как [исторический документ](docs/archive/instructions_before_21_0_1/README_PRODUCTION_RU.md); её команды и обещания не являются текущей инструкцией.
