# Установка и эксплуатация VPN Shop by Corgi Lucy

Для установки выберите тег опубликованного дистрибутива. В выпуске [v28.161.0](https://github.com/booarkz-cpu/shop-by-boo/releases/tag/v28.161.0) версия runtime/API — `21.5.1`. Состав пакета и ограничения выпуска приведены в [заметках](docs/ru/RELEASE_V28_161_0.md).

- **Установка.** [Подготовьте VPS](docs/wiki/ru/Installation.md), [настройте домены](docs/wiki/ru/Domains.md) и войдите в админку.
- **Первые продажи.** [Подключите Remnawave](docs/wiki/ru/Remnawave.md) для выдачи доступа и [настройте платёжного провайдера](docs/wiki/ru/Payments.md).
- **Мобильные приложения.** [Скачайте магазин, VPN-клиент или Lucy Admin](README.md#скачать-мобильные-приложения).
- **Обслуживание.** [Обновите магазин](docs/wiki/ru/Updates.md) или [восстановите базы, секреты и файлы](docs/ru/BACKUP_CURRENT.md).
- **Проверки.** [Сверьтесь с критериями готовности](docs/ru/MATRIX_COMPLETION_21_5_1.md) или [найдите причину сбоя](docs/wiki/ru/Troubleshooting.md).
