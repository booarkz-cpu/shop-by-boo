# Модель угроз

Дата: 2026-11-12, выпуск v28.123.0. Метод: STRIDE по границам доверия.
Документ опирается на проверенный код и тесты; где проверки нет, так и написано. Подробности мер — в
[SECURITY_MODEL_RU.md](../SECURITY_MODEL_RU.md), итоги аудитов — в [SECURITY_AUDIT.md](ru/new/SECURITY_AUDIT.md),
находки и их повторная проверка — в [SECURITY_FINDINGS.md](SECURITY_FINDINGS.md).

## Что защищаем

| Актив | Где находится |
| --- | --- |
| Учётные записи и сессии клиентов и администраторов | База магазина |
| Подписки и ключи доступа к VPN | Панель Remnawave; ссылки подписки в базе магазина |
| Платежи, балансы, возвраты | База магазина; кассы |
| Секреты: ключи касс, токен бота, ключи SSH нод, токен панели | `.env` (права 600) и база магазина в зашифрованном виде |
| Серверы: магазин, панель, ноды | VPS владельца |
| Выпуски и обновления | GitHub Releases; агент обновления на сервере |

## Границы доверия

| № | Граница | Кто по ту сторону |
| --- | --- | --- |
| Г1 | Интернет → Caddy → API магазина | Любой посетитель |
| Г2 | Клиент (кабинет, Mini App, бот, приложение) → API | Вошедший клиент |
| Г3 | Администратор → панель администратора → API | Администратор с ролью |
| Г4 | Касса → webhook магазина | Платёжный провайдер или тот, кто им притворяется |
| Г5 | Магазин → панель Remnawave | Панель на отдельном сервере |
| Г6 | Магазин → нода по SSH | Сервер ноды |
| Г7 | GitHub → агент обновления; GitHub → приложения | Источник выпусков |
| Г8 | Телефон клиента: приложение, другие приложения, сеть | Устройство вне контроля магазина |

## Что не закрыто

| Что | Почему |
| --- | --- |
| Сквозной тест «чужой идентификатор» на всех клиентских маршрутах | Проверено аудитом кода, автоматического теста на все маршруты нет |
| Динамическое сканирование боевого стенда | Есть базовый OWASP ZAP на стенде CI; боевого стенда нет |
| Проверка на настоящих VPS, с настоящими кассами, на настоящих телефонах | Нужны серверы, тестовые ключи, устройства |
| Защита на устройстве с root | Не обещаем |
| Подпись архива выпуска ключом владельца | Есть SHA-256 и аттестация GitHub |
