# Развитие трёх продуктов

VPN Shop, Corgi Lucy Client и Lucy Admin имеют равную продуктовую значимость. Очерёдность конкретных изменений определяется риском потери данных, неисправностью сборки, пользовательским эффектом и зависимостями между работами. [Исходные требования](prompts/MASTER_PROMPT_V6.md)

| Продукт | Работа, которую можно проверить отдельно | Проверка результата |
| --- | --- | --- |
| VPN Shop | Каталог и заказ в кабинете, платёжное событие в backend, выдача конфигурации в приложении | Браузерные сценарии и интеграционные тесты на отдельной PostgreSQL |
| Corgi Lucy Client | Импорт конфигурации и работа встроенного VPN-движка в Android | Сборка со штатным AAR, контроль ELF и прохождение трафика в эмуляторе |
| Lucy Admin | Доступ администратора, состояние услуг и операции поддержки на Web, Android и iOS | Проверки прав в API, браузерные и инструментальные сценарии на каждой платформе |

Обновление общего образа, API или AAR затрагивает несколько продуктов. Для него перечисляют потребителей, проверяют совместимость и сохраняют журнал по каждой затронутой платформе. Один успешный сценарий Android подтверждает только испытанное приложение и ABI. Для исходного кода, тестов и ближайших решений см. [рабочую матрицу](PROJECT_WORKLOAD_MATRIX.md), для состояния требований по разделам — [матрицу завершения](PROJECT_COMPLETION_MATRIX.md).
