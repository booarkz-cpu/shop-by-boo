# Возможности Lucy Admin на Web, Android и iOS

Для учёта продукта используется идентификатор `lucy-admin`. Идентификаторы приложений и суффикс preview относятся к конкретной сборке. Таблица отражает вызовы API, обнаруженные в исходном коде интерфейсов. Для приёмки операции отдельно проверяют полномочия пользователя и сохранение результата после повторного входа.

| Возможность и API | Web | Android | iOS |
| --- | --- | --- | --- |
| Обзор, `/api/admin/overview` | Запрашивает | Запрашивает | Запрашивает |
| Платежи, `/api/admin/payments` | Запрашивает | Запрашивает | Запрашивает |
| Состояние Remnawave, `/api/admin/remnawave/monitoring` | Запрашивает | Запрашивает | Запрашивает |
| Обращения в поддержку, `/api/admin/support/tickets` | Запрашивает | Запрашивает | Запрашивает |
| Готовность установки, `/api/admin/ops/readiness` | Запрашивает | Запрашивает | Запрашивает |
| Оперативная сводка, `/api/admin/mobile/ops` | Эквивалентный сценарий требует отдельной сверки | Запрашивает | Запрашивает |
| Создание и завершение инцидента через `/api/admin/v41/incidents` | Есть вызовы создания и завершения | Требуется проверка действий из мобильной сводки | Требуется проверка действий из мобильной сводки |

Вызовы находятся в точках входа трёх приложений [Web](../apps/lucy-admin/web/src/main.tsx), [Android](../apps/lucy-admin/android/app/src/main/java/shop/remnawave/admin/MainActivity.kt) и [iOS](../apps/lucy-admin/ios/VpnShopAdmin/ContentView.swift). Подтверждение каждого действия требует проверки на соответствующей платформе.

## Жизненный цикл инцидента

Модель `SecurityIncidentEvent` хранит важность, категорию, заголовок, подробности, статус, время создания и время разрешения. API требует право `ops.incidents`, пишет события создания и разрешения в аудит и может уведомлять подписчиков о сервисном инциденте. Для приёмки полного цикла остаются назначение ответственного, хронология изменений, влияние на пользователей, меры устранения и разбор после закрытия. Проверить их сохранение и доступ после перезапуска следует отдельно от работы переключателя аварийного режима.
