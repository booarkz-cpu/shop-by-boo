# Находки безопасности

Каждая находка записывается по одной схеме: серьёзность, насколько легко воспользоваться, последствия,
затронутые версии, исправление, доказательство повторной проверки. Находки прошлых аудитов —
в [SECURITY_AUDIT.md](ru/new/SECURITY_AUDIT.md); этот файл ведётся с v28.123.0.

Серьёзность: критическая, высокая, средняя, низкая — по оценке сканера или аудита.
