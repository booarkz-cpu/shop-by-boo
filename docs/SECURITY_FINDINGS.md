# Находки безопасности

Каждая находка записывается по одной схеме: серьёзность, насколько легко воспользоваться, последствия,
затронутые версии, исправление, доказательство повторной проверки. Находки прошлых аудитов —
в [SECURITY_AUDIT.md](ru/new/SECURITY_AUDIT.md); этот файл ведётся с v28.123.0.

Серьёзность: критическая, высокая, средняя, низкая — по оценке сканера или аудита.

Предложение npm выполнить audit fix --force с downgrade Vitest до 3.1.4 не применялось: это несовместимое изменение и не доказательство устранения finding. Нельзя устанавливать неподтверждённую версию, маскировать версию зависимости или удалять тесты ради зелёного CI. Допустимый следующий шаг — выпущенное исправление с проверкой advisory либо проверенная поддерживаемая замена тестовой цепочки с сохранением всех сценариев, assertions и изоляции; текущее состояние остаётся заблокированным.


### Проверка замены тестовой цепочки 18 ноября 2026 года

Кандидат переносит тесты кабинета на встроенный модуль `node:test`. Для проверки DOM используется прежняя версия jsdom, для утверждений — Chai, для подмен — самостоятельный пакет `@vitest/spy`. TypeScript компилирует исходные тесты во временный каталог. Node запускает каждый файл тестов в отдельном процессе. Сохранены 22 файла и 74 именованных сценария. В новом lockfile отсутствуют отдельные пакеты picomatch, Vitest, Vite, tinyglobby и fdir. Аудит зависимостей выполняется с прежними настройками.

На коммите [51a9fb02](https://github.com/booarkz-cpu/shop-by-boo/commit/51a9fb028207f09fc190c2d11be5dd40cdad4f78) [аудит зависимостей](https://github.com/booarkz-cpu/shop-by-boo/actions/runs/44283674966/job/134730658156) прошёл. Для всех трёх npm-проектов получен результат «0 известных уязвимостей». В [задании кабинета](https://github.com/booarkz-cpu/shop-by-boo/actions/runs/44283674966/job/134730657923) прошли npm ci, проверка типов, 74 теста из 22 файлов и сборка. Причина F-006 в проверенном графе зависимостей устранена. Готовность всего проекта к выпуску и проверки последующих коммитов учитываются отдельно.
