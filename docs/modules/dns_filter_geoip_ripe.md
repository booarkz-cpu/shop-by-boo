# Фильтр рекламы и детский режим, регионы клиентов, RIPE Atlas (v28.54)

## Фильтр рекламы и детский режим

Код: `backend/app/dns_filter.py`, колонка `subscriptions.dns_filter` (миграция `0088_filter_and_regions`). Админка: «Ноды → Фильтр рекламы и детский режим», в мобильных админках — карточка с тем же названием.

Клиенту фильтр доступен:
- в кабинете — раздел «Подписка»;
- в боте — `/filter`;
- в приложениях — «Моя статистика», карточка «Фильтр».

Владелец семьи выбирает режим для каждого участника в разделе «Семья». Участник сам фильтр семейной подписки не меняет.

### Как это работает

Фильтрация идёт на нодах. Магазин переводит пользователя панели в отдельный Internal Squad, профиль конфигурации которого блокирует нужные домены. При выключении фильтра возвращается сквад тарифа. Раз в 15 минут магазин сверяет сквады: продление или смена тарифа могли вернуть сквад тарифа, и тогда магазин снова ставит сквад фильтра.

### Настройка в Remnawave (один раз)

1. **Скопируйте профиль.** Откройте «Профили конфигурации» и скопируйте профиль, которым пользуются ваши тарифы.
2. **Добавьте блокировку.** В копию добавьте outbound `blackhole` с тегом `block`, если его нет, и правило маршрутизации в начало `routing.rules`.
   - Для «Без рекламы»:
     ```json
     {"type": "field", "domain": ["geosite:category-ads-all"], "outboundTag": "block"}
     ```
   - Для «Детского режима» — реклама и сайты для взрослых:
     ```json
     {"type": "field", "domain": ["geosite:category-ads-all", "geosite:category-porn"], "outboundTag": "block"}
     ```
   - На нодах должен быть файл `geosite.dat` с этими категориями. В образах Remnawave Node он есть.
3. **Создайте сквады.** Создайте Internal Squad для каждого профиля с теми же инбаундами, что у сквада тарифа.
4. **Укажите сквады в магазине.** В админке задайте строку: «Сквад тарифа» → «Без рекламы» / «Детский режим». Строка `*` действует для всех тарифов. Если у тарифов разные сквады (например, премиум-локации), добавьте строку на каждый.

Пока сквады не указаны, фильтр клиентам не показывается.

API клиента:
- `GET`/`PUT /api/me/filter` (`mode`: `""`, `ads`, `kids`);
- `PUT /api/me/family/members/{id}/filter` — владелец семьи для участника.

API админки: `GET`/`PUT /api/admin/dns-filter`.

## Регионы клиентов (GeoLite2)

Код: `backend/app/geoip.py`, колонка `vpn_sessions.region`, зависимость `maxminddb`. Админка: «Аналитика → Регионы клиентов», в мобильных админках — карточка с тем же названием.

- Страну адреса магазин определяет по данным регистратора, как и раньше. Для регионов внутри страны нужна база GeoLite2-City от MaxMind.
- Подключение:
  1. зарегистрируйтесь на maxmind.com — это бесплатно;
  2. в «Manage License Keys» создайте ключ;
  3. укажите в админке ID аккаунта и ключ;
  4. нажмите «Обновить базу».
- Ключ хранится в зашифрованном виде.
- База (около 70 МБ) хранится в `GEOIP_DIR` (по умолчанию `/data/geoip`) и обновляется раз в неделю.
- Новые сессии получают регион, «География клиентов» и карточка показывают регионы стран за 7 дней.
- Без ключа всё работает как раньше, только без регионов.
- Лицензия данных — CC BY-SA 4.0, ссылка на MaxMind показана в админке.

API: `GET`/`PUT /api/admin/geoip`, `POST /api/admin/geoip/update`.

## Проверка доступности из России (RIPE Atlas)

Код: `backend/app/ripe_atlas.py`. Админка: «Ноды → RIPE Atlas — доступность из России» (рядом с монитором блокировок), в мобильных админках — карточка с тем же названием.

- Раз в `interval_hours` часов (по умолчанию 6) магазин заказывает разовые измерения `sslcert` у RIPE Atlas. Измеряется подключение по TCP с TLS-рукопожатием — так подключается VPN-клиент.
- Измерения идут с `probes` зондов (по умолчанию 5) в стране (по умолчанию RU) ко всем адресам монитора блокировок: доменам API на 443 и нодам на их портах.
- Через `wait_minutes` минут (по умолчанию 15) магазин читает результаты. Адрес доступен, если рукопожатие удалось у доли зондов не меньше `ok_share` (по умолчанию половина).
- Итог передаётся в монитор блокировок как проба «RIPE Atlas RU». Если адрес недоступен `fail_streak` проверок подряд, а нода в панели онлайн, это блокировка. Срабатывают те же оповещения, перестановка резервных адресов API и резервный сквад.
- Нужен ключ API RIPE Atlas с правом создавать измерения (atlas.ripe.net → API keys) и кредиты на измерения: их начисляют за размещение своего зонда или за спонсорство.
- Расход кредитов: одно измерение sslcert с одного зонда — несколько кредитов. Расход = число адресов × число зондов × число проверок в день. Уменьшите число зондов или частоту, если кредитов мало.

API: `GET`/`PUT /api/admin/ripe-atlas`, `POST /api/admin/ripe-atlas/run`.
