# Автомасштабирование нод

«Серверы → Автомасштабирование»: магазин раз в минуту (вместе с мониторингом нод) смотрит, сколько пользователей
онлайн приходится на одну работающую ноду, и решает, не пора ли добавить или убрать ноду.

## Правила

| Условие | Действие |
| --- | --- |
| нагрузка выше «Добавлять выше» дольше «Держится, мин», нод меньше максимума | добавить ноду |
| нод онлайн меньше минимума | добавить сразу |
| нагрузка ниже «Убирать ниже» дольше «Держится, мин», нод больше минимума | убрать одну ноду, **созданную автоматически**, с наименьшим числом пользователей |

Между изменениями — пауза («Пауза между изменениями»). Ноды, созданные вручную, никогда не удаляются.

## Режимы

* **Рекомендации** (по умолчанию): только сообщение в Telegram — что сделать и почему (повтор не чаще раза в 6 часов).
* **Авто (Hetzner)**: магазин создаёт сервер в Hetzner Cloud (`POST /v1/servers`, метка `corgi=autoscale`) с
  cloud-init, который ставит Docker и запускает контейнер `remnawave/node`, и добавляет ноду в панель с выбранным профилем
  конфигурации и инбаундами. Если панель не приняла ноду, сервер сразу удаляется, чтобы не платить за него. Удаление —
  в обратном порядке: нода из панели, затем сервер.

Для «Авто» в `.env` нужен `HETZNER_API_TOKEN` (проект Hetzner → Security → API tokens, Read & Write); без него режим
«Авто» работает как «Рекомендации». Ключ ноды магазин берёт из панели (`GET /api/keygen`); `REMNANODE_SECRET_KEY`
в `.env` нужен, только если хотите задать свой.

## Ограничения

* Вызовы Remnawave (ключ ноды, создание ноды с профилем и инбаундами, удаление) проверяются в CI на настоящей
  панели последней версии (`tests/live/test_remnawave_live.py`). Вызовы Hetzner Cloud соответствуют его публичной
  документации и проверены на имитации — первый запуск «Авто» стоит провести под наблюдением.
* Метрика — пользователи онлайн по данным панели; загрузку CPU и канала нод она не учитывает.
* Новой ноде нужно несколько минут на установку; до этого она офлайн и в нагрузку не входит.

API: `GET /api/admin/nodes/autoscale`, `PUT /api/admin/nodes/autoscale` (право `provision_nodes`). Тесты:
`tests/test_node_autoscale.py`.
