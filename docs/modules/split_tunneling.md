# Split tunneling: российские сайты и приложения мимо VPN

Встроенный движок Xray (Android — `XrayEngine.kt`, iOS — `Shared/CorgiXray.swift` в Network Extension) строит
правила маршрутизации так:

| Правило | Куда | Где включается |
| --- | --- | --- |
| Локальные сети (10/8, 172.16/12, 192.168/16, 100.64/10, link-local, ULA) | напрямую | всегда |
| `.ru`, `.su`, `.рф`, Госуслуги, ФНС и российские сервисы на других доменах (sberbank.com, vk.com, vk.me, userapi.com, yandex.net, yandex.com, yastatic.net) | напрямую | переключатель «Российские сайты напрямую» в приложении |
| Домены, добавленные администратором | напрямую | тот же переключатель; список — «Приложения → Резервные адреса API и сайты напрямую» |
| Выбранные приложения (Android) | мимо VPN | «Приложения без VPN» (`addDisallowedApplication`) |
| Остальное | VPN: выбранный сервер или «Авто» | — |

* Список администратора приходит в подписанном документе `/api/public/mirrors` (поле `direct`, см.
  [anti_blocking.md](anti_blocking.md)): новые банки и госсервисы добавляются без выпуска приложения.
  Приложение принимает только строки вида домена (`^[a-z0-9.-]{3,253}$`).
* «Авто» — балансировщик Xray `leastPing` с наблюдателем: каждую минуту проверяет серверы запросом к
  `generate_204` и ведёт трафик через самый быстрый живой сервер; упавший сервер выпадает до восстановления.
* Сам процесс приложения всегда идёт напрямую, чтобы трафик Xray не зацикливался в туннель.
