# Юнит-экономика по источникам

«Аналитика → Юнит-экономика по источникам»: сколько стоит клиент из каждого канала и сколько он приносит.

## Откуда берётся источник

Первое касание, потом не перезаписывается (`users.acquisition_source`, миграция `0079_acquisition`):

| Ссылка | Пример |
| --- | --- |
| Бот | `https://t.me/ваш_бот?start=src_vk_ads` |
| Бот с рефералом | `https://t.me/ваш_бот?start=ref_КОД__src_vk_ads` — работают и реферал, и источник |
| Mini App | `https://t.me/ваш_бот/app?startapp=src_vk_ads` |
| Кабинет | `https://cabinet.example.com/?utm_source=vk_ads` |

Источник — латиница, цифры, `_ . -`, до 48 символов. Засчитывается только новому аккаунту (созданному меньше суток
назад): старый клиент, кликнувший по рекламе, не считается привлечённым ею. Без источника клиент попадает в строку
«без источника».

## Что считается

За выбранные месяцы — по клиентам, зарегистрированным в эти месяцы:

* новых клиентов, платящих клиентов, конверсия;
* выручка — все их оплаты (кроме оплат с баланса);
* расход — сумма введённых расходов на рекламу за эти месяцы;
* **CAC** = расход / платящие; выручка на платящего; **ROMI** = (выручка − расход) / расход.

Расходы вносит администратор по источнику и месяцу (0 удаляет месяц). API: `GET /api/admin/analytics/economics?months=3`,
`PUT /api/admin/analytics/economics/spend`, `POST /api/me/source`. Тесты: `tests/test_economics.py`.
