# Диагностика «Не работает VPN» в приложениях

Кнопка «Сообщить о проблеме» в Android и iOS 3.2.0 при оформленной подписке не просто создаёт обращение, а сначала
проверяет связь с телефона и отправляет результат в `POST /api/me/diagnostics`. Клиент сразу видит вероятную причину
и что сделать, поддержка — готовый отчёт в тикете «Не работает VPN — отчёт диагностики».

## Что проверяет телефон

| Проверка | Как |
| --- | --- |
| `dns` | разрешение имени API магазина (с учётом активного зеркала) |
| `api` | `GET /health/live` через активное зеркало |
| `subscription` | загрузка ссылки подписки, число серверов |
| `server` | TCP-подключение к каждому серверу подписки (до 12, таймаут 5 с) |

Код: `mobile/android-user/.../support/CorgiDiagnostics.kt`, `mobile/ios-user/VpnShopUser/VpnShopUserApp.swift`
(`enum CorgiDiagnostics`). Без подписки кнопка работает как раньше — обычное обращение.

## Что добавляет сервер и как выбирается причина

`backend/app/diagnostics.py` добавляет подписку (активна/истекла), устройства против лимита, ноды онлайн и последнюю
оплату. Причины проверяются по порядку, первая сработавшая — ответ:

1. `no_subscription`, 2. `expired` — нет или закончилась подписка;
3. `device_limit` — устройств больше лимита;
4. `servers_down` — все ноды офлайн в панели;
5. `shop_unreachable` — телефон не достучался до API и не скачал подписку;
6. `servers_blocked` — ноды онлайн, но ни один сервер не открылся с телефона (вероятна блокировка сети);
7. `some_servers` — часть серверов недоступна;
8. `unknown` — всё проходит, нужен человек.

Ответ: `{ticket_id, cause, hints}`; подсказки показываются клиенту. Лимит — 5 отчётов в минуту. Тесты:
`tests/test_diagnostics.py`.
