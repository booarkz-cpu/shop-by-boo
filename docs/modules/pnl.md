# P&L, расходы на инфраструктуру и оптовые заказы реселлеров

## P&L (`pnl.py`) — «Аналитика → P&L»

* **Выручка** — оплаченные платежи по месяцам (покупки с баланса не считаются второй раз: выручка — пополнение)
  минус возвраты.
* **Комиссии касс** — процент, который владелец задаёт для каждой кассы.
* **Расходы** — записи «Аналитика → Расходы»: месяц, категория (серверы, домены, ПО, персонал, прочее), поставщик и,
  для сервера, его нода; расходы на рекламу берутся из [юнит-экономики](unit_economics.md). Таблица `infra_costs`.
* **Итог** — валовая прибыль, маржа, прибыль на платящего клиента и стоимость каждой ноды на активного клиента.

API: `GET /api/admin/pnl`, `GET/POST /api/admin/pnl/costs`, `DELETE /api/admin/pnl/costs/{id}`, `PUT /api/admin/pnl/fees`.
Карточка «P&L» есть в мобильных админках.

## Оптовые заказы реселлеров (`reseller_orders.py`)

Партнёр продаёт подписки в своём боте или на сайте и получает их по API.
`POST /api/reseller/orders` (ключ реселлера, как для `/api/reseller/catalog`) с тарифом и своей ссылкой на клиента
создаёт или продлевает подписку этого клиента и возвращает ссылку подписки. Оптовая цена — цена тарифа минус процент
комиссии реселлера — списывается с баланса реселлера (его комиссии плюс пополнения, которые владелец вносит в
«Партнёры → Пополнить баланс», `POST /api/admin/marketplace/resellers/{id}/deposit`). Одна ссылка — всегда один
клиент. `Idempotency-Key` обязателен: повтор возвращает тот же заказ без второго списания.
`GET /api/reseller/orders/{id}` — состояние заказа.

Тесты: `tests/test_reconciliation.py`.
