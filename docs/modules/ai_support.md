# ИИ-черновики ответов поддержки

В обращении кнопка «Черновик ИИ» (веб-админка, Android- и iOS-админка) готовит ответ, который оператор
проверяет и отправляет сам: ИИ ничего не отправляет клиенту.

## Как строится черновик

1. **База знаний** — «Поддержка → База знаний для ИИ» (`support_ai.faq` в `app_settings`): вопросы и ответы.
2. **Поиск** (`support_ai.rank`) — по словам обращения выбираются подходящие пункты FAQ.
3. **Контекст обращения** (`ticket_context`) — переписка и состояние подписки клиента (статус, дней до конца, лимиты).
4. **Модель** — любая OpenAI-совместимая или Anthropic Messages API. `SUPPORT_AI_URL` — полный адрес эндпоинта
   (`https://…/v1/chat/completions` или `https://api.anthropic.com/v1/messages`; по слову `anthropic` в адресе
   выбирается формат Anthropic), `SUPPORT_AI_KEY`, `SUPPORT_AI_MODEL` («Настройки → Рабочие параметры → Поддержка»).
   В модель уходят последние 12 сообщений обращения и строка о подписке; температура 0.2, до 700 токенов.
5. **Без модели или при ошибке** черновик собирается из найденных ответов FAQ; в ответе API `source: "faq"`
   и причина в `note`.

## API

| Метод | Путь | Право |
| --- | --- | --- |
| `POST` | `/api/admin/support/tickets/{id}/draft` → `{"draft", "source", "matched"}` | `support.write` |
| `GET`/`PUT` | `/api/admin/support/ai` — база знаний и признак настроенной модели | `support.read` / `support.write` |

Ключ модели не возвращается в API. Тесты: `tests/test_support_ai.py`.
