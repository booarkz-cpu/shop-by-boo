# Языки интерфейса (i18n)

| Клиент | Языки | Где строки | Как выбирается язык |
| --- | --- | --- | --- |
| Android и iOS (клиент и админка) | RU, EN, UK | `packages/localization/user.json`, `packages/localization/admin.json` → копируются в `assets/l10n.json` (Android) и `l10n.json` (iOS) | язык системы (uk → UK, en → EN, иначе RU), можно сменить в приложении |
| Telegram-бот | RU, EN, UK | `services/backend/app/bot.py` (`_tr`) | `language_code` пользователя Telegram; `uk`/`ua` → UK |
| Кабинет и Mini App | RU, EN, UK | `apps/user-cabinet/src/i18n.tsx` (`EN`, `UK`) | кнопка языка в шапке, цикл RU → EN → UK; сохраняется в `localStorage.rw_lang` |
| Админка | RU, EN | `apps/lucy-admin/web/src/i18n.tsx` (`data-i18n`) | переключатель, `localStorage.rw_lang` |
| Макет мобильных экранов из админки | RU, EN, UK | «Приложения → Макет», для каждого языка свой текст | язык приложения |

Правила:

* Ключи всех языков совпадают, пустых значений нет — это проверяет `tests/test_v270_mobile_apps.py`
  (и что копии в приложениях совпадают с `packages/localization/*.json`).
* Добавляя строку, добавьте её во все языки каталога и выполните копирование в оба приложения.
* Каталог `UK` покрывает все ключи `EN` (95 из 95). Украинский **не** наследует русский:
  если записи нет, берётся английская строка, чтобы непереведённая подпись не рендерилась
  по-русски. `detectLang()` проверяет `uk`/`ua` до `en`, иначе локаль `uk-UA` свалилась бы в русский.
* Язык по умолчанию выбирается в админке (Настройки → Язык по умолчанию) из `ru`, `en`, `uk`
  и отдаётся в `/api/public/config`.
* Ответы backend об ошибках — на русском; приложения показывают их как есть.

## Редакционная проверка 17.11.2026 (REQ-UI-0004)

- Подсказка адреса API на RU/EN/UK одинаково указывает HTTPS и исключения для локального HTTP: localhost, 127.0.0.1 и 10.0.2.2. Ранее украинская версия ограничивалась фразой «Потрібен HTTPS».
- В подсказке установки VPN-клиента устранена ссылка во множественном числе на единственный клиент. Уточнено, что для подключения нужен совместимый бесплатный клиент.
- Подпись суммы оплаты приведена к формам «Оплачено за VPN» / «Paid for VPN». Подпись места в конкурсе больше не требует неоднозначного числового окончания.
- Украинский Heartbeat переведён как «Контрольний сигнал». Основные каталоги и их копии Android/iOS и сервера синхронизированы.
- Полнота переводов всех продуктов, ошибок, писем, установщика и документов по-прежнему не подтверждена: REQ-UI-0004 остаётся PARTIAL. Полная визуальная приёмка этих строк на физических устройствах не выполнялась.
