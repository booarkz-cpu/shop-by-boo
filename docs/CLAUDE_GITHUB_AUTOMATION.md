# Автоматизация VPN Shop by Corgi Lucy

## Что запускается автоматически

### 1. CI — при push, Pull Request и вручную

Workflow `.github/workflows/ci.yml` выполняет существующий набор проверок проекта: backend и миграции, тесты, линтеры, frontend typecheck/build, Docker Compose, security checks и доступные мобильные проверки. Конкретный набор определяется актуальным workflow. GitHub Actions — источник истины для статуса: непроведённая или пропущенная проверка не считается пройденной.

### 2. Claude Code — при push в рабочую ветку

Workflow `.github/workflows/claude-roadmap.yml` запускает Claude Code на push в ветки, кроме `main`, а также поддерживает ручной запуск через **Actions → Claude Code — roadmap automation → Run workflow**.

Claude:
- читает дорожную карту и текущий diff;
- работает только в выбранной рабочей ветке;
- исправляет подтверждённые, безопасные проблемы небольшими изменениями;
- добавляет/обновляет регрессионные тесты, когда это уместно;
- запускает подходящие проверки и отражает только реальные результаты;
- при изменениях добавляет запись в `docs/AUTOMATION_LOG.md`;
- не сливает PR, не включает auto-merge, не деплоит production, не проводит реальные платежи/возвраты и не выполняет разрушительные операции.

Автоматизация не гарантирует, что Claude найдёт или исправит все дефекты за один запуск. Изменения остаются в рабочей ветке и должны пройти CI и review.

## Обязательная настройка авторизации Claude

Workflow GitHub Actions сам по себе не получает доступ к Anthropic. В репозитории открой:

**Settings → Secrets and variables → Actions → New repository secret**

Добавь один из вариантов:
- `ANTHROPIC_API_KEY` — API-ключ Anthropic; или
- `CLAUDE_CODE_OAUTH_TOKEN` — OAuth-токен Claude Code, если он доступен для твоего аккаунта и сценария.

Не записывай секрет в YAML, код, README, Issues или логи. Не отправляй ключ в чат и не помещай его в commit. При отсутствии обоих секретов AI-шаг безопасно пропускается с предупреждением; обычный CI работает независимо.

Официальная инструкция: https://github.com/anthropics/claude-code-action/blob/main/docs/setup.md

## Как включить и проверить

1. Открой PR, который содержит файлы автоматизации, и проверь результаты CI.
2. После включения изменений в основную ветку добавь секрет Anthropic в настройках репозитория.
3. Выполни push в отдельную рабочую ветку или запусти Claude workflow вручную на этой ветке.
4. Проверь **Actions**: успешный запуск CI и Claude — разные статусы.
5. Просмотри diff, отчёт `docs/AUTOMATION_LOG.md`, результаты тестов и замечания Claude.
6. Только после проверки человеком решай, сливать ли PR.

## Ограничения и защита

- `main` исключена из автоматического редактирования Claude.
- Workflow не сливает PR и не выпускает релиз автоматически.
- Платёжные интеграции должны тестироваться в sandbox. Реальные списания и возвраты запрещены без отдельного разрешения.
- Не запускай workflow на ветках с недоверенным кодом, если в репозитории настроены секреты, пока не проверены права записи и политика доступа.
- Внешние API, эмуляторы, Apple signing, Android signing и production VDS могут требовать отдельных секретов, лицензий, устройств или разрешений.
- Скриншоты считаются обновлёнными только после фактической генерации из актуальной сборки и проверки файлов.
- При создании коммитов через `GITHUB_TOKEN` GitHub намеренно не запускает все последующие workflow-события повторно; это предотвращает бесконечный цикл автоматизации. Если нужен повторный проход, используй новый пользовательский push или ручной запуск.

## Ручной запуск

Вкладка **Actions** → **Claude Code — roadmap automation** → **Run workflow** → выбери рабочую ветку. Не выбирай `main`.

## Диагностика

- **Claude пропущен:** проверь, что задан один из двух секретов.
- **CI не прошёл:** открой конкретный job и исправь первопричину; не отключай тест ради зелёного статуса.
- **Claude изменил код, но проверки не запускались:** задача не считается завершённой.
- **Нет возможности сделать мобильный скриншот:** зафиксируй блокер (SDK, эмулятор, подпись или устройство), не подменяй его фиктивным изображением.
