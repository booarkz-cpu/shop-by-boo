# Архив: исторические документы из корня репозитория

Здесь лежат релиз-ноты, отчёты аудитов и инструкции прошлых выпусков (V1–V45 старой нумерации, 1.x–3.x),
которые раньше занимали корень репозитория. Они сохранены для истории и не описывают текущий выпуск.
