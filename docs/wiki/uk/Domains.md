# Домени й сертифікати

| Домен | Куди вказує | Для чого |
| --- | --- | --- |
| `shop.` `api.` `admin.` `cabinet.` | сервер магазину | кабінет, API, адмінка, Mini App |
| `panel.` | сервер панелі | панель Remnawave |
| `sub.` | сервер сторінки підписки | сторінка підписки Remnawave |
| `link.` та інші | сервер магазину | портал підписки магазину й дзеркала |

- Для доменів із Let's Encrypt вимкніть проксі Cloudflare: перевірці потрібні порти 80 і 443 напряму.
- Перевірка записів і сертифікатів — «Серверы → Домены и сертификаты».
- Сертифікати подовжуються самі; за 14 днів до закінчення — попередження в «Состоянии системы».

Докладніше: [посібник власника](https://github.com/booarkz-cpu/shop-by-boo/blob/main/docs/uk/OWNER_SETUP_GUIDE.md#домени), [налаштування доменів](https://github.com/booarkz-cpu/shop-by-boo/blob/main/docs/ru/new/DOMAIN_SETUP_GUIDE.md) (російською).
