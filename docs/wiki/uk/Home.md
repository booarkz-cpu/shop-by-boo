# Коргі Люсі — Вільний інтернет без зайвого Гав!

Магазин VPN-підписок поверх вашої панелі Remnawave: клієнт платить і одразу отримує доступ, а ви керуєте
всім з однієї адмін-панелі.

> Поточний випуск **v28.161.0**, runtime/API `21.5.1`, міграція магазину `0094_store_subscriptions`.

## Що потрібно заздалегідь

1. **Сервер.** Для чистого VPS рекомендовано Ubuntu 24.04 або Debian 12 із доступом root. Для збирання всіх образів орієнтуйтеся на 4 vCPU, 8 ГБ оперативної пам’яті та 40 ГБ диска.
2. **DNS.** Спрямуйте вибрані імена на сервер. Для API, адмінпанелі, Mini App, кабінету й підтримки інсталятор пропонує піддомени `api`, `admin`, `app`, `cabinet` і `support`.
3. **Панель Remnawave** — адреса й API-токен. Без неї магазин не зможе видати доступ.
4. **Telegram-бот** — токен від [@BotFather](https://t.me/BotFather).
5. **Платіжна каса** — ключі будь-якого провайдера. Без ключів магазин працює, але гроші прийняти не зможе.

## Як це влаштовано

```mermaid
flowchart LR
    C[Клієнт] --> B[Telegram-бот]
    C --> M[Mini App]
    C --> W[Особистий кабінет]
    C --> A[Android / iOS]
    B --> API[Backend API]
    M --> API
    W --> API
    A --> API
    API --> DB[(PostgreSQL)]
    API --> R[(Redis)]
    API --> RW[Remnawave]
    P[Платіжна каса] -->|webhook| API
    AU[Адмін-панель] --> API
```

Клієнт платить → каса надсилає webhook → магазин звіряє підпис і суму в провайдера → worker видає доступ у
Remnawave → клієнт отримує посилання-підписку.
