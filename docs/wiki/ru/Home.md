# Корги Люси — Свободный интернет без лишнего Гав!

Магазин VPN-подписок поверх вашей панели Remnawave: клиент платит и сразу получает доступ, вы управляете
всем из одной админ-панели.

> Текущий выпуск **v28.161.0**, runtime/API `21.5.1`, миграция магазина `0094_store_subscriptions`.

## Что нужно заранее

1. **Сервер.** Для чистого VPS рекомендуется Ubuntu 24.04 или Debian 12 с доступом root. Для сборки всех образов ориентируйтесь на 4 vCPU, 8 ГБ памяти и 40 ГБ диска.
2. **DNS.** Направьте выбранные имена на сервер. Для API, админки, Mini App, кабинета и поддержки установщик предлагает поддомены `api`, `admin`, `app`, `cabinet` и `support`.
3. **Панель Remnawave** — адрес и API-токен. Без неё магазин не сможет выдать доступ.
4. **Telegram-бот** — токен от [@BotFather](https://t.me/BotFather).
5. **Платёжная касса** — ключи любого провайдера. Без ключей магазин работает, но деньги принять не сможет.

## Как это устроено

```mermaid
flowchart LR
    C[Клиент] --> B[Telegram-бот]
    C --> M[Mini App]
    C --> K[Личный кабинет]
    C --> A[Android / iOS]
    B --> API[Backend API]
    M --> API
    K --> API
    A --> API
    API --> DB[(PostgreSQL)]
    API --> R[(Redis)]
    API --> RW[Remnawave]
    P[Платёжная касса] -->|webhook| API
    AU[Админ-панель] --> API
```

Клиент платит → касса присылает webhook → магазин сверяет подпись и сумму у провайдера → worker выдаёт
доступ в Remnawave → клиент получает ссылку-подписку.
