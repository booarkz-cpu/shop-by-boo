# Админ-панель

Все разделы читают и изменяют реальные данные. Каждое действие проверяет право на сервере — скрыть кнопку в
браузере недостаточно.

## Как устроен доступ

Роли: `admin`, `operator`, `support`, `viewer`. Право проверяется зависимостью `require_permission(...)` на
каждом административном маршруте. Например, возврат требует `payments.refund`, просмотр клиента —
`users.read`, ответ в поддержке — `support.write`.

Если кнопка не срабатывает — сначала смотрите ответ сервера: `403` значит «нет права», а не «сломан интерфейс».

## Что делает панель при сбое

* Ошибка загрузки раздела показывает причину и кнопку повтора — данные не изменяются;
* сбой отрисовки показывает экран ошибки вместо пустой страницы;
* опасные операции (возврат, удаление, отключение подписки) требуют подтверждения.

## Работа с клиентом

1. Откройте «Пользователи», найдите клиента по почте, Telegram или ID.
2. В карточке: подписки, платежи, устройства, трафик по дням, сессии.
3. Действия: продлить, сменить тариф, отключить, вернуть деньги, отправить сообщение.

Трафик по дням берётся из статистики Remnawave. Если панель её не отдаёт, раздел покажет пустой график, а не
ошибку.
