# Домены и сертификаты

| Домен | Куда указывает | Для чего |
| --- | --- | --- |
| `shop.` `api.` `admin.` `cabinet.` | сервер магазина | кабинет, API, админка, Mini App |
| `panel.` | сервер панели | панель Remnawave |
| `sub.` | сервер страницы подписки | страница подписки Remnawave |
| `link.` и другие | сервер магазина | портал подписки магазина и зеркала |

- Для доменов с Let's Encrypt выключите прокси Cloudflare: проверке нужны порты 80 и 443 напрямую.
- Проверка записей и сертификатов — «Серверы → Домены и сертификаты».
- Сертификаты продлеваются сами; за 14 дней до окончания — предупреждение в «Состоянии системы».

Подробно: [настройка доменов](https://github.com/booarkz-cpu/shop-by-boo/blob/main/docs/ru/new/DOMAIN_SETUP_GUIDE.md), [домен подписки](https://github.com/booarkz-cpu/shop-by-boo/blob/main/docs/ru/new/SUBSCRIPTION_DOMAIN.md).
