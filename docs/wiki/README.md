## Включить Wiki и создать первую страницу

1. Войдите в GitHub под учётной записью с правом изменять настройки репозитория. Откройте **Settings → General → Features** и установите флажок **Wikis**. Для записи страниц по умолчанию нужен доступ на запись в репозиторий.
2. Откройте вкладку **Wiki**. Если GitHub предлагает **Create the first page**, создайте страницу `Home` и нажмите **Save page**. Если уже открылась домашняя страница, переходите к следующему шагу.
3. Проверьте адрес отдельного Git-репозитория Wiki. После сохранения первой страницы команда возвращает SHA и имя `HEAD`.

```bash
git ls-remote --exit-code https://github.com/booarkz-cpu/shop-by-boo.wiki.git HEAD
```

## Подготовить и проверить три перевода

Выполните команды из корня клона `shop-by-boo` на версии документации, которую хотите опубликовать. Проверенные версии Python — 3.14 и 3.15. Для клонирования и публикации нужен Git.

```bash
work=$(mktemp -d)
python3 scripts/export_wiki.py "$work/pages"
git clone https://github.com/booarkz-cpu/shop-by-boo.wiki.git "$work/wiki"
cp "$work/pages/"*.md "$work/wiki/"
git -C "$work/wiki" add -- Home.md _Sidebar.md 'ru-*.md' 'en-*.md' 'uk-*.md'
git -C "$work/wiki" diff --cached --stat
git -C "$work/wiki" diff --cached
```

Экспорт создаёт отдельные страницы, например `ru-Installation`, `en-Installation` и `uk-Installation`. В корне `Home.md` предлагает выбрать язык, а `_Sidebar.md` содержит меню всех трёх руководств. Ссылки между страницами ведут в Wiki. Ссылки на подробные руководства вне Wiki ведут в основной репозиторий. GitHub отображает боковое меню после публикации файла. [Боковая панель Wiki](https://docs.github.com/en/communities/documenting-your-project-with-wikis/creating-a-footer-or-sidebar-for-your-wiki)

Просмотрите изменения в существующих страницах, особенно в `Home.md` и `_Sidebar.md`, и совместите ручные правки, если их нужно сохранить. Если список изменений пуст, опубликованные файлы уже совпадают с экспортом. Для публикации проверенных изменений выполните команды в той же оболочке.

```bash
git -C "$work/wiki" commit -m "wiki: обновить руководства на трёх языках"
git -C "$work/wiki" push
git -C "$work/wiki" rev-parse HEAD
git ls-remote --exit-code https://github.com/booarkz-cpu/shop-by-boo.wiki.git HEAD
```

После публикации сравните два SHA и откройте Wiki в браузере. С главной выберите каждый язык, перейдите по ссылке установки и вернитесь через боковое меню. В открытом репозитории повторите проверку в окне без авторизации.

## Если Wiki не открывается

| Симптом | Что проверить |
| --- | --- |
| Вкладка Wiki отсутствует | Проверьте пункт **Wikis** в настройках и меню дополнительных вкладок. Если настройки скрыты для вашей учётной записи, администратор репозитория может проверить флажок. |
| `/wiki` возвращает 404 или переносит на главную репозитория | Откройте прямую ссылку с учётной записью с доступом и проверьте флажок и наличие сохранённой страницы `Home`. У публичного запроса после перенаправления может быть HTTP 200 на странице исходников. Сверьте конечный адрес в браузере. |
| `git ls-remote` или `git clone` сообщает `Repository not found` либо запрашивает учётные данные | Сравните адрес с **Clone this wiki locally**. Проверьте доступ к основному репозиторию тем же аккаунтом, затем наличие первой сохранённой страницы. Эти две проверки позволяют различить причины отказа. |
| `git push` отклонён | Проверьте право записи и обычную Git-аутентификацию. При `non-fast-forward` получите свежий клон Wiki и заново просмотрите разницу с экспортом, чтобы сохранить изменения другого автора. |
| Открывается другая языковая версия или ссылка страницы даёт 404 | Проверьте в клоне файлы `ru-Home.md`, `en-Home.md`, `uk-Home.md`, корневые `Home.md` и `_Sidebar.md`. Повторите экспорт из нужной версии проекта и сравните подготовленные изменения. |
