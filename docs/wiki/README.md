# VPN Shop by Corgi Lucy — Wiki

Готовые материалы для GitHub Wiki проекта. GitHub создаёт репозиторий `*.wiki.git` только после первой
страницы, сделанной вручную в веб-интерфейсе, поэтому эта папка служит источником для его наполнения: каждая
страница ниже — готовый Markdown, который достаточно скопировать в Wiki.

Пока Wiki не создана, эти же страницы читаются прямо в репозитории и связаны с полной документацией.

## Как опубликовать в GitHub Wiki

1. Откройте `https://github.com/booarkz-cpu/shop-by-boo/wiki` и нажмите **Create the first page** —
   этим GitHub создаёт репозиторий Wiki.
2. Сохраните первую страницу (достаточно заголовка), затем склонируйте Wiki:

   ```bash
   git clone https://github.com/booarkz-cpu/shop-by-boo.wiki.git
   ```

3. Скопируйте содержимое `docs/wiki/ru`, `docs/wiki/en`, `docs/wiki/uk` в клон. Имена файлов —
   готовые имена страниц (`Home.md`, `Installation.md`, …).
4. Закоммитьте и запушьте:

   ```bash
   cd shop-by-boo.wiki
   git add -A && git commit -m "wiki: русская, английская и украинская документация" && git push
   ```

5. В настройках Wiki включите боковую панель: файл `_Sidebar.md` в каждой языковой папке содержит
   готовое меню.
