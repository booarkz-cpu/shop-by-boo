# Журнал изменений реестра требований

Реестр: [REQUIREMENTS_MASTER_REGISTER.md](REQUIREMENTS_MASTER_REGISTER.md). Требования из реестра не удаляются:
отменённое владельцем получает статус `RETIRED_BY_OWNER` с причиной и ссылкой на решение. Проверка в CI
(`scripts/audit/requirements_register.py --check`) не пропускает исчезнувшее или изменённое требование.

## 2026-11-10

- Источник: мастер-промпт владельца v6 (`docs/prompts/MASTER_PROMPT_V6.md`, 2499 строк), сохранён без изменений.
- Создан реестр: 653 требования с постоянными ID и номерами строк источника. Части I, II и IV разобраны по пунктам;
  Часть III (исходный XML) повторяет Часть I и оставлена для сверки.
- Первая сверка с кодом: 18 требований получили статус с доказательством (11 `PASS`, 7 `PARTIAL`),
  остальные 635 — `NOT_TESTED`, то есть ещё не сверены.
- Объединений дублей нет. Удалений нет.
