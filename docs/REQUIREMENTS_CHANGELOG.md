# Журнал изменений реестра требований

Реестр: [REQUIREMENTS_MASTER_REGISTER.md](REQUIREMENTS_MASTER_REGISTER.md). Требования из реестра не удаляются:
отменённое владельцем получает статус `RETIRED_BY_OWNER` с причиной и ссылкой на решение. Проверка в CI
(`scripts/audit/requirements_register.py --check`) не пропускает исчезнувшее или изменённое требование.

  остальные 635 — `NOT_TESTED`, то есть ещё не сверены.
