# Що нового у v28.54.0

- **Фільтр реклами та дитячий режим.** Клієнт вмикає фільтр у кабінеті, боті чи застосунку, власник родини — для учасника. Фільтр працює на нодах.
- **Регіони клієнтів.** З безкоштовним ключем MaxMind географія показує регіони всередині країн.
- **Доступність із Росії через RIPE Atlas.** API та ноди перевіряються із зондів російських провайдерів, результати йдуть у монітор блокувань.
