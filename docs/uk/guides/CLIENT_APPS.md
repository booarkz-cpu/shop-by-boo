# Android-застосунки для клієнтів

Магазин має два Android-застосунки для клієнтів. Обидва підписані ключем `corgi` і додаються до кожного випуску під постійними іменами.

| | Застосунок магазину | «Корги Люси: клиент» (клієнт Коргі Люсі) |
| --- | --- | --- |
| Що це | Кабінет клієнта в магазині: вхід, тарифи, оплата, підписка, підтримка, вбудований VPN | VPN-клієнт для будь-якої підписки, не лише магазину |
| Каталог | `mobile/android-user` (`shop.remnawave.user`) | `mobile/android-client` (`shop.corgi.client`) |
| Завантажити | [corgi-lusi-android.apk](https://github.com/booarkz-cpu/shop-by-boo/releases/latest/download/corgi-lusi-android.apk) | [corgi-lusi-client.apk](https://github.com/booarkz-cpu/shop-by-boo/releases/latest/download/corgi-lusi-client.apk) |

Російські оригінали: [ANDROID_ARCHITECTURE](../../ru/new/ANDROID_ARCHITECTURE.md), [ANDROID_CLIENT_APP](../../ru/new/ANDROID_CLIENT_APP.md). Інші посібники: [зміст](README.md).

## Застосунок магазину

- **Вхід:** e-mail і пароль, passkey, Telegram, Яндекс ID, VK ID, Google (ті, що ввімкнув магазин). Адреса магазину вшита в застосунок.
- **Кабінет:** тарифи й конструктор тарифів, оплата (зокрема з балансу), промокоди, стан підписки, пристрої, підтримка, реферали; кожен текст і блок екрана змінюється з адмінпанелі («Android та iOS»).
- **Вбудований VPN** (Xray-core): імпортує підписку магазину — посилання або Xray JSON від Remnawave, зокрема Hysteria2 — і підключається однією кнопкою; найшвидший сервер обирається автоматично, якщо ви не обрали свій.
- **Що працює без VPN** (діалог «розділення»):
  - застосунки, що ходять в інтернет напряму;
  - російські сайти (.ru, .рф, .su) напряму;
  - **свої правила** (v28.87.0): сайт або адреса — `example.com`, `full:api.example.com`, `keyword:ads`, `regexp:…`, `10.0.0.0/8` — йде **через VPN**, **напряму** або **блокується**. Ваші правила діють раніше за маршрутизацію підписки. «Через VPN» веде туди ж, куди решта трафіку: на обраний сервер або автоматичний вибір. Списки `geosite:`/`geoip:` не приймаються: файлів geo в застосунку немає, і Xray відмовився б запускати всю конфігурацію;
  - **фрагментація TLS** (v28.87.0): ділить початок TLS-з'єднання (ClientHello або пакети 1–3 / 1–5) — допомагає, коли провайдер заважає підключенню. Лише для серверів з TLS; REALITY не зачіпається.
  - Зміни діють з наступного підключення; закриття діалогу перепідключає VPN.
- Без вбудованого рушія застосунок передає підписку в Happ, v2rayNG або Hiddify.

## «Корги Люси: клиент»

Окремий застосунок для будь-яких підписок (посилання, QR, «Поділитися», повний Xray JSON), написаний з нуля на нашому рушії Xray-core.

| Розділ | Що має |
| --- | --- |
| Головна | Велика кнопка підключення, картка обраного сервера відкриває список серверів із пінгом; картка провайдера з трафіком, строком, посиланнями на підтримку й сайт із заголовків підписки |
| Сервери | Кілька провайдерів, пошук, фільтр за протоколом, сортування, пінг усіх, «Автовибір» (observatory + leastPing), прапори |
| Протоколи | VLESS (REALITY, TLS, Vision), VMess, Trojan, Shadowsocks, SOCKS5, WireGuard, Hysteria2; транспорти tcp, ws, grpc, xhttp, httpupgrade |
| Маршрутизація | Усе через VPN, усе, крім локальної мережі, російські сайти напряму, свої правила (домен, IP/CIDR, `geosite:`, `geoip:` з вашими geo-файлами); іменовані профілі маршрутизації |
| Тунель | TUN або лише проксі; фрагментація TLS, noises, Mux, сніфінг, блокування UDP, DNS (IP/DoH/DoT), MTU, виключені маршрути |
| З'єднання | Проксі для окремих застосунків, плитка швидких налаштувань, kill switch через системні налаштування, LAN, доступ через хотспот до SOCKS5/HTTP з паролем, автопідключення |
| Інше | Віджет, Android TV і «підписка на ТВ з телефона», резервні копії (файл, QR, посилання), схеми `corgi://`, журнали тунелю, три іконки застосунку, RU/EN/UK |

Оновлення: застосунок перевіряє `corgi-lusi-client.json` останнього випуску; або додайте репозиторій до [Obtainium](https://github.com/ImranR98/Obtainium) з фільтром APK `^corgi-lusi-client\.apk$`. З v28.108.0 кожна нова версія клієнта також отримує власний випуск `client-v<версія>` (ніколи не «останній»): додайте в Obtainium фільтр назв випусків `^client-v`, щоб стежити лише за клієнтом.

## Перевірка

Модульні тести (JUnit) обох застосунків, Compose UI-тести та тести VPN на емуляторі з локальним Xray виконуються в CI. Перевірка на справжньому телефоні й ТВ — BLOCKED_EXTERNAL.
