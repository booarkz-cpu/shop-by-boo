# Remnawave з нуля: покроковий посібник власника

Від порожнього VPS до магазину, що продає підписки на власні ноди. Усе робиться в адмінпанелі магазину, без команд на серверах.

Російський оригінал: [REMNAWAVE_INSTALLATION_GUIDE](../../ru/new/REMNAWAVE_INSTALLATION_GUIDE.md). Інші посібники: [зміст](README.md).

## 0. Що підготувати

- **VPS:** один (панель і нода разом) або кілька (панель окремо, ноди окремо). Debian 12–13 або Ubuntu 22.04–26.04, x86_64 чи arm64.
- **Вхід:** root або користувач із `sudo` без пароля; ключ Ed25519 або пароль.
- **Домени:** для панелі та, за бажанням, для сторінки підписки — див. [DOMAIN_SETUP_GUIDE](../../ru/new/DOMAIN_SETUP_GUIDE.md).
- **Підтвердження небезпечних дій.** Увімкніть 2FA в «Захисті та 2FA»: запуск плану на серверах підтверджується кодом ([RBAC](../../ru/new/RBAC.md)).

## 1. Додати сервери

«Сервери → Встановлення Remnawave → Сервери для Remnawave»:
1. Вкажіть адресу, порт, користувача та ключ або пароль.
2. Звірте відбиток ключа сервера з консоллю хостингу і збережіть.
3. Натисніть «Перевірити». Звіт покаже ОС, ресурси, Docker, зайняті порти та DNS.

Докладно: [майстер встановлення](../../ru/new/REMNAWAVE_INSTALLATION_WIZARD.md).

## 2. Змінити ключ на ключ магазину

«Змінити ключ» у рядку сервера. Магазин створить власний ключ для цього сервера і перевірить вхід ним. Після цього магазин більше не зберігає ваш пароль чи ключ.

## 3. Встановити

1. **Режим:** «Панель і нода», «Лише панель», «Лише нода», з окремою сторінкою підписки або розподілено.
2. **Домени й сертифікат:** Let's Encrypt для справжніх доменів або внутрішній для перевірки.
3. **План:** «Скласти план», прочитати, що зміниться, «Запустити за цим планом», підтвердити кодом. Журнал кроків видно одразу; у разі помилки зміни відкочуються.

За бажанням під час встановлення з SelfSteal: транспорти ноди xHTTP + REALITY (TCP 4443), gRPC + REALITY (TCP 8443) і Hysteria2 (UDP 443) поруч із TCP + REALITY.

## 4. Підключити магазин

«Підключити магазин до цієї панелі» → «Застосувати». Магазин почне створювати користувачів у цій панелі без перезапуску. Пароль адміністратора панелі — «Показати вхід у панель», з підтвердженням.

## 5. Додавати ноди

Режим «Додати ноди» на вже підключену панель: магазин реєструє ноду в панелі, відкриває її порт лише для адреси панелі й перевіряє зв'язок. Модулі нод — IPv6, ядро Xray, WARP, NetBird, Xray Checker, транспорти ноди, захист сервера (fail2ban, оновлення безпеки, BBR, SSH лише з ваших адрес) і самовідновлення — у «Розширеннях Remnawave» та майстрі ([REMNAWAVE_EXTENSIONS](../../ru/new/REMNAWAVE_EXTENSIONS.md)).

## 6. Обслуговування

| Що | Де |
| --- | --- |
| Оновлення панелі та нод | «Оновлення → Автооновлення Remnawave» — вночі або кнопкою ([AUTO_UPDATE](../../ru/new/AUTO_UPDATE.md)) |
| Копії бази панелі | автоматично під час кожного оновлення; зберігаються на сервері панелі та, зашифровані, у магазині |
| Діагностика, відновлення бази, перевстановлення, видалення | кнопки встановлення в «Встановленні Remnawave» |
| Вимкнути/увімкнути ноду, перейменувати, перенести | «Сервери → Сервери» |
| Стан | «Стан системи», «Automation Center», моніторинг |

**Перевірено:** встановлення в CI на справжню панель і ноду (живі тести `remnawave-live.yml`). На вашому VPS з вашими доменами — BLOCKED_EXTERNAL, доки не з'являться тестові сервери.
