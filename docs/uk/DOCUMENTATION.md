# VPN Shop — v28.7.0 (runtime 21.5.1)

Поточне стабільне ядро: API, адмінка, кабінет/Mini App, бот, Support Pro і мобільні вихідні коди. Міграція магазину: `0066_push_notifications`; Support Pro: `0007`. v28.7.0 додає email-канал підтримки в Support Pro 3.7 (прийом IMAP без дублів, відповіді SMTP у ланцюжку листів, захист від автовідповідей і повернень, видалення даних і строк зберігання). v28.6.0 додав віджет підписки на робочий стіл Android і кілька профілів магазинів в адмін-застосунках Android та iOS. v28.5.0 додав нативні push-сповіщення в застосунки Android та iOS (FCM HTTP v1 і APNs, токен прив'язаний до сесії входу й відкликається при виході). v28.4.0 переніс адмінку, кабінет і Telegram Mini App на Next.js у дизайні Remna Dark, додав звірений імпорт історії підписок і платежів із відкатом та API профілю клієнта. v28.3.0 додав 96 типізованих live-налаштувань із шифруванням секретів, staged apply, аудитом, збіжністю процесів і rollback; restart-bound поля та 2 workflow-поля класифіковані окремо.

Справжні платежі залишаються закритими до завершення application E2E v2. Повне перенесення функцій та підписані APK/IPA ще не завершено. Stable визначає канал поточного ядра.

Для локального тесту клонуйте тег `v28.7.0` і виконайте `bash scripts/test-up.sh`. Loopback-порти: API 18080, адмінка 18081, кабінет 18082, Mini App 18083. Sandbox-підписка не створює VPN-тунель.

Нова установка через root SSH/Termius:

```bash
curl -fsSL https://raw.githubusercontent.com/booarkz-cpu/shop-by-boo/v28.7.0/install.sh -o /root/shop-install.sh && BRANCH=v28.7.0 bash /root/shop-install.sh
```

Для чинного магазину використовуйте регламент оновлення, збережіть секрети й перевірте узгоджену копію.
