# VPN Shop — v28.14.0 (runtime 21.5.1)

Поточне стабільне ядро: API, адмінка, кабінет/Mini App, бот, Support Pro і мобільні вихідні коди. Міграція магазину: `0070_node_terminal`; Support Pro: `0008`. v28.14.0 додає термінал вузлів: повну оболонку на VPN-сервері через агент (без SSH і відкритих портів), лише для адміністратора з 2FA, з підтвердженням кожної сесії та зашифрованим записом. v28.13.0 додав перевірку поштового домену (MX, SPF, DKIM, DMARC) і звіти DMARC зі скриньки лише на читання або завантаженням, без дублів, із захистом від архівів-бомб і XXE. v28.12.0 додав до Support Pro 3.8 міст Zendesk і Freshdesk (імпорт звернень та історії без дублів, клієнт об’єднується за email, відповіді операторів публікуються один раз, пауза при HTTP 429, видалення даних без повторного імпорту). v28.11.0 додав ключі доступу (passkeys) у застосунки Android та iOS. v28.10.0 оновив адмін-панель: стартова сторінка «Усі розділи», підписи всіх полів. v28.9.0 додав мережеву аналітику вузлів: ASN, власника мережі, країну RIR і репутацію IP з кешем і позначкою свіжості. v28.8.0 додав середовище плагінів: підписані пакети від довірених видавців, явне підтвердження прав, API плагіна з обмеженими правами, підписані події, оновлення й відкат без перезапуску. v28.7.0 додав email-канал підтримки в Support Pro 3.7 (прийом IMAP без дублів, відповіді SMTP у ланцюжку листів, захист від автовідповідей і повернень, видалення даних і строк зберігання). v28.6.0 додав віджет підписки на робочий стіл Android і кілька профілів магазинів в адмін-застосунках Android та iOS. v28.5.0 додав нативні push-сповіщення в застосунки Android та iOS (FCM HTTP v1 і APNs, токен прив'язаний до сесії входу й відкликається при виході). v28.4.0 переніс адмінку, кабінет і Telegram Mini App на Next.js у дизайні Remna Dark, додав звірений імпорт історії підписок і платежів із відкатом та API профілю клієнта. v28.3.0 додав 96 типізованих live-налаштувань із шифруванням секретів, staged apply, аудитом, збіжністю процесів і rollback; restart-bound поля та 2 workflow-поля класифіковані окремо.

Справжні платежі залишаються закритими до завершення application E2E v2. Повне перенесення функцій та підписані APK/IPA ще не завершено. Stable визначає канал поточного ядра.

Для локального тесту клонуйте тег `v28.14.0` і виконайте `bash scripts/test-up.sh`. Loopback-порти: API 18080, адмінка 18081, кабінет 18082, Mini App 18083. Sandbox-підписка не створює VPN-тунель.

Нова установка через root SSH/Termius:

```bash
curl -fsSL https://raw.githubusercontent.com/booarkz-cpu/shop-by-boo/v28.14.0/install.sh -o /root/shop-install.sh && BRANCH=v28.14.0 bash /root/shop-install.sh
```

Для чинного магазину використовуйте регламент оновлення, збережіть секрети й перевірте узгоджену копію.
