# Що нового у v28.45.0

- **Код кас.** Кожна каса має окремий модуль у `backend/app/gateways/`. Таблиця можливостей `GATEWAYS` зберігає для кожної каси ключі, підпис сповіщень, повторну перевірку, повернення й автоплатежі.
- **Здоров'я кас.**
  - Раз на 6 годин магазин робить у кожній налаштованій касі одну перевірочну операцію, гроші при цьому не рухаються.
  - Каса, яка двічі поспіль не відповіла, виходить із черги, а оператор отримує сповіщення. Коли перевірка знову проходить, каса повертається в чергу сама.
  - Звіт показує оплати, про які каса не надіслала сповіщення.
  - «Найкраща каса перша»: черга впорядковується за конверсією.
- **Workflow «Payments acceptance».** Для кожної каси з ключами в секретах GitHub він проходить перевірку, створює сторінку оплати на 10 ₽ і читає її статус «не оплачено». Без руху грошей.
