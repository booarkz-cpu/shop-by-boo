# Що нового у v28.38.0

Функції [remnawave-subscription-middleware](https://github.com/Mrvibecodic/remnawave-subscription-middleware), реалізовані всередині магазину (у проєкту немає файлу ліцензії, тому код не копіювався). Head міграцій: `0081_subscription_proxy` (лише нові таблиці). Застосунки: 3.4.0 (збірка 3400). Докладно: [subscription_proxy](../modules/subscription_proxy.md), звірка: [MIDDLEWARE_RECONCILIATION](../ru/MIDDLEWARE_RECONCILIATION.md).

## Прошарок підписки
Клієнти оновлюють підписку через ваш домен (`SUB_PROXY_DOMAINS` або `https://<API_DOMAIN>/sub/<shortUuid>`), магазин забирає її з внутрішньої адреси панелі. Посилання панелі продовжує працювати.
Кабінет, Mini App, бот, застосунки й реселери показують посилання дзеркала. Прошарок додає:
- блокування пристрою за HWID із заглушкою та HWID з User-Agent;
- правила заголовків за застосунком (кирилиця — як `base64:`);
- додаткові ключі для скваду й злиття з другою підпискою — лише для активних підписок і списків посилань;
- нейтральну сторінку для сканерів;
- журнал запитів (14 днів) і каталог версій клієнтів із позначкою «застарів».

## Вебхуки та журнал змін
Вебхуки панелі пересилаються на кілька адрес, кожна отримує власний підпис. «Хто змінював користувача» фіксує зміни полів із позначкою «магазин» або «ззовні», CSV можна знеособити. На дашборді є стрічка подій підписок, а «Запити до панелі» показують виклики API магазином за джерелами.

## Клієнти й тарифи
- Строк із першого підключення.
- Пільговий доступ в обмеженому скваді.
- Сесії та аномалії за IP, провайдерами й країнами, «Зараз онлайн», скидання з’єднань, географія клієнтів.
- Трафік за днями й серверами в адмінці, кабінеті, Mini App і застосунках.
- Пул WireGuard / AmneziaWG, ключі підключення з QR, команда бота `/keys`.

## Сервери й експлуатація
- Повний редактор хостів і сквадів (перевірено на живій панелі в CI).
- Rich-сповіщення в Telegram.
- Поріг подій торентів за годину.
- Оператор для iOS — за ASN зовнішнього IP.
- Заголовки безпеки на тестовому стенді для ZAP.

## Каси
CloudPayments і Lava (картки, СБП): сповіщення приймається лише з правильним підписом і після повторної перевірки статусу через API каси; обидві входять у чергу кас і способи оплати. Ключі: `CLOUDPAYMENTS_*`, `LAVA_*`.
