# Посібники VPN Shop by Corgi Lucy

[Русский](../ru/README.md) · [English](../en/README.md) · **Українська**

Ці посібники допоможуть розгорнути магазин на новому VPS або виконати потрібну операцію в уже встановленому магазині.

## Завантажити мобільні застосунки

[Оберіть і завантажте застосунок](../../README.uk.md#завантажити-мобільні-застосунки). Для Android доступні магазин, окремий VPN-клієнт і Lucy Admin. Для магазину й Lucy Admin на iOS є IPA для підписання та ZIP для симулятора. Біля кожного файлу є посилання на його контрольну суму SHA-256.

Для локальної перевірки встановіть Docker і Compose, перейдіть до каталогу вихідного коду опублікованого тегу та виконайте `bash scripts/test-up.sh`. Сервіси доступні на `127.0.0.1`. API використовує порт `18080`, Lucy Admin — `18081`, кабінет — `18082`, Mini App — `18083`. Локальний магазин працює з тестовими платежами.
