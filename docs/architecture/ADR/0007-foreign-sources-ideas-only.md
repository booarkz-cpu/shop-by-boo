# 0007. Из чужих проектов берутся только идеи, код пишется свой

- Дата: 2026-11-14
- Статус: принято
- Решения владельца № 13 и 21. Перечень источников: [REFERENCE_REPOSITORIES.md](../../REFERENCE_REPOSITORIES.md).

## Контекст

Для функций магазина владелец указал образцы: remnawave-admin и bedolaga-cabinet (AGPL-3.0), bedolaga-bot
(Commons Clause), проекты без лицензии, StepBot (MIT). Код магазина распространяется под своей лицензией.

## Варианты

1. **Копировать код с соблюдением лицензий.** Для AGPL-3.0 это меняет лицензию всего магазина; Commons Clause
   запрещает продажу; без лицензии копировать нельзя вовсе.
2. **Копировать только MIT-код** с сохранением copyright. Законно, но в репозитории появляется чужой код другого стиля.
3. **Только идеи.** Функции сверяются с образцом по описанию и поведению и пишутся заново.

## Решение

Вариант 3 для всех источников, в том числе для StepBot под MIT (так решил владелец). Сверка ведётся по списку модулей
и маршрутов, а не поиском по ключевым словам: поиск по словам однажды ошибочно показал пять «отсутствующих» функций.

## Последствия

- Лицензия магазина не меняется, в репозитории нет чужих файлов.
- Работы больше: каждую функцию нужно спроектировать и проверить самим.
- В документах указывается, у какого проекта взята идея.

## Риски

- Похожий код может появиться случайно. Ревью сверяет только поведение, а не текст образца.

## Обратимость

Полная: решение касается только того, как пишется новый код.
