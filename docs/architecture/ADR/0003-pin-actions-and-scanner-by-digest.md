# 0003. Действия CI и сканер закреплены по хешу

- Дата: 2026-11-11
- Статус: принято
- Выпуски: v28.122.0, v28.123.0. Требования: `REQ-CI-0009`, `REQ-SEC-0010`.

## Контекст

Действия GitHub Actions вызывались по тегу версии. Тег можно передвинуть на другой код, и CI с доступом к секретам выполнит его.

## Варианты

1. **Оставить теги.** Обновления приходят сами. Риск подмены кода остаётся.
2. **Закрепить по хешу коммита**, версию держать в комментарии. Подмена невозможна. Обновлять нужно явно.

## Решение

Вариант 2 для всех действий и для образа сканера Trivy. Обновляет хеши Dependabot. Тесты
`test_every_action_is_pinned_to_a_commit` и `test_security_scanners_block_the_merge` не дают добавить вызов по тегу.

## Последствия

- Что выполняется в CI, определено однозначно.
- Исправления в действиях приходят только через pull request от Dependabot.

## Риски

- Если Dependabot выключен, действия устаревают незаметно.

## Обратимость

Полная: заменить хеши на теги и убрать тесты.
