# 0006. Папки перекладываются по этапам, старые пути остаются переходниками

- Дата: 2026-11-14
- Статус: принято
- Решения владельца № 14, 17, 23. Выпуски: v28.149.0 (этап 1) … v28.158.0 (этап 5). План: [MONOREPO_LAYOUT.md](../../MONOREPO_LAYOUT.md).

## Контекст

Мастер-промпт задаёт структуру `apps/`, `services/`, `packages/`, `infrastructure/`. Код лежал в корне (`backend/`,
`support-pro/`, `deploy/`, `admin/`, `cabinet/`…). Установленные серверы обновляются сами: агент обновления и `update.sh`
прежних выпусков ищут файлы по старым путям.

## Варианты

1. **Одним выпуском.** Быстро, но ломает обновление серверов со старым агентом и сразу все сборки CI.
2. **Не перекладывать.** Ничего не ломается, но структура расходится с промптом и документами.
3. **По этапам, со старыми путями как переходниками.** Каждый этап — отдельный выпуск с полным CI; по старому пути
   остаётся то, что читают установленные серверы.

## Решение

Вариант 3. Пять этапов: клиент; приложения магазина и администратора; веб-панель, кабинет и Mini App; `infrastructure/`;
`services/`. После этапа 4 в `deploy/` остались пять скриптов, которые вызывают новые. После этапа 5 по пути
`backend/app/main.py` лежит только номер версии: агент обновления прежних выпусков читает из него установленную версию
и принимает архив, только если файл в нём есть. Секреты Support Pro остаются в `support-pro/.env` на сервере.

## Последствия

- Агент обновления и `update.sh` понимают обе раскладки; откат на снимок со старой раскладкой работает.
- Файл версии по старому пути сверяется тестом и `check-current-docs.py`: он обязан совпадать с версией API.
- Замена путей по всему репозиторию задевает строки, которые только похожи на путь: маршруты API, адреса чужих проектов.
  Тест `tests/test_layout_stage5.py` проверяет, что такие строки не изменились.

## Риски

- Обновление настоящего сервера со старой раскладки не проверено: VPS нет (O1). Проверено тестами на модели дерева файлов.
- Убрать переходники можно только когда не останется серверов на выпусках до v28.154.0.

## Обратимость

Полная, но дорогая: обратный перенос — такой же выпуск с заменой путей и теми же переходниками.
