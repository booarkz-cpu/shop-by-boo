# 0005. В рабочих образах нет pip и setuptools

- Дата: 2026-11-12
- Статус: принято
- Выпуск: v28.123.0. Находка: F-003 в [SECURITY_FINDINGS.md](../../SECURITY_FINDINGS.md).

## Контекст

Сканирование образов нашло уязвимости во вложенных библиотеках pip и setuptools. Для работы магазина эти инструменты не нужны:
зависимости ставятся при сборке образа.

## Варианты

1. **Обновлять pip и setuptools при сборке.** Находки возвращаются с каждой новой уязвимостью во вложенных библиотеках.
2. **Удалять инструменты упаковки из готового образа.** Находок нет; в контейнере нельзя установить пакет.
3. **Сборка в два этапа** с переносом только установленных пакетов. Чище, но меняет все файлы сборки.

## Решение

Вариант 2: после установки зависимостей pip, setuptools и wheel удаляются. Пакеты системы обновляются при сборке.

## Последствия

- В работающем контейнере нельзя выполнить `pip install`. Отладочные зависимости нужно добавлять в образ.
- Сканирование образов в CI проходит без исключений для Python.

## Риски

- Библиотека, которой во время работы нужен `pkg_resources`, перестанет работать. Задача `containers` в CI запускает магазин из этих образов и ловит это.

## Обратимость

Полная: убрать одну команду из файлов сборки.
