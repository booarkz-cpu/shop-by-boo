# Полный план исполнения — VPN Shop by Corgi Lucy

Дистрибутив `v28.57.0`, runtime/API `21.5.1`, миграция магазина `0088_filter_and_regions`, Support Pro `0008`.

Документ составлен по master prompt V3. Каждая задача имеет ID, исходный раздел, критерии приёмки и
фактический статус. Статус задачи хранится в
[MASTER_EXECUTION_PROGRESS.md](MASTER_EXECUTION_PROGRESS.md); блокировки — в
[MASTER_EXECUTION_BLOCKERS.md](MASTER_EXECUTION_BLOCKERS.md); отчёты — в
[MASTER_EXECUTION_REPORTS.md](MASTER_EXECUTION_REPORTS.md).

## Правила ведения реестра

* `IMPLEMENTED` — код изменён и локальные проверки пройдены, но сценарий требует внешнего доступа и не
  воспроизведён end-to-end.
* `PASS` — выставлен только после фактически выполненной проверки с полученным результатом.
* `BLOCKED_SECRETS` / `BLOCKED_ACCESS` / `BLOCKED_PERMISSIONS` — точная причина и необходимое условие
  зафиксированы в файле блокировок.
* `NOT_APPLICABLE` — функциональность в проекте отсутствует (например, отдельного планировщика нет по
  архитектуре), а не «не проверялась».
