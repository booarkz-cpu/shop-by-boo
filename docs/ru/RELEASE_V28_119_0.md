# Релиз v28.119.0 — приложения магазина и администратора для Android находят обновление сами

Дистрибутив: `v28.119.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8.
Приложения Android и iOS: `3.6.0`.

Дата: 2026-11-11. Задача владельца: автоматическое обновление с GitHub всей экосистемы (этап 22, часть 2).

## Что изменилось

- **Приложение магазина** и **приложение администратора** для Android 3.6.0 раз в сутки при запуске проверяют последний выпуск на GitHub.
  - Если версия в выпуске новее, появляется окно «Доступна версия …».
  - «Обновить» открывает загрузку APK; установку подтверждает владелец телефона. Данные приложения сохраняются.
  - «Позже» откладывает эту версию: окно появится снова только для следующей.
- В каждом выпуске теперь лежат `corgi-lusi-android.json` и `corgi-lusi-android-admin.json`: номер версии, SHA-256 и адрес APK.
- Таблица «Вся экосистема» в разделе «Обновления» показывает у этих приложений «в приложении».

Подробно: [AUTO_UPDATE.md](../AUTO_UPDATE.md#10-вся-экосистема).

## Что защищает от подмены

- Адрес APK принимается только из выпусков этого репозитория и только с именем файла своего приложения.
- Android не установит APK с чужой подписью поверх приложения.
- Приложение, установленное из магазина приложений, GitHub не спрашивает: его обновляет магазин приложений.

## Чем проверено

- `AppUpdateTest` — разбор манифеста, отказ от чужого адреса, «раз в сутки», «Позже».
- `AdminScreensTest.updateManifestIsCheckedStrictly` — то же для приложения администратора, на эмуляторе.
- `tests/test_download_links.py` — сборка пишет манифесты, выпуск их публикует.

## Чего пока нет

- На настоящем телефоне переход между версиями не проверен: сравнивать пока не с чем, 3.6.0 — первая версия с проверкой.
  Версии 3.5.0 и старше новую версию не найдут: 3.6.0 на них ставится вручную один раз.
- Приложение не скачивает APK само, а открывает загрузку в браузере. Так ему не нужно разрешение на установку приложений.
- iOS: автообновления нет. В приложениях для iOS изменился только номер версии.

## Что нужно от владельца

Один раз установить приложения 3.6.0 вручную. Дальше они предложат обновление сами.
