# Выпуск v28.21.0 — движок автоматизации и аудит интеграций

Дистрибутив: `v28.21.0`. Runtime/API: `21.5.1`. Head магазина: `0074_automation_engine`. Support Pro: `0008` / 3.8. Дата и commit фиксируются тегом выпуска.

## Новое

- **Автоматизация работает.** Правила «событие → условия → действия» выполняет фоновый процесс каждые 5 минут ([модуль 25](modules/25-automation-jobs.md)). События: подписка скоро истекает, подписка истекла, оплата прошла, новый клиент, клиент без покупки N дней. Условия: дни, тарифы, сумма оплаты, лимит выполнений в сутки. Действия: уведомление в кабинете и Telegram, бонус на баланс (только администратор, запись `automation_bonus` в журнале). Каждое действие выполняется один раз на клиента и событие (таблица `automation_executions`), события до создания правила не затрагиваются. Кнопка «Проверить» показывает, сколько клиентов ждут выполнения.
- **Кампании отправляются.** Запланированная кампания в своё время уходит в очередь рассылок Telegram по сегменту (все, с активной подпиской, без подписки); счётчики берутся из рассылки.
- **Стартовые тарифы.** На пустой базе `PRICE_1/3/6/12` из `.env` превращаются в выключенные тарифы на 1, 3, 6 и 12 месяцев ([модуль 06](modules/06-plans.md)).
- **Возвраты из кабинета YooKassa.** Уведомление `refund.succeeded` перепроверяется через API; полный возврат отзывает доступ и записывается в финансовый журнал ([модуль 07](modules/07-payments.md)).

## Исправлено

- **Remnawave 3.x.** Ответы панели приходят в обёртке `{"response": …}` — раньше магазин читал идентификатор и срок пользователя как пустые, сохранял `None` как идентификатор и не видел узлов. Обёртка разворачивается, повреждённые идентификаторы лечатся при следующей выдаче. Лимит устройств тарифа теперь передаётся как `hwidDeviceLimit`.
- **Антиабуз.** «Ограничить» больше не отменяет подписки навсегда: они приостанавливаются и возвращаются кнопкой «Снять» ([модуль 19](modules/19-node-agent-antiabuse.md)). Исправлена ошибка `NameError` (не объявлен `logger`) в коде антиабуза.
- **Возвраты.** Сверенный возврат теперь пишет запись в финансовый журнал.
- **Бот.** `/buy` и `/promo` в группах не отправляют кнопки Mini App (Telegram отвечает `BUTTON_TYPE_INVALID`) и просят написать в личку; промокод проверяется; цены в валюте магазина; ответы Telegram 429 повторяются по `retry_after` до трёх раз.
- **Заглушки v16** (профиль туннеля, роуминг, регистрация узлов, failover) отвечают `410 Gone` вместо имитации успеха.

## Обновление

Миграция `0074_automation_engine` добавляет `automation_executions` и `subscriptions.suspended_from` и **выключает существующие правила автоматизации**: раньше они не выполнялись, теперь будут — проверьте каждое и включите вручную.

```bash
cd /opt/vpn-shop && bash scripts/backup.sh
sudo env APP_DIR=/opt/vpn-shop RELEASE_TAG=v28.21.0 bash /opt/vpn-shop/scripts/update-from-github.sh
```

В настройках HTTP-уведомлений YooKassa включите событие `refund.succeeded`.

Ожидаемые head: магазин `0074_automation_engine`, Support Pro `0008`.
