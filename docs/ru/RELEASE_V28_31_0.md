# Выпуск v28.31.0 — новые приложения Android и iOS 3.0.0, экраны и кнопки из админ-панели

Дистрибутив: `v28.31.0`. Runtime/API: `21.5.1`. Head магазина: `0076_growth` (без новых миграций). Support Pro: `0008` / 3.8. Мобильные приложения: 3.0.0. Дата и commit фиксируются тегом выпуска.

Полный список работ: [WORKLIST_V28_31_0.md](WORKLIST_V28_31_0.md).

## Что изменилось

**Приложения Android и iOS 3.0.0**

- Новый интерфейс в тёмной теме бренда: нижняя панель «Подписка · Премиум · VPN · Локации · Настройки», VPN в центре.
- Главный экран: статус, большая кнопка подключения, карточка тарифа и остатка трафика, карточка локации, кнопки раздела.
- Кнопка «Подключить» передаёт подписку установленному клиенту (Android: Happ, v2rayNG, Hiddify; iOS: Happ, v2RayTun, Streisand): первый раз импортирует, потом открывает клиент. Статус «VPN подключён» приложение берёт из сети телефона. Если клиента нет, показывает ссылки на магазин приложений.
- Экраны локаций (флаги, загрузка), тарифов (цена в месяц, скидка), подписки (ID, срок, устройства, трафик), устройств, семьи, рефералов, баланса, уведомлений, состояния сервиса, безопасности и своих страниц.
- Без изменений остались: защита сессии (Android Keystore, Keychain), PKCE, биометрия, push, виджет Android, passkeys.

**Все разделы и кнопки — из админ-панели**

- Новый раздел «Бот и кабинет → Приложения: экраны и кнопки». В нём настраиваются:
  - разделы: включение, нижняя панель, порядок, названия на ru/en/uk, подзаголовок, иконка, баннер;
  - кнопки каждого раздела: текст на трёх языках, одно из 27 действий, вид, иконка, видимость, кому показывать;
  - свои страницы, тексты интерфейса, цвета бренда, ссылки на личный кабинет и Telegram-канал.
- Рядом с редактором — предпросмотр телефона.
- Приложения получают макет из `GET /api/mobile/layout` при каждом открытии, с ETag. Изменения видны клиентам без обновления в сторе. Стандартный макет встроен в приложения, поэтому без сети экраны тоже работают.
- Проверки на стороне магазина: от 2 до 5 вкладок, раздел VPN всегда включён, ссылки только `https://` и `tg://`, кнопки открывают только существующие разделы.

**Документы и полное редактирование приложений**

- «Документы»: баннер каждого документа (FAQ, правила, политика, оферта) загружается, скрывается и сбрасывается прямо в редакторе; текст и баннер одновременно меняются в боте, Mini App, кабинете и приложениях (`banner` в `/api/public/info-pages`).
- Приложения: раздел «Информация» со списком документов, экран документа (заголовки, списки, FAQ), действие «Открыть документ».
- Макет: замена любой строки приложения на ru/en/uk и выключатели блоков главного экрана, входа и настроек.

**Баннеры разделов приложений**

- 15 тёмных баннеров `app-*` с корги Люси, отдельно для каждого раздела. Их собирает `scripts/bot-banners/render.py --app`.
- В «Баннерах бота» они собраны в отдельную группу: любой можно заменить своим изображением или скрыть.
- Стандартные баннеры встроены в приложения.

**Порядок в репозитории**

- 118 исторических документов из корня перенесены в `docs/archive/root/`, все ссылки на них обновлены.
- Проверки по тексту кода для чеков App Store и вебхуков Stripe/PayPal заменены поведенческими тестами.
- Из `main.py` вынесен раздел восстановления, возвратов и выплат: `recovery_api.py`, 3317 → 2866 строк.
- CI:
  - статический анализ `bandit`;
  - кэш зависимостей для e2e;
  - сводка ошибок e2e в аннотациях;
  - workflow «Mobile screenshots» по ручному запуску обновляет и коммитит все скриншоты.

## Обновление

Миграций нет.

```bash
cd /opt/vpn-shop && bash scripts/backup.sh
sudo env APP_DIR=/opt/vpn-shop RELEASE_TAG=v28.31.0 bash /opt/vpn-shop/scripts/update-from-github.sh
```

После обновления:

1. Откройте «Приложения: экраны и кнопки».
2. Укажите ссылки на личный кабинет и Telegram-канал: без них кнопки с этими ссылками не показываются.
3. Соберите и подпишите приложения 3.0.0 ([модуль 16](modules/16-mobile-apps.md)).
