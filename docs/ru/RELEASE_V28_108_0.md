# Выпуск v28.108.0 — «Корги Люси: клиент» 1.7.4: журнал сети

Дистрибутив: `v28.108.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8. «Корги Люси: клиент»: `1.7.4` (versionCode 174).

По промпту владельца (N12, фаза 2 «Live Network Log»): какие домены открывает телефон и куда они идут. Этим выпуском фаза 2 закрыта.

## Что нового

- **«Настройки» → «Журнал сети»**: каждое соединение — время, домен и порт и куда оно пошло: **через VPN**, **напрямую**, **в блок** (реклама, свои правила «block») или в **DNS**. Новые сверху, фильтры, поиск по домену; пока страница открыта — обновляется раз в 2 секунды.
- Запись включается переключателем «Записывать соединения» и работает со следующего подключения. Источник — журнал доступа Xray (`log.access`, `dnsLog`), он начинается заново при каждом подключении и не покидает телефон.
