# 16. Мобильные приложения

## Для чего

В репозитории есть исходники четырёх приложений:

| Приложение | Каталог |
| --- | --- |
| Android для клиентов | `mobile/android-user` |
| iOS для клиентов | `mobile/ios-user` |
| Android для администраторов | `mobile/android-admin` |
| iOS для администраторов | `mobile/ios-admin` |

Клиентское приложение 3.4.0 (Android и iOS) устроено так:

- нижняя панель «Подписка · Премиум · VPN · Локации · Настройки», VPN в центре;
- на главном экране — статус, большая кнопка «Подключить», карточка тарифа с остатком трафика и карточка локации;
- остальные экраны: тарифы, подписка, устройства, семья, рефералы, баланс, уведомления, состояние сервиса, безопасность и свои страницы.

Языки — русский, английский и украинский (`mobile/l10n/user.json` и тексты макета, по умолчанию — язык телефона). На Android есть виджет со статусом подписки. Вход возможен по ключу доступа (passkey).

**Подключение.**

- **Android со встроенным VPN** (сборки «Mobile packages» и `assembleDebug` после `scripts/mobile/build-xray-aar.sh`). Кнопка «Подключить» поднимает туннель прямо в приложении на Xray-core: Android спрашивает разрешение на VPN один раз. Серверы берутся из подписки клиента. В настройках:
  - «Встроенный VPN» — включить или перейти на приложение-клиент;
  - «Сервер VPN» — «Авто» (самый быстрый, с переключением при сбое) или конкретный сервер;
  - «Что работает без VPN» — приложения и российские сайты, которые идут напрямую.
  
  В шторке держится уведомление с кнопкой «Отключить».
  
  На Xiaomi, Samsung, Huawei, OPPO, vivo и других прошивках, которые останавливают VPN в фоне, после первого подключения приложение один раз за версию покажет подсказку «VPN может отключаться в фоне» с кнопками «Без ограничений батареи», «Автозапуск и работа в фоне» и инструкцией для телефона.
- **iOS со встроенным VPN** (сборка владельца с разрешением Network Extension, см. «Сборка»). «Подключить» запускает расширение `CorgiTunnel` на Xray-core: iOS один раз спрашивает разрешение добавить конфигурацию VPN. Серверы — из подписки, «Авто» или выбранный сервер, российские сайты по желанию напрямую.
- **Без встроенного движка** туннель держит сторонний клиент: на Android — Happ, v2rayNG или Hiddify, на iOS — Happ, v2RayTun или Streisand. Первое нажатие импортирует подписку в клиент, следующие открывают его. Если клиента нет, приложение показывает ссылки на магазин приложений.

Статус «VPN подключён» берётся из сети телефона: любой поднятый VPN-туннель считается подключением.

**Вход.** Адрес магазина можно вшить в сборку (`-Pcorgi.shop_url=…` / `CORGI_SHOP_URL`): поле адреса на экране входа исчезает. Способы входа:
- одноразовая ссылка `corgi://login` из бота (`/app`) или кабинета («Безопасность → Войти в приложение»);
- Telegram, Яндекс ID, VK ID, Google — показываются только настроенные в магазине;
- почта и пароль, ключ доступа.

**Push.** Внешний вид уведомлений задаётся в «Приложения: стиль push-уведомлений»: картинка, кнопки, раздел по нажатию, группа Android и звук. Android рисует уведомление с большой картинкой и кнопками, iOS — с кнопками, а в сборке с расширением `CorgiNotificationService` — и с картинкой.

**После оплаты.** Оплата, начатая в приложении, возвращает клиента в приложение (`/api/app/paid` → `corgi://payment`): приложение показывает, прошла ли оплата, и обновляет подписку.

**Розыгрыши.** Раздел «Розыгрыши и бонусы» показывает акции из «Розыгрышей». Пока есть открытая акция, на главном экране висит её баннер.

**Экраны и кнопки задаёт магазин.** Приложения рисуют каждый раздел, кнопку, баннер, текст и цвет по макету из `GET /api/mobile/layout`, а макет редактируется в админ-панели (см. ниже). Изменения видны клиентам при следующем открытии приложения, без обновления в сторе. Стандартный макет и баннеры встроены в приложение, поэтому экраны работают и без сети.

Готовых подписанных APK/IPA в выпуске нет: каждый владелец собирает и подписывает приложения своими ключами. Файл `mobile-production-status.json` в выпуске GitHub показывает фактический статус сборок.

## Экраны и кнопки приложений

**Разделы.** У каждого раздела настраиваются:

- включён или выключен;
- показывается ли он в нижней панели (2–5 вкладок);
- порядок (стрелки ↑ ↓);
- название и подзаголовок на русском, английском и украинском;
- иконка и баннер.

Раздел VPN выключить нельзя. Кнопка «Добавить свою страницу» создаёт раздел с баннером, текстом и кнопками: например, для акции или инструкции.

**Кнопки.** У каждой кнопки любого раздела настраиваются:

- текст на трёх языках;
- действие;
- вид: главная, акцент, обычная, тихая, опасная;
- иконка и видимость;
- кому показывать: всем, только с подпиской или только без подписки.

Действия кнопок (30):

| Действие | Что делает |
| --- | --- |
| Подключить | Импорт подписки в VPN-клиент или открыть клиент |
| Открыть документ | Частые вопросы, правила, политика конфиденциальности, оферта |
| Открыть раздел / ссылку | Переход в раздел приложения или по ссылке `https://`, `tg://` |
| Личный кабинет, Telegram-канал | Ссылки из настроек макета; пока ссылка не задана, кнопка скрыта |
| Добавить в Happ / v2rayNG / Hiddify / Streisand | Импорт подписки в выбранный клиент |
| QR-код, скопировать ссылку подписки, скопировать ID | Для подключения другого устройства и обращения в поддержку |
| Оплатить, оплатить с баланса, пробный период, пополнить, промокод | Покупка и баланс |
| Поделиться / скопировать реферальную ссылку, пригласить в семью | Рост |
| Написать в поддержку, сообщить о проблеме | Обращение; к отчёту о проблеме приложение добавляет свою версию и состояние VPN |
| Язык, push, виджет, ключ входа, обновить, выйти | Настройки |
| Встроенный VPN, сервер VPN, что работает без VPN | Только Android со встроенным движком; в остальных сборках кнопки скрыты |

**Строки приложения.** Любую надпись приложения (около 170: экран входа, диалоги, уведомления, ошибки, подписи кнопок входа) можно заменить на русском, английском и украинском. Найдите строку поиском по тексту или ключу и впишите свой вариант. Пустой язык оставляет текст приложения: английская версия не покажет русскую замену.

**Блоки экранов.** Выключатели: кнопки поддержки и уведомлений в шапке, статус VPN, карточки тарифа и локации на главном экране, баннер, регистрация, вход по ключу и переключатель языка на экране входа, версия в настройках.

**Документы.** Действие кнопки «Открыть документ» показывает частые вопросы, правила, политику конфиденциальности или оферту из «Бот и кабинет → Документы» с их баннером; раздел «Информация» показывает список всех опубликованных документов ([модуль 13](13-content-pages.md#документы-вопросы-правила-политика-оферта)).

**Тексты, цвета и ссылки.** Можно задать:

- название бренда в шапке;
- статусы VPN («VPN отключён», «VPN подключён»);
- подписи карточек, текст согласия с офертой;
- цвета бренда (акцент, фон, карточки, текст), скругление углов;
- ссылки на личный кабинет и Telegram-канал.

Пустое поле текста означает стандартный текст.

**Баннеры.** Для каждого раздела выбирается баннер из реестра «Баннеров бота». Можно указать ссылку, которая открывается по нажатию на баннер. Стандартные баннеры `app-*` тёмные, 1280×512, с корги Люси; любой заменяется своим изображением в «Баннерах бота». Чтобы баннеры отображались без обрезки, загружайте картинки 2.5:1. Общий выключатель баннеров приложений находится в макете и не зависит от выключателя баннеров бота.

**Перенос между магазинами.** Блок «Макет в JSON» — копия всего макета. Вставьте её в другом магазине и нажмите «Сохранить JSON». «Вернуть стандартный макет» сбрасывает все изменения.

Магазин проверяет макет при сохранении:

- ссылки только `https://` и `tg://`;
- кнопка «Открыть раздел» ведёт только на существующий раздел;
- неизвестные баннеры и действия отклоняются.

Если сохранённый макет повреждён, приложения показывают стандартный.

## Сборка

**Адрес магазина.** Приложение спрашивает «Адрес API» при первом входе. Клиент вводит `https://api.ДОМЕН`. Пересобирать приложение под каждый магазин не нужно, но распространять его вы будете под своей подписью.

**Android** (Linux/macOS, Android SDK 35, JDK):

```bash
export ANDROID_HOME=$HOME/android-sdk
# release-подпись своим ключом; без ANDROID_KEYSTORE собирается debug
export ANDROID_KEYSTORE=/secure/release.jks ANDROID_KEYSTORE_PASSWORD=... ANDROID_KEY_ALIAS=... ANDROID_KEY_PASSWORD=...
bash scripts/build-android-apk.sh "$PWD/dist/mobile"
```

Для push передайте данные Android-приложения своего Firebase-проекта переменными `CORGI_FIREBASE_APP_ID`, `CORGI_FIREBASE_API_KEY`, `CORGI_FIREBASE_PROJECT_ID`, `CORGI_FIREBASE_SENDER_ID` (или свойствами Gradle `corgi.firebase.*`) — [модуль 12](12-notifications-push.md). Debug-сборка получает пакет `shop.remnawave.user.preview`.

**iOS** (macOS, Xcode): подпись профилем своего Apple Developer-аккаунта:

```bash
CORGI_ASSOCIATED_DOMAIN=cabinet.ДОМЕН bash scripts/build-ios-signed.sh "$PWD/dist/mobile"
```

`CORGI_ASSOCIATED_DOMAIN` нужен для ключей доступа. В App ID включите Associated Domains и Push Notifications.

**Встроенный VPN и push с картинками на iOS.** Оба расширения лежат в проекте, но встраиваются только в сборку владельца, чтобы не ломать обычную подпись:

1. В Apple Developer запросите для команды Network Extension и создайте App ID `shop.remnawave.user.tunnel` (Network Extension → Packet Tunnel, App Group `group.shop.remnawave.user`) и `shop.remnawave.user.push`; у основного App ID включите ту же App Group и Network Extension.
2. Профили обоих расширений сохраните в секретах `IOS_USER_TUNNEL_PROFILE_BASE64` и `IOS_USER_PUSH_PROFILE_BASE64` (можно только один из них).
3. «Mobile packages» соберёт движок (`scripts/ios/build-tunnel-frameworks.sh`), включит расширения (`scripts/ios/enable-extensions.py`) и подпишет каждое своим профилем. Локально: `bash scripts/ios/build-tunnel-frameworks.sh && python3 scripts/ios/enable-extensions.py --tunnel --push`.

Без этих профилей приложение собирается как раньше и подключается через Happ или v2RayTun.

Ключи подписи и профили храните вне репозитория, не коммитьте их.

## Скриншоты

Workflow **Mobile screenshots** (`.github/workflows/mobile-screenshots.yml`) запускается вручную (Actions → Run workflow) и в PR, которые меняют клиентские приложения.

1. Собирает отладочные версии клиентских приложений.
2. Запускает их в эмуляторе Android и симуляторе iPhone в демо-режиме.
3. Снимает экраны всех вкладок, экраны «Устройства», «Семья» и «Состояние сервиса», главный экран с подключённым VPN и английскую версию.
4. Выкладывает снимки как артефакты `mobile-screenshots-android` и `mobile-screenshots-ios` на странице запуска.
5. При ручном запуске с отметкой «commit» снимает ещё все разделы админ-панели и кабинета, обновляет раздел «Скриншоты» в README и коммитит картинки в тег `screenshots-<номер запуска>` (`screenshots/mobile`, `screenshots/admin_panel`, `screenshots/storefront_user`, README); в ветку их переносит владелец: `git fetch origin tag screenshots-N && git checkout screenshots-N -- screenshots README.md`. Пушить в ветки напрямую workflow не может: так настроены правила репозитория.

Демо-режим есть только в отладочных сборках. На Android его включает `--ez corgi_demo true` (раздел — `--es corgi_tab vpn|subscription|premium|…`, язык — `--es corgi_lang`, подключённый VPN — `--ez corgi_vpn_on true`), на iOS — `-CorgiDemo` (раздел — `-CorgiTab`, подключённый VPN — `-CorgiVpnOn`). В этом режиме данные фиксированы, сеть не используется, сессия не сохраняется. На Android в демо-режиме снят запрет снимков экрана (`FLAG_SECURE`), в рабочих сборках он действует как раньше.

## Публикация

1. **Android и iOS** → карточка «Покупатель»: включите «Показывать», заполните названия и тексты на двух языках.
2. Загрузите файл (APK) или укажите HTTPS-ссылку на стор или TestFlight.
3. «Сохранить приложения». Кабинет показывает карточку и контрольную сумму файла.
4. Загрузка IPA его не подписывает: распространять iOS-приложение можно только подписанным.

## Ключи доступа в приложениях

В `.env`:

```dotenv
CUSTOMER_WEBAUTHN_ORIGIN=https://cabinet.ДОМЕН
ANDROID_USER_PACKAGE=shop.remnawave.user
ANDROID_USER_CERT_SHA256=AB:CD:...:EF        # отпечаток ключа подписи; при Google Play — ключ Play App Signing
IOS_USER_APP_ID=TEAMID.shop.remnawave.user   # пусто — из APNS_TEAM_ID и APNS_BUNDLE_ID
```

Отпечаток своего ключа: `keytool -list -v -keystore release.jks -alias ALIAS | grep SHA256`.

После перезапуска backend кабинет отдаёт `/.well-known/assetlinks.json` и `/.well-known/apple-app-site-association`. Функция `passkeys` должна быть включена.

## Семья и статус сервиса

- Раздел **«Семья»**:
  - владелец видит занятые места, создаёт приглашение и делится ссылкой на бота, убирает участников;
  - участник видит владельца и срок, может выйти;
  - любой клиент присоединяется по коду приглашения.

  Работает через те же `/api/me/family/*`, что и кабинет ([семейная подписка](06-plans.md#семейная-подписка)).
- Раздел **«Состояние сервиса»**: общий статус, серверы онлайн по странам, компоненты и текущие проблемы (`GET /api/public/service-status`).
- Подписка за Telegram Stars оформляется и отменяется только в Telegram, приложение лишь напоминает об этом. Встроенная оплата Apple и Google не используется.
- Если магазин старше v28.25.0, эти разделы пустые, остальные работают как раньше. Если магазин старше v28.45.0 (нет `/api/mobile/layout`), приложение показывает встроенный стандартный макет.

В магазинах приложения называются «Corgi Lusi» и «Corgi Lusi Admin»; на телефоне название показывается на языке системы («Корги Люси», «Коргі Люсі»).

## Виджет Android

Клиент добавляет виджет «VPN Shop» на рабочий стол и включает его кнопкой «Виджет на главный экран» в «Настройках» приложения. На виджете видны:

- название тарифа и состояние подписки;
- дата окончания;
- остаток трафика;
- число непрочитанных уведомлений.

Ссылка подписки, балансы и email на виджет никогда не попадают. Обновление — раз в 30 минут.

## Проверка

1. Установите собранное приложение, введите `https://api.ДОМЕН`, войдите тестовым клиентом: видны подписка и тарифы.
2. Проверьте доступность файлов привязки:
   - `curl -fsS https://cabinet.ДОМЕН/.well-known/assetlinks.json`;
   - `curl -fsS https://cabinet.ДОМЕН/.well-known/apple-app-site-association`.
3. Добавьте ключ доступа и войдите им.
4. Включите push и получите тестовое уведомление.

## Проблемы

| Симптом | Причина | Что делать |
| --- | --- | --- |
| «Не удалось подключиться» к API | Неверный адрес или нет HTTPS | Вводите `https://api.ДОМЕН` |
| Вход по ключу: «не настроено» (503) | Пустые `ANDROID_USER_CERT_SHA256` / `IOS_USER_APP_ID` | Задайте и перезапустите backend |
| На Android ключ не находится | Отпечаток не совпадает с ключом, которым подписано приложение | Возьмите отпечаток ключа Play App Signing, если подписывает Google |
| Оплата в приложении | Встроенная оплата Apple и Google отключена (410) | Оплата идёт через платёжных агентов магазина |
| «Подключить» открывает окно «Установите VPN-клиент» | На телефоне нет поддерживаемого клиента | Установите Happ (или v2rayNG/Hiddify на Android, v2RayTun на iOS) и нажмите ещё раз |
| Кнопки «Личный кабинет» или «Telegram-канал» не видны | В макете не заданы ссылки | Заполните их в «Приложения: экраны и кнопки → Цвета, ссылки и баннеры» |
| Изменения макета не видны в приложении | Приложение обновляет макет при открытии | Закройте и откройте приложение; проверьте `curl -fsS https://api.ДОМЕН/api/mobile/layout` |

## API

`GET|PUT|DELETE /api/admin/mobile-layout`, `GET|PUT /api/admin/apps`, `POST|DELETE /api/admin/apps/{id}/file`, `POST|DELETE /api/admin/apps/logo`, `GET /api/admin/mobile/ops`. Клиент: `GET /api/mobile/layout?lang=ru|en|uk` (без входа, ETag), `POST /api/auth/mobile/token`, `GET /api/me/widget`, `GET /api/me/family`, `POST /api/me/family/join`, `POST /api/me/family/{subscription_id}/invite`, `DELETE /api/me/family/members/{id}`, `GET /api/public/service-status`, `/.well-known/assetlinks.json`, `/.well-known/apple-app-site-association`.
