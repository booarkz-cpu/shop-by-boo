# 15. Личный кабинет

## Для чего

Веб-кабинет клиента `https://cabinet.ДОМЕН` и его версия в Telegram (Mini App). В нём клиент:

- смотрит подписки, остаток трафика и срок;
- копирует ссылку подписки или сканирует QR-код;
- покупает и продлевает подписку, меняет тариф, докупает трафик;
- пользуется кошельком, видит историю платежей;
- активирует и покупает подарки;
- приглашает друзей;
- управляет устройствами;
- пишет в поддержку;
- отвечает на опросы и участвует в конкурсах;
- настраивает безопасность: ключи доступа, сессии, удаление аккаунта, объединение аккаунтов.

## Где и кто

| Раздел | Что делает | Права |
| --- | --- | --- |
| **Бот и кабинет → Личный кабинет** | Вкладки кабинета: название, адрес (slug), тип, порядок, содержимое произвольной вкладки; инструкции подключения для Android, iOS, TV, Windows, macOS и Linux | `manage_content` (оператор, администратор) |

## Способы входа

| Способ | Что нужно |
| --- | --- |
| Email и пароль | Рабочий SMTP: письмо подтверждения и восстановления пароля ([модуль 26](26-mail.md)); `CABINET_URL` с HTTPS |
| Telegram | Открыть кабинет как Mini App из бота: вход по данным Telegram |
| Yandex ID | Приложение на oauth.yandex.ru с redirect `https://api.ДОМЕН/api/auth/yandex/callback`; `YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET`, `YANDEX_REDIRECT_URI` |
| VK ID | Приложение VK ID с redirect `https://api.ДОМЕН/api/auth/vk/callback`; `VK_CLIENT_ID`, `VK_CLIENT_SECRET`, `VK_REDIRECT_URI` |
| Ключ доступа (passkey) | `CUSTOMER_WEBAUTHN_ORIGIN=https://cabinet.ДОМЕН` (без пути и `/` в конце) и включённая функция `passkeys` в **Система → Функции и модули** |

После изменения `.env`: `docker compose up -d --force-recreate backend`. Пустые значения OAuth выключают соответствующую кнопку входа.

## Настройка вкладок

1. **Личный кабинет** → «Вкладки кабинета». Типы вкладок:
   - обзор, тарифы, пробный период, подключение;
   - поддержка, серверы, кошелёк, история платежей;
   - подарки, рефералы, подписка, безопасность;
   - уведомления, устройства, опросы, конкурсы и призы;
   - партнёрский кабинет;
   - произвольная.
2. «Название вкладки», «Адрес вкладки (slug)», «Тип», «Порядок» → «Добавить вкладку». Для произвольной заполните «Содержимое вкладки» — текст или безопасный HTML: скрипты не выполняются.
3. Основные системные вкладки добавляются автоматически, даже если меню сохранено в старой версии. Дубли объединяются.
4. Вкладка — это навигация, а не защита: права и бизнес-ограничения проверяет сервер.

## Инструкции подключения

**Инструкции по устройствам** — тексты для Android, iOS, TV, Windows, macOS и Linux. Клиент видит их во вкладке «Подключение» рядом со ссылкой подписки и QR-кодом. Укажите рекомендуемые VPN-клиенты, совместимые с вашими протоколами Remnawave, и шаги импорта ссылки.

## Безопасность аккаунта клиента

- **Подтверждение email и восстановление пароля** — одноразовые ссылки с ограниченным сроком. При смене пароля отзываются сессии.
- **Ключи доступа** — вход по биометрии или PIN устройства; регистрация требует подтверждения входом.
- **Сессии** — клиент видит и завершает свои входы.
- **Объединение аккаунтов** — клиент подтверждает оба аккаунта, видит конфликты и подтверждает перенос подписок, платежей и баланса в один аккаунт ([регламент](../ACCOUNT_MERGE_CURRENT.md)).
- **Удаление аккаунта** — обезличивание. Недоступно, пока есть действующая подписка, незавершённая покупка или ненулевой партнёрский баланс.

## Проверка

1. Зарегистрируйтесь по email, подтвердите адрес по письму, войдите.
2. Получите пробный период, откройте «Подключение»: ссылка и QR-код есть, инструкция для вашей платформы показана.
3. Если включён Yandex или VK — войдите через него.
4. Добавьте ключ доступа и войдите им.

## Проблемы

| Симптом | Причина | Что делать |
| --- | --- | --- |
| Письмо подтверждения не приходит | SMTP не настроен или письмо в «Спаме» | [Модуль 26](26-mail.md) |
| OAuth: «redirect_uri mismatch» | URI в приложении провайдера не совпадает с `*_REDIRECT_URI` | Сделайте их одинаковыми |
| Ключ доступа: ошибка origin | `CUSTOMER_WEBAUTHN_ORIGIN` не совпадает с адресом страницы | Точный `https://cabinet.ДОМЕН` |
| Вход сбрасывается | `COOKIE_SECURE=true` при открытии по HTTP | Открывайте только по HTTPS |

## API

Админка: `/api/admin/cabinet/menu`, `/api/admin/cabinet/guides/{platform}`. Клиент: `/api/auth/register|login|logout`, `/api/auth/yandex`, `/api/auth/vk`, `/api/auth/telegram`, `/api/me/...`.
