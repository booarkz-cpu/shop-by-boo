# 08. Подарки

## Для чего

Подарочный код даёт подписку по тарифу на заданный срок без оплаты. Коды создаёт администратор: для акций, компенсаций, партнёров, первых клиентов. Клиенты сами покупают подарки с баланса кошелька и передают код другому человеку.

Подарочные коды работают независимо от платёжных систем: так можно выдать платный доступ без оплаты, например партнёрам или при остановленном приёме платежей.

## Где и кто

| Раздел | Что делает | Права |
| --- | --- | --- |
| **Тарифы и оплата → Подарки** | Создать код: код, ID тарифа, срок в днях, число активаций; список кодов с использованием и статусом | просмотр `marketing.read`, создание `manage_marketing` (оператор, администратор) |
| Кабинет клиента → «Подарки» | Активировать код, купить подарок с баланса, «Мои подарки» | клиент |

## Настройка и создание кода

1. Узнайте ID тарифа: он указан на карточке в **Тарифы**. Тариф должен быть в продаже и с профилем Remnawave ([модуль 06](06-plans.md)).
2. **Подарки** → заполните поля:
   - «Код» — например `GIFT2026`. Сохраняется заглавными буквами и должен быть уникальным;
   - «ID тарифа»;
   - «Срок, дней»;
   - «Число активаций»: 1 — личный код, больше — общий код для акции.
3. «Создать». Код появится в списке «Коды» со статусом «активен».

Код передавайте получателю лично. Не публикуйте его в общих чатах и журналах: тот, кто первым введёт код, получит подписку.

## Работа

- **Клиент активирует код** в кабинете или Mini App («Подарки» → ввести код). Подписка создаётся или продлевается на срок кода с лимитами тарифа.
- **Повторная активация** тем же клиентом доступ второй раз не выдаёт.
- **Клиент покупает подарок:** пополненный кошелёк → «Тарифы» → «Купить в подарок с баланса» → код появляется в «Моих подарках». Сумма и набор опций фиксируются при покупке.
- **Ошибка при активации («ожидает проверки»).** Попросите клиента ввести тот же код ещё раз: срок уже закреплён за активацией, повтор не добавит лишних дней. Второй код для обхода ошибки не создавайте.

## Проверка

Создайте код на 1 активацию и 7 дней, активируйте его тестовым клиентом. Должно получиться:

- в **Подарках** — «Использовано 1»;
- у клиента — подписка на 7 дней;
- в Remnawave — пользователь с правильным сроком и squad.

## Проблемы

| Симптом | Причина | Что делать |
| --- | --- | --- |
| «Код не найден» | Опечатка или код выключен | Проверьте список кодов |
| «Plan not found or disabled» при создании | Тариф скрыт или неверный ID | Верните тариф в продажу или исправьте ID |
| «Gift code already exists» | Такой код уже есть | Задайте другой код |
| «Лимит активаций исчерпан» | Использованы все активации | Создайте новый код |
| Подписка без серверов | У тарифа нет профиля Remnawave | Задайте профиль, затем повторите выдачу в **Очереди задач** |
| Покупка подарка: «технический режим» | Включён технический режим | [Модуль 30](30-backups-recovery.md) |

## API

`GET|POST /api/admin/gifts`. Финансовые подарочные карты: `GET /api/admin/payments/gift-cards`, `POST /api/admin/payment/gift-cards`. Клиент: `/api/me/gifts/...`.
