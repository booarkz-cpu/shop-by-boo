# 13. Новости и страницы

## Для чего

Редактор страниц, которые видят клиенты в кабинете («Новости и документы») и в Mini App:

- новости;
- лендинги;
- юридические документы: правила сервиса, оферта, политика конфиденциальности.

Каждая публикация сохраняется версией, поэтому видно, какой текст действовал в какой момент.

## Где и кто

**Маркетинг → Новости и страницы.** Права `manage_content` (оператор, администратор). Наблюдатель черновики не видит.

## Создание и публикация

1. «Новая страница» → тип: новость, лендинг или юридическая страница.
2. Slug — латиница в нижнем регистре, цифры и дефисы, до 80 символов, например `rules`. Язык RU или EN: одинаковый slug допустим для разных языков. Заголовок.
3. Краткое описание и блоки: заглавный, текст, кнопка, преимущества, вопросы и ответы.
4. Расписание публикации, если нужно, — **в UTC** (12:00 по Москве = 09:00 UTC).
5. «Предпросмотр» → «Сохранить черновик» → «Опубликовать». Публикация недоступна, пока есть несохранённые изменения.
6. HTML и JavaScript не выполняются: вставленный `<script>` покажется как текст.

## Изменение и снятие

- Правка черновика не меняет опубликованный текст. Чтобы показать новую версию, опубликуйте ещё раз.
- «История» — все версии; любую можно восстановить в черновик.
- «Снять с публикации» скрывает страницу, черновик и история сохраняются.

## Что опубликовать перед запуском

| Страница | Зачем |
| --- | --- |
| Правила сервиса | Ограничения (торренты, спам, злоупотребления), устройства, возвраты |
| Оферта | Условия продажи; её требуют платёжные системы |
| Политика конфиденциальности | Какие данные хранятся: email, Telegram ID, платежи, счётчики узлов |
| Инструкция по подключению | Дублирует инструкции из **Личного кабинета** для тех, кто пришёл по ссылке |

Тексты юридических документов составляет владелец магазина под свою деятельность. Редактор только хранит их версии. Готовый пункт о торрентах есть в разделе **Серверы → Торренты на узлах**.

## Проверка

- Опубликуйте тестовую страницу и откройте её в кабинете («Новости и документы»): текст совпадает.
- Измените черновик, не публикуя: в кабинете остаётся прежний текст.
- Кнопка «Публичная страница» в админке работает, если `CABINET_URL` задан с HTTPS.

## Проблемы

| Симптом | Причина | Что делать |
| --- | --- | --- |
| Страницы нет в кабинете | Не опубликована, расписание ещё не наступило или язык другой | Проверьте статус и время в UTC |
| `409` при сохранении | Страницу изменили в другой вкладке | Обновите страницу и повторите |
| Нет кнопки «Публичная страница» | `CABINET_URL` пуст или без HTTPS | Задайте `CABINET_URL` |

## API

`GET|POST /api/admin/pages`, `GET|PUT /api/admin/pages/{id}`, `POST /api/admin/pages/{id}/publish|archive|restore`, `GET /api/admin/pages/{id}/revisions`, `GET /api/public/pages`, `GET /api/public/pages/{slug}?locale=ru`.
