# 19. Агенты узлов и антиабуз

## Для чего

- **Агент узла** (`scripts/node-agent.py`) — небольшая программа на каждом VPN-сервере. Каждую минуту она отправляет в магазин:
  - метрики узла: CPU, память, диск, работает ли Xray;
  - наблюдения подключений.

  По желанию агент также ограничивает скорость (`tc`), считает торренты, анализирует трафик и обслуживает терминал. Порты на узле не открываются: агент сам обращается к API магазина по HTTPS.
- **Антиабуз** — оценка «расшаривания» подписки по наблюдениям. Учитывается:
  - сколько разных сетей одновременно;
  - скорость «перемещения» между странами;
  - ASN хостингов;
  - число аккаунтов на одном устройстве;
  - торренты.

  Нарушения попадают на проверку оператору, а при включённой политике может срабатывать автоблокировка.
- **Ключи API и исходящие вебхуки** — для внешних систем: CRM, аналитики.

## Где и кто

**Серверы → Антиабуз и агенты**:

- просмотр — `read`;
- политика, агенты, чёрный список, модули — `manage_users` (оператор, администратор).

На странице:

- модули платформы: `abuse`, `agent`, `webhooks`, `mail`, `metrics`, `torrents` — включить или выключить;
- «Агент узла»: имя узла → «Создать агента» → **токен показывается один раз**;
- «Чёрный список HWID»: идентификатор устройства → «Блокировать»;
- «Нарушения»: оценка, рекомендация, «Ограничить» или «Снять»;
- «География» подключений;
- «Ключ API и webhook»: ключ с правами чтения, адрес вебхука (HTTPS) и его секрет.

## Установка агента на узел

1. В магазине: «Создать агента» с именем узла (например `nl-ams-1`), скопируйте токен.
2. На узле (Python 3.10+):

```bash
mkdir -p /opt/corgi && cd /opt/corgi
curl -fsSL https://raw.githubusercontent.com/booarkz-cpu/shop-by-boo/v28.41.0/scripts/node-agent.py -o node-agent.py
cat > /etc/corgi-agent.env <<'ENV'
SHOP_API_BASE=https://api.ДОМЕН
AGENT_TOKEN=токен-из-магазина
AGENT_INTERVAL=60
# Наблюдения для антиабуза из журнала Xray (необязательно):
# AGENT_XRAY_ACCESS_LOG=/var/log/remnanode/access.log
# AGENT_OBSERVE_ACCESS_LOG=1
ENV
chmod 600 /etc/corgi-agent.env
```

3. Запуск как службы systemd:

```ini
# /etc/systemd/system/corgi-agent.service
[Unit]
Description=Corgi node agent
After=network-online.target

[Service]
EnvironmentFile=/etc/corgi-agent.env
ExecStart=/usr/bin/python3 /opt/corgi/node-agent.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload && systemctl enable --now corgi-agent
journalctl -u corgi-agent -n 50
```

4. В магазине агент должен появиться «в сети» (heartbeat не старше 5 минут), с CPU, памятью, диском и состоянием Xray.

### Переменные агента

| Переменная | Назначение |
| --- | --- |
| `SHOP_API_BASE`, `AGENT_TOKEN` | Обязательные: API магазина и токен агента |
| `AGENT_INTERVAL` | Период отправки, секунд (не меньше 15, по умолчанию 60) |
| `AGENT_XRAY_ACCESS_LOG` | Путь к access-журналу Xray: торренты ([модуль 20](20-torrents-traffic-analysis.md)) и наблюдения |
| `AGENT_OBSERVE_ACCESS_LOG` | `1` — отправлять для антиабуза публичные IP-источники подключений клиентов (до 8 на клиента за интервал). Адреса назначения не отправляются |
| `OBSERVATIONS_FILE` | Альтернатива: JSON-файл с готовыми наблюдениями от своего сборщика |
| `AGENT_APPLY_TC`, `AGENT_IFACE` | `1` и интерфейс — выполнять ограничение скорости `tc` по действиям из магазина |
| `AGENT_TERMINAL` и др. | Терминал узла ([модуль 21](21-node-terminal.md)) |
| `AGENT_DPI` и др. | Глубокий анализ трафика ([модуль 20](20-torrents-traffic-analysis.md)) |

Клиент в журнале Xray определяется по полю `email`. Remnawave называет пользователей магазина `user_<ID>`, поэтому магазин узнаёт клиента без дополнительной настройки.

## Политика антиабуза

| Параметр | По умолчанию | Смысл |
| --- | --- | --- |
| Минимальная оценка | 50 | С какой оценки создаётся нарушение |
| Одновременных сетей (IP) | 0 | 0 — по лимиту устройств подписки |
| Буфер CGNAT | 3 | Допуск для мобильных сетей и CGNAT |
| Максимальная скорость перемещения, км | 50 | Невозможная смена географии |
| Аккаунтов на один HWID | 2 | Одно устройство в разных аккаунтах |
| Автоблокировка | выкл. | Блокировать автоматически при «жёсткой» оценке |
| Жёсткая оценка | 80 | Порог автоблокировки |
| Анализаторы | все | `temporal`, `geo`, `asn`, `behavior`, `devices`, `hwid`, `user_agent`, `torrent` |

**Сначала только наблюдайте.** CGNAT, мобильные сети и смена Wi-Fi дают ложные сигналы. Включайте автоблокировку только после нескольких недель проверки нарушений вручную.

## Работа

1. «Нарушения» → откройте запись: клиент, оценка, анализаторы и их доводы.
2. Проверьте карточку клиента и его устройства.
3. Решите, что делать:
   - **«Ограничить»** — клиенту запрещаются покупки и пробный период, его активные подписки **приостанавливаются**: статус «приостановлена», пользователь отключён в Remnawave. Срок подписки и деньги не трогаются, возврат при необходимости оформляется отдельно в «Возвратах». Автоблокировка агента делает то же самое;
   - **«Снять»** — запрет снимается, приостановленные подписки с неистёкшим сроком снова включаются в Remnawave и возвращаются в прежний статус; истёкшие переходят в «истекла». Обе операции записываются в журнал аудита (`abuse.user.restricted`, `abuse.user.cleared`);
   - **временная мера** — сначала используйте мягкие инструменты: массовую операцию «Ограничить доступ к магазину» ([модуль 04](04-customer-import.md)) или чёрный список устройства.
4. Устройство, замеченное в злоупотреблениях, добавьте в «Чёрный список HWID».

## Проверка

- Агент «в сети», метрики обновляются раз в минуту.
- С `AGENT_OBSERVE_ACCESS_LOG=1` подключитесь тестовым клиентом: в «Географии» появляется страна подключения.

## Проблемы

| Симптом | Причина | Что делать |
| --- | --- | --- |
| Агент «stale» | Служба остановлена, неверный адрес или токен | `journalctl -u corgi-agent`, проверьте `SHOP_API_BASE` |
| `503 Модуль отключён` | Модуль `agent` или `abuse` выключен | Включите модуль |
| Наблюдений нет | Не задан журнал или флаг, у агента нет прав на чтение журнала | `AGENT_XRAY_ACCESS_LOG`, `AGENT_OBSERVE_ACCESS_LOG=1`, права на файл |
| Много ложных нарушений | Мобильные сети | Увеличьте буфер CGNAT и минимальную оценку; выключите `geo` для мобильной аудитории |

## API

Агент: `POST /api/agent/heartbeat`, `POST /api/agent/observations`, `POST /api/agent/torrent`. Админка: `GET /api/admin/platform/summary`, `PUT /api/admin/platform/policy`, `POST /api/admin/platform/plugins/{key}`, `POST /api/admin/platform/agents`, `POST /api/admin/platform/blacklist`, `POST /api/admin/platform/violations/{id}/review`, `/api/admin/platform/api-keys`, `POST /api/admin/platform/webhooks`.
