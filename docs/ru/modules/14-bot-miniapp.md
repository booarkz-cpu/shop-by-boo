# 14. Telegram-бот и Mini App

## Для чего

- **Бот** — вход в магазин из Telegram: приветствие с картинкой, кнопки меню (Mini App, ссылки, поля с текстом, вложенные папки), команды. Привязывает реферальные ссылки `ref_…`.
- **Mini App** — кабинет внутри Telegram: подписка, оставшийся трафик и срок, ссылка и QR-код для подключения, тарифы, кошелёк, поддержка. Вход по данным Telegram, пароль не нужен.

Бот работает через long polling: вебхук и отдельный домен для бота не нужны.

## Где и кто

| Раздел | Что делает | Права |
| --- | --- | --- |
| **Бот и кабинет → Меню бота и Mini App** | Название бота и приложения, картинка `/start`, кнопки меню Telegram, картинки меню; экран Mini App: заголовок, подзаголовок, цвет и картинка фона, главная картинка, инструкция, кнопки; пользовательские поля | `manage_content` (оператор, администратор) |
| **Бот и кабинет → Дерево кнопок** | Вложенные папки до четырёх уровней, стили кнопок, custom emoji, предпросмотр; отдельно для бота и для Mini App | `manage_content` |

## Настройка

### В BotFather

1. `/newbot` — создайте бота, получите токен (`BOT_TOKEN`) и имя (`BOT_USERNAME`).
2. `/mybots` → бот → **Bot Settings → Menu Button** → URL Mini App (`MINI_APP_URL`, например `https://app.ДОМЕН`) и текст кнопки.
3. **Bot Settings → Configure Mini App** → тот же URL.
4. `/setcommands`:

```text
start - Главное меню
buy - Тарифы
subscription - Моя подписка
account - Мой кабинет
balance - Кошелёк
payments - Платежи
gifts - Подарки
referral - Реферальная программа
devices - Устройства
support - Поддержка
promo - Промокод
surveys - Опросы
```

5. `/setdescription` и `/setabouttext` — описание бота для новых пользователей.

### В `.env`

| Переменная | Значение |
| --- | --- |
| `BOT_TOKEN`, `BOT_USERNAME` | Из BotFather |
| `MINI_APP_URL` | HTTPS-адрес Mini App |
| `ADMIN_TELEGRAM_ID` | Ваш ID: только вам отвечает `/ops` |
| `DEFAULT_LANGUAGE` | `ru` или `en`, пока клиент не выбрал язык |
| `REQUIRED_TELEGRAM_CHANNEL` | `@канал` или `-100…`: перед покупкой бот проверяет подписку клиента. Бот должен быть администратором канала. Пусто — проверка выключена |

После изменения: `docker compose up -d --force-recreate bot backend`.

### В админке

1. **Меню бота и Mini App** → «Брендинг бота»: название бота, название приложения, «Изображение для /start».
2. «Меню Telegram» → текст кнопки, ссылка или действие, тип кнопки:
   - Mini App;
   - HTTPS-ссылка;
   - поле — показывает текст пользовательского поля;
   - папка.
   → «Добавить».
3. «Кнопки Mini App» → текст, действие: тарифы, HTTPS-ссылка, промокод, поле.
4. «Пользовательские поля» → ключ (например `promo_banner`), название, текст — значение, которое показывает кнопка «поле».
5. Экран Mini App: заголовок, подзаголовок, цвет фона, фон и главная картинка, инструкция по подключению.
6. **Дерево кнопок** — если нужны вложенные меню: создайте папку, затем кнопки с «Родителем». Стили: обычный, синий, зелёный, красный. Перед сохранением откройте предпросмотр.

## Команды бота

| Команда | Что делает |
| --- | --- |
| `/start` | Приветствие с картинкой и кнопками меню; `/start ref_КОД` — привязка приглашения |
| `/buy` | Список тарифов с кнопкой оплаты в Mini App |
| `/subscription` | Состояние подписки |
| `/account`, `/balance`, `/payments`, `/gifts`, `/referral`, `/support`, `/devices`, `/surveys` | Открывают соответствующий раздел Mini App |
| `/promo КОД` | Открывает Mini App с промокодом (сервер проверит код при оплате) |
| `/ops` | Только владельцу: открытые нарушения, агенты в сети, ссылка на админку |

Команды с данными клиента работают в личном чате с ботом.

## Mini App

Mini App — тот же кабинет, собранный для Telegram:

- тема берётся из Telegram (светлая или тёмная);
- кнопки дают тактильный отклик;
- «Назад» Telegram возвращает к предыдущему разделу;
- перед уходом на оплату приложение просит подтверждения;
- оплата открывается внешней ссылкой.

Telegram Web открывает Mini App во фрейме — это разрешено настройкой домена Mini App.

## Проверка

1. `/start` — приходит приветствие с картинкой и кнопкой Mini App.
2. Кнопка открывает Mini App, вход происходит автоматически, видны подписка и тарифы.
3. `/buy` показывает тарифы в продаже.
4. `/ops` от вашего аккаунта отвечает сводкой, от чужого — отказом.

## Проблемы

| Симптом | Причина | Что делать |
| --- | --- | --- |
| Бот не отвечает | Неверный `BOT_TOKEN` или тот же токен запущен в другом месте | `docker compose logs --tail=100 bot`; остановите второй экземпляр |
| Mini App: «ошибка входа» | Открыт в браузере, а не из Telegram; неверный `BOT_TOKEN` у backend | Открывайте из Telegram; проверьте `.env` |
| Mini App не открывается в Telegram Web | Старая настройка домена | Обновитесь; в Caddy для домена Mini App разрешён `frame-ancestors https://web.telegram.org` |
| «Подпишитесь на обязательный канал» | Включён `REQUIRED_TELEGRAM_CHANNEL` | Клиент подписывается; бот должен быть администратором канала |
| Custom emoji не видны | У бота нет прав на custom emoji (Fragment или Premium-владелец) | Используйте обычные emoji в названии |

## API

`GET /api/admin/content`, `/api/admin/menu`, `PUT /api/admin/miniapp/config`, `PUT /api/admin/miniapp/menu`, `/api/admin/fields`, `/api/admin/images`, `/api/admin/bot/start-image`, `/api/admin/miniapp/image|background`. Публично: `GET /api/public/config`, `GET /api/public/menu-emoji/{id}`. Вход Mini App: `POST /api/auth/telegram`.
