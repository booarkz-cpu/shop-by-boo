# 14. Telegram-бот и Mini App

## Для чего

- **Бот** — вход в магазин из Telegram: приветствие с картинкой, кнопки меню (Mini App, ссылки, поля с текстом, вложенные папки), команды. Привязывает реферальные ссылки `ref_…`.
- **Mini App** — кабинет внутри Telegram: подписка, оставшийся трафик и срок, ссылка и QR-код для подключения, тарифы, кошелёк, поддержка. Вход по данным Telegram, пароль не нужен.

Бот работает через long polling: вебхук и отдельный домен для бота не нужны.

## Где и кто

| Раздел | Что делает | Права |
| --- | --- | --- |
| **Бот и кабинет → Меню бота и Mini App** | Название бота и приложения, кнопки меню Telegram, картинки меню; экран Mini App: заголовок, подзаголовок, цвет и картинка фона, главная картинка, инструкция, кнопки; пользовательские поля | `manage_content` (оператор, администратор) |
| **Бот и кабинет → Баннеры бота** | Картинки над разделами бота (`/start`, тарифы, подписка, кошелёк, поддержка…) и над кнопками-папками: стандартные с корги Люси или свои; скрыть баннер, выключить все | просмотр `read`, изменения `manage_content` |
| **Бот и кабинет → Дерево кнопок** | Вложенные папки до четырёх уровней, стили кнопок, custom emoji, предпросмотр; отдельно для бота и для Mini App | `manage_content` |

## Настройка

### В BotFather

1. `/newbot` — создайте бота, получите токен (`BOT_TOKEN`) и имя (`BOT_USERNAME`).
2. `/mybots` → бот → **Bot Settings → Menu Button** → URL Mini App (`MINI_APP_URL`, например `https://app.ДОМЕН`) и текст кнопки.
3. **Bot Settings → Configure Mini App** → тот же URL.
4. `/setcommands`:

```text
start - Главное меню
buy - Тарифы
subscription - Моя подписка
account - Мой кабинет
balance - Кошелёк
payments - Платежи
gifts - Подарки
referral - Реферальная программа
devices - Устройства
support - Поддержка
promo - Промокод
surveys - Опросы
```

5. `/setdescription` и `/setabouttext` — описание бота для новых пользователей.

### В `.env`

| Переменная | Значение |
| --- | --- |
| `BOT_TOKEN`, `BOT_USERNAME` | Из BotFather |
| `MINI_APP_URL` | HTTPS-адрес Mini App |
| `ADMIN_TELEGRAM_ID` | Ваш ID: только вам отвечает `/ops` |
| `DEFAULT_LANGUAGE` | `ru` или `en`, пока клиент не выбрал язык |
| `REQUIRED_TELEGRAM_CHANNEL` | `@канал` или `-100…`: перед покупкой бот проверяет подписку клиента. Бот должен быть администратором канала. Пусто — проверка выключена |

После изменения: `docker compose up -d --force-recreate bot backend`.

### В админке

1. **Меню бота и Mini App** → «Брендинг бота»: название бота и приложения.
2. «Меню Telegram» → текст кнопки, ссылка или действие, тип кнопки:
   - Mini App;
   - HTTPS-ссылка;
   - поле — показывает текст пользовательского поля;
   - папка.
   → «Добавить».
3. «Кнопки Mini App» → текст, действие: тарифы, HTTPS-ссылка, промокод, поле.
4. «Пользовательские поля» → ключ (например `promo_banner`), название, текст — значение, которое показывает кнопка «поле».
5. Экран Mini App: заголовок, подзаголовок, цвет фона, фон и главная картинка, инструкция по подключению.
6. **Дерево кнопок** — если нужны вложенные меню: создайте папку, затем кнопки с «Родителем». Стили: обычный, синий, зелёный, красный. Перед сохранением откройте предпросмотр.
7. **Баннеры бота** — см. ниже.

### Баннеры бота

Каждый раздел бота приходит сообщением «картинка + текст + кнопки». Картинку-баннер задаёт **Бот и кабинет → Баннеры бота**:

| Раздел | Команда | Стандартный баннер |
| --- | --- | --- |
| Приветствие | `/start` | «Добро пожаловать» |
| Меню | кнопки-папки без своего баннера | «Меню» |
| Тарифы, Подписка, Промокод | `/buy`, `/subscription`, `/promo` | «Тарифы», «Подписка», «Промокод» |
| Мой кабинет, Кошелёк, Платежи, Подарки | `/account`, `/balance`, `/payments`, `/gifts` | одноимённые |
| Пригласи друзей, Поддержка, Устройства, Опросы | `/referral`, `/support`, `/devices`, `/surveys` | одноимённые |

- **Своё изображение** — PNG, JPG или WEBP до 8 МБ; лучше 1280×640 (2:1). Магазин проверяет файл, уменьшает до 1600 px по большей стороне и пересохраняет в JPEG. Соотношение сторон — не больше 20:1 (ограничение Telegram).
- **Вернуть стандартный** — удаляет своё изображение.
- **Показывать** — снимите флажок, чтобы раздел приходил без картинки. Общий флажок «Показывать баннеры в боте» выключает все баннеры.
- **Кнопки меню.** У каждой кнопки-папки и кнопки-поля можно задать свой баннер. Папка без своего баннера показывает баннер «Меню», кнопка-поле — только свой.
- **Навигация без лишних сообщений.** Нажатие на кнопку-папку меняет картинку, текст и кнопки в том же сообщении (`editMessageMedia`).
- **Длинный текст.** Подпись к фото в Telegram — до 1024 символов. Если текст раздела длиннее, бот отправит баннер и текст двумя сообщениями.
- Изображение, загруженное раньше в «Изображение для /start», становится баннером приветствия.
- Бот читает загруженные файлы из общего тома `media_data` (в `docker-compose.yml` он подключён к контейнеру `bot` только на чтение). Telegram получает каждый файл один раз, дальше бот отправляет его по `file_id`. Если баннер не удалось отправить, раздел придёт текстом.

Стандартные баннеры лежат в `backend/app/assets/bot_banners/` и собираются скриптом `python3 scripts/bot-banners/render.py` (SVG → JPEG через Playwright; шрифт Rubik, лицензия OFL). Подписи и цвета разделов задаются в начале скрипта.

## Команды бота

| Команда | Что делает |
| --- | --- |
| `/start` | Приветствие с картинкой и кнопками меню; `/start ref_КОД` — привязка приглашения |
| `/buy` | Список тарифов с кнопкой оплаты в Mini App |
| `/subscription` | Состояние подписки |
| `/account`, `/balance`, `/payments`, `/gifts`, `/referral`, `/support`, `/devices`, `/surveys` | Открывают соответствующий раздел Mini App |
| `/promo КОД` | Открывает Mini App с промокодом (сервер проверит код при оплате) |
| `/ops` | Только владельцу: открытые нарушения, агенты в сети, ссылка на админку |

Команды с данными клиента работают в личном чате с ботом. В группах `/buy` и `/promo` отвечают просьбой написать боту в личку: Telegram не разрешает кнопки Mini App (`web_app`) вне личных чатов. Промокод в `/promo` принимается только из латинских букв, цифр, `_` и `-` (до 64 символов). Рассылки идут с паузой между сообщениями и при ответе Telegram 429 ждут `retry_after` (до трёх попыток).

## Mini App

Mini App — тот же кабинет, собранный для Telegram:

- тема берётся из Telegram (светлая или тёмная);
- кнопки дают тактильный отклик;
- «Назад» Telegram возвращает к предыдущему разделу;
- перед уходом на оплату приложение просит подтверждения;
- оплата открывается внешней ссылкой.

Telegram Web открывает Mini App во фрейме — это разрешено настройкой домена Mini App.

## Проверка

1. `/start` — приходит приветствие с баннером «Добро пожаловать» (или вашим) и кнопкой Mini App; `/balance` — с баннером «Кошелёк».
2. Кнопка открывает Mini App, вход происходит автоматически, видны подписка и тарифы.
3. `/buy` показывает тарифы в продаже.
4. `/ops` от вашего аккаунта отвечает сводкой, от чужого — отказом.

## Проблемы

| Симптом | Причина | Что делать |
| --- | --- | --- |
| Бот не отвечает | Неверный `BOT_TOKEN` или тот же токен запущен в другом месте | `docker compose logs --tail=100 bot`; остановите второй экземпляр |
| Mini App: «ошибка входа» | Открыт в браузере, а не из Telegram; неверный `BOT_TOKEN` у backend | Открывайте из Telegram; проверьте `.env` |
| Mini App не открывается в Telegram Web | Старая настройка домена | Обновитесь; в Caddy для домена Mini App разрешён `frame-ancestors https://web.telegram.org` |
| «Подпишитесь на обязательный канал» | Включён `REQUIRED_TELEGRAM_CHANNEL` | Клиент подписывается; бот должен быть администратором канала |
| Раздел приходит без баннера | Баннер скрыт, выключены все баннеры или контейнер `bot` не видит том `media_data` | Проверьте флажки в «Баннерах бота»; `docker compose up -d --force-recreate bot` |
| Custom emoji не видны | У бота нет прав на custom emoji (Fragment или Premium-владелец) | Используйте обычные emoji в названии |

## API

`GET /api/admin/content`, `/api/admin/menu`, `PUT /api/admin/miniapp/config`, `PUT /api/admin/miniapp/menu`, `/api/admin/fields`, `/api/admin/images`, `/api/admin/bot/start-image` (прежний способ), `GET /api/admin/bot/banners`, `POST|DELETE /api/admin/bot/banners/{раздел}`, `PUT /api/admin/bot/banners/{раздел}/visibility`, `PUT /api/admin/bot/banners-enabled`, `/api/admin/miniapp/image|background`. Публично: `GET /api/public/config`, `GET /api/bot/banners/default/{раздел}.jpg`, `GET /api/public/menu-emoji/{id}`. Вход Mini App: `POST /api/auth/telegram`.
