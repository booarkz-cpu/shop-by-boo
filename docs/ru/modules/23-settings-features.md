# 23. Настройки и функции

## Для чего

- **Настройки без перезапуска** — 96 параметров магазина меняются из панели и применяются за 5 секунд в API, worker и боте. Примеры: цены и валюта, лимиты, ключи платёжных агентов, SMTP, тексты, сроки уведомлений.
- **Остальные параметры** меняются только через `.env` и перезапуск:
  - 81 параметр развёртывания — корневые ключи, БД, Redis, домены, токен бота, порты, терминал, приём почты;
  - 2 специальных — резервные копии и технический режим, у них свои разделы.
- **Функции и модули** — включение и выключение отдельных возможностей.

## Где и кто

| Раздел | Что делает | Права |
| --- | --- | --- |
| **Система → Настройки без перезапуска** | Каталог всех 187 полей с подсказкой, типом, источником (`.env` или БД) и диапазоном; двухшаговое изменение; история и откат | чтение `settings.runtime.read` (оператор, администратор), изменение `settings.runtime.write` (администратор) |
| **Система → Функции и модули** | Флаги функций с описанием | `feature_flags.manage` (оператор, администратор) |

## Как изменить параметр без перезапуска

1. Найдите поле по названию, ключу или назначению. Прочитайте подсказку (значок «?»).
2. Измените значение. «Вернуть .env» убирает переопределение из БД.
3. Введите причину (без секретов) → «Проверить и подготовить».
4. Проверьте предпросмотр, предупреждения и короткий fingerprint → «Применить версию N».
5. Новая версия видна в истории. Процессы перечитывают её не позже чем через 5 секунд.

Секретное поле оставьте пустым, если не меняете его: метка «секрет задан» подтверждает, что значение есть. Секреты хранятся зашифрованными и никогда не возвращаются в браузер.

**Откат** — только последней применённой версии, с причиной. **Конфликт `409`** — кто-то изменил настройки или `.env` изменился; обновите страницу и подготовьте набор заново.

## Как изменить параметр развёртывания

```bash
cd /opt/vpn-shop
nano .env                       # или другой редактор
docker compose up -d --force-recreate backend worker bot
docker compose ps
```

Список параметров развёртывания с причиной для каждого — внизу раздела «Настройки без перезапуска». `APP_SECRET` меняется только скриптом `bash scripts/rotate-secrets.sh`, иначе станут нечитаемыми сохранённые секреты:

- скрипт сохраняет копию `.env`;
- переносит прежний ключ в `APP_SECRET_PREVIOUS`;
- заодно выпускает новый `METRICS_TOKEN` — обновите его в Prometheus.

## Проверка

Измените безопасное значение (например, срок предупреждения об окончании подписки) → примените → проверьте в истории → откатите. В логах нет ошибок:

```bash
docker compose logs --since=10m backend worker bot | grep -E "Runtime settings|ERROR" || true
```

## Проблемы

| Симптом | Причина | Что делать |
| --- | --- | --- |
| `409` при применении | Устаревшая вкладка или изменился `.env` | Обновите и подготовьте заново |
| Значение не применилось | Параметр развёртывания | Меняйте в `.env` с перезапуском |
| Счётчики не 96/81/2 | Не обновлён backend | Проверьте версию и миграции |

## API
