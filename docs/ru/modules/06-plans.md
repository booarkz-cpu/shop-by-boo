# 06. Тарифы и подписки

## Для чего

Определяет, что продаёт магазин:

- **фиксированные тарифы** — срок, цена, трафик, устройства, профиль Remnawave;
- **конструктор** — клиент сам собирает устройства, трафик и срок;
- **пакеты трафика** — докупка гигабайт к действующей подписке;
- **изменения подписок** — смена тарифа и докупки;
- **пробный период**;
- **автопродление**.

У клиента может быть до 20 независимых подписок, у каждой свой пользователь в Remnawave, срок и лимиты.

## Где и кто

| Раздел | Что делает | Права |
| --- | --- | --- |
| **Тарифы и оплата → Тарифы** | Создать, изменить, снять с продажи, удалить тариф; выбрать профиль Remnawave | просмотр `read`, изменение `manage_plans` (оператор, администратор) |
| **Тарифы и оплата → Конструктор тарифов** | Базовая цена и пункты с доплатой: устройства, трафик, дни | `manage_plans` |
| **Тарифы и оплата → Пакеты трафика** | Название, объём, цена, порядок, доступность | `manage_plans` |
| **Тарифы и оплата → Изменения подписок** | Последние 100 смен тарифа и докупок; полный возврат на кошелёк | просмотр `payments.read`, возврат `payments.refund` (администратор) |

## Как тариф превращается в VPN-доступ

При оплате, пробном периоде или подарке worker создаёт или продлевает пользователя Remnawave:

- срок — срок тарифа;
- лимит трафика — из тарифа (0 — без ограничения);
- **Internal Squad** — профиль тарифа.

Squad определяет, какие узлы и протоколы доступны клиенту. **Без профиля пользователь создаётся без серверов и не подключится.** Условия тарифа фиксируются в заказе: последующая правка тарифа не меняет уже оплаченные заказы.

## Настройка

### Фиксированные тарифы

1. В Remnawave создайте Internal Squads ([модуль 18](18-nodes-routing.md)).
2. **Тарифы** → форма «Новый тариф»:

   | Поле | Значение |
   | --- | --- |
   | Название тарифа | Что увидит клиент: «1 месяц», «3 месяца» |
   | Цена, ₽ | Цена за весь срок |
   | Срок | 1, 3, 6, 12 месяцев или «Другой срок…» в днях (1–3650) |
   | Трафик, ГБ | 0 — без ограничения |
   | Устройств | Пусто — без ограничения; иначе 1–100 |
   | Профиль Remnawave (Internal Squad) | Выбор из списка панели. Если список не загрузился, вставьте UUID вручную |
   | В продаже | Снимите флажок, чтобы создать скрытый тариф |

3. «Создать тариф». Тариф сразу появляется в боте (`/buy`), кабинете и Mini App.
4. Тарифы без профиля подсвечиваются предупреждением вверху раздела.
5. «Изменить» — правка любого поля. «Снять с продажи» — скрыть, не удаляя. «Удалить» работает только для тарифа без продаж, подписок и пробных периодов. Тариф с историей снимайте с продажи.

Цены `PRICE_1`…`PRICE_12` в `.env` — справочные значения установщика. Продажи идут только по тарифам из этого раздела.

### Конструктор

1. **Конструктор тарифов** → название, базовая цена, ID профиля Remnawave, порядок, описание, «Включён».
2. Добавьте пункты: параметр (устройства, трафик ГБ, дни), подпись для клиента, значение, доплата. Трафик 0 означает безлимит.
3. Цена для клиента = базовая цена + выбранные пункты. Проверьте несколько комбинаций в кабинете.
4. Пробный период для конструктора недоступен.

### Пакеты трафика

**Пакеты трафика** → название, объём ГБ, цена, тариф (пусто — для всех тарифов), порядок. Клиент покупает пакет с кошелька. Срок подписки при этом не меняется.

### Пробный период

- Клиент выбирает тариф в разделе «Пробный период» кабинета и получает его на срок до `TRIAL_MAX_DAYS` дней (по умолчанию 3, максимум 30).
- Один раз на аккаунт, только без действующей подписки.
- Пробная подписка получает трафик, устройства и профиль выбранного тарифа.

### Автопродление

| Переменная | Значение |
| --- | --- |
| `AUTO_RENEW_ENABLED` | `true` — включить механизм |
| `AUTO_RENEW_LEAD_DAYS` | За сколько дней до конца списывать (1–14) |
| `AUTO_RENEW_GRACE_DAYS`, `AUTO_RENEW_MAX_RETRIES` | Окно и число повторных попыток |
| `NOTIFICATION_EXPIRY_DAYS` | За сколько дней предупреждать об окончании |

Клиент включает автопродление для конкретной подписки. Списание идёт сохранённым способом оплаты YooKassa. Как и любой реальный платёж, автопродление работает только при открытом production gate ([модуль 07](07-payments.md)).

## Работа

- **Смена тарифа клиентом.** Клиент открывает «Подписку», выбирает новый тариф, видит доплату и подтверждает списание с кошелька. Доплата = разница стоимости дня × оставшиеся дни; срок не меняется.
- **Возврат смены тарифа.** **Изменения подписок** → «Вернуть на кошелёк». Лимиты возвращаются к прежним.
- **Повышение цены.** Измените тариф: новая цена действует для новых заказов, оплаченные сохраняют свою.
- **Вывод тарифа.** «Снять с продажи». Действующие подписки продолжают работать до конца срока.

## Проверка

1. Создайте тариф на 3 месяца с профилем, откройте кабинет: тариф виден с правильной ценой и сроком.
2. Получите пробный период этого тарифа тестовым клиентом. В Remnawave у пользователя `user_<ID>` правильный срок, лимит трафика и squad.
3. Подключитесь по ссылке подписки — VPN работает.

## Проблемы

| Симптом | Причина | Что делать |
| --- | --- | --- |
| Подписка выдана, VPN не подключается | У тарифа нет профиля или squad без инбаундов | Выберите профиль; проверьте squad в Remnawave |
| Список профилей пуст | Remnawave недоступен или нет squads | «Обновить профили Remnawave»; вставьте UUID вручную |
| «Тариф уже используется…» при удалении | Есть платежи, подписки или пробные периоды | Снимите тариф с продажи |
| Тарифа нет в боте | Тариф скрыт | «Вернуть в продажу» |
| Доплата отклонена | Новый лимит устройств ниже числа активных устройств или трафик ниже использованного | Клиенту нужно отключить устройства или выбрать другой тариф |
