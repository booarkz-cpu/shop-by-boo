# Выпуск v28.85.0 — «Корги Люси: клиент» 1.4.0: новый главный экран, иконки, профили маршрутизации

Дистрибутив: `v28.85.0`. Runtime/API: `21.5.1`. Head магазина: `0093_ssh_key_rotation` (миграций нет). Support Pro: `0008` / 3.8.

Этап 19, часть D3 — последнее из списка эталонного клиента.

## Клиент 1.4.0

- **Новый главный экран** (по промпту владельца):
  - баннер с корги — отдельная карточка, без текста поверх картинки;
  - слоган «Свободный интернет без лишнего Гав!» и статус подключения — под баннером;
  - большая круглая кнопка: свечение акцента при подключении, кольцо во время подключения;
  - карточка выбранного сервера по нажатию плавно раскрывает список всех серверов провайдера. В строке: флаг, название, протокол серым («VLESS • TCP • REALITY»), пинг цветной точкой и мс. Выбор закрывает список;
  - «стеклянные» полупрозрачные карточки с тонкой рамкой на глубоком тёмном фоне, скругления 24–28 dp;
  - баннеры всех разделов тоже без текста поверх картинки.

  Логика прежняя: подключение, профили, выбор сервера, пинг, добавление.
- **Иконка приложения на выбор**: «Корги», «Ночь», «Мята» — «Настройки → Оформление → Иконка приложения»; значок на рабочем столе меняется через несколько секунд.
- **Профили маршрутизации**: режим и правила сохраняются под именем и включаются одним касанием, например «Дом» и «Работа». Профили входят в резервную копию.
- **Фильтр журналов** по уровню: Error, Warning, Info.
