# Выпуск v28.91.0 — раздел «SelfSteal»: сайты нод, проверка снаружи, свой сайт, каталог шаблонов

Дистрибутив: `v28.91.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8.

Задача владельца N8 этапа 20 (скриншоты 2026-11-07). Всё — в админке: **«Серверы → SelfSteal»**.

## Что в разделе

- **«Зачем ноде свой сайт»** — раскрывающаяся подсказка.
- **«Что стоит на нодах — известно про N из M»** и «Обновить»: по каждой ноде — флаг страны, имя, адрес, домен (или «домена нет»), сайт на ноде («нечего показывать» / «не знаем» для нод, поставленных не мастером / название шаблона или своего сайта), итог проверки снаружи («не проверяли» / «в порядке» / «есть замечания (N)») и кнопки «Проверить» и «Сменить сайт».
- **Проверка снаружи — 11 пунктов** с сервера магазина, только по адресу самой ноды из реестра (домен — как SNI и Host; ни на какие другие адреса магазин не ходит): домен указывает на сервер; сайт открывается по HTTPS (код, время); свой `<title>`, а не страница веб-сервера; сертификат настоящий и для этого домена (издатель, имя, дней осталось); http → 301 на https; несуществующий адрес → 404 со страницей сайта; заголовки не выдают программу (Server, X-Powered-By); HSTS; robots.txt; карта сайта из robots.txt; внутренние страницы открываются.
- **Свой сайт → «Загрузить архив»**: zip или tar.gz до 20 МБ (до 60 МБ и 800 файлов в распакованном виде) — html, css, js, картинки, шрифты, видео; index.html с `<title>` в корне или в единственной папке. Не принимаются: пути за пределы сайта, ссылки и особые файлы, скрытые и служебные файлы, серверные скрипты (php, py, sh…). Список загруженных; удалить нельзя, пока сайт стоит на ноде.
- **Каталог шаблонов — 22** в 7 темах («Творчество и дизайн», «Технологии», «Бизнес и услуги», «Образование», «Еда и дом», «Путешествия», «Хобби»), русский и английский, фильтр по теме и языку, превью в изолированной рамке. Тексты и картинки написаны для магазина, ничего не грузится с чужих сайтов. **У каждой ноды своя сборка**: название, оттенок цвета, раскладка, порядок разделов, год и картинки зависят от домена ноды. В каждой сборке — внутренние страницы, 404, robots.txt, sitemap.xml.
- **«Сменить сайт»** — модуль «Сайт SelfSteal» установки: план → «Запустить» → журнал шагов; при ошибке возвращается прежний сайт.

## Как сайт попадает на ноду

Сайт целиком (а не одна страница) упаковывается в tar.gz, проверяется по SHA-256 на ноде, распаковывается в `/opt/remnawave-selfsteal/sites/site-<sha>`, и ссылка `current` переключается одним переименованием; откат переключает обратно, три последние сборки хранятся. Caddy ноды: без «всё на index.html» (несуществующие адреса — 404 со страницей сайта), HSTS, без заголовка `Server`. Старые установки получают это при следующем «Обновить» или смене сайта.
