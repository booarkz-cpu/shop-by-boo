## A5: покупки в Google Play и App Store

До этого выпуска приём покупок из магазинов приложений был закрыт ответом 410 (решение от 2026-10-02: «оплата только через кабинет»). Теперь его включает владелец: «Настройки без перезапуска → Магазины приложений → Покупки в магазинах приложений». По умолчанию **выключено**.

- **Покупка.** Приложение присылает покупку на `POST /api/payments/mobile/verify`. Магазин сам спрашивает Google (Android Publisher API, `subscriptionsv2`) или Apple (App Store Server API), сверяет товар с тарифом (`MOBILE_STORE_PRODUCTS`) и выдаёт подписку тем же путём, что и любую оплату: блокировки «клиент → платёж», без двойной выдачи. Платёж привязан к подписке клиента. Одна покупка магазина — один платёж и один аккаунт.
- **Продления.** App Store Server Notifications V2 (`POST /api/webhooks/app-store`) и уведомления Google Play через Pub/Sub (`POST /api/webhooks/google-play?token=…`). Каждый период — новый платёж той же подписки. Состояние Google всегда перечитывается из API; первая покупка приходит только из приложения.
- **Возвраты и отзыв.** REFUND/REVOKE от Apple, «voided purchase» и REVOKED от Google забирают доступ как возврат из админки: внутри блокировок, реферальное вознаграждение отменяется только после отключения; если панель недоступна — повтор планировщиком возвратов.
- **Подпись Apple.** Каждый JWS проверяется по цепочке x5c до Apple Root CA G3 (SHA-256 отпечаток сверен на support.apple.com) и по меткам сертификатов Apple.
- **Новые настройки:** `mobile_store_purchases_enabled`, `google_play_rtdn_token` (секрет). Миграция `0094_store_subscriptions`: связь подписки магазина с клиентом, подпиской и тарифом (токен Google хранится только как SHA-256).

Живые покупки — **BLOCKED_SECRETS**: нужны сервисный аккаунт Google Play, ключ App Store Connect (Issuer ID, Key ID, .p8), bundle id и товары в консолях магазинов.

## A6: свои выпуски «Корги Люси: клиента»

«Mobile packages» на каждую новую версию клиента создаёт выпуск `client-v<версия>` с APK, `.sha256` и манифестом, ссылка которого ведёт на этот выпуск. Выпуск никогда не становится «последним» — ссылки магазина `releases/latest/download/…` не меняются. Obtainium: фильтр названий выпусков `^client-v`.
