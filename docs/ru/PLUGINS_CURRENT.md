# Плагины

Плагин подключает к магазину внешний сервис: CRM, аналитику, программу лояльности, собственную автоматизацию. Плагин — это **отдельный HTTPS-сервис** издателя. Магазин принимает от издателя только подписанный пакет с описанием плагина (манифестом) и **никогда не выполняет код плагина у себя**. Поэтому плагин не может прочитать базу, ключи платёжных агентов или настройки магазина.

Плагин:

- получает от магазина события (новый клиент, успешный платёж, активированная подписка), подписанные HMAC;
- читает данные и отправляет уведомления через API `/api/plugin/v1` — только в рамках прав, которые подтвердил администратор;
- включается, обновляется, откатывается и выключается без перезапуска магазина.

## Для администратора

Раздел **Система → Плагины**. Просматривать раздел могут роли с правом диагностики, изменять — администраторы с правом управления безопасностью. Все действия записываются в журнал.

### 1. Доверьте ключу издателя

Получите от издателя открытый ключ Ed25519 (строка base64, 44 символа) по проверенному каналу: из его документации, договора или личного обмена — не из письма от неизвестного отправителя. В блоке «Доверенные издатели» введите название и ключ. Магазин покажет отпечаток ключа (16 символов) — сверьте его с издателем.

Отзыв ключа сразу выключает все плагины, активная версия которых подписана этим ключом, и запрещает включать их версии.

### 2. Загрузите пакет

«Проверить и загрузить» принимает `.zip` до 256 КБ. Магазин отклоняет пакет, если:

- подпись не сходится или файлы изменены после подписи;
- ключ неизвестен или отозван;
- в пакете есть что-то кроме `manifest.json`, `signature.json`, `README.md` (например, код);
- `api_version` не поддерживается (сейчас поддерживается `1`);
- манифест запрашивает неизвестные права или события, либо событие без нужного права;
- адрес событий не HTTPS или ведёт во внутреннюю сеть.

Загруженный пакет не активен, пока вы его не включите.

### 3. Заполните настройки

Настройки описаны в манифесте: строки, числа, флажки и секреты (например, ключ API самой CRM). Обязательные настройки нужно заполнить до включения. Секреты хранятся зашифрованными, в интерфейсе не показываются; пустое поле секрета оставляет прежнее значение. Настройки видит только сам плагин через `GET /api/plugin/v1/me`.

### 4. Подтвердите права и включите

Карточка показывает права и события выбранной версии:

| Право | Что даёт |
| --- | --- |
| `users.read` | ID, имя и дату регистрации клиента; событие «Новый клиент» |
| `payments.read` | Сумму, валюту, статус и тариф платежа; событие «Успешный платёж» |
| `subscriptions.read` | Тариф, статус и срок подписок клиента; событие «Подписка активирована» |
| `notifications.send` | Уведомления клиенту в приложении (до 60 в минуту, с защитой от повторов) |

Ни одно право не открывает email, телефоны, балансы, ссылки подписок, платёжные реквизиты и данные других разделов.

Отметьте «Разрешаю плагину эти права и события» и нажмите «Включить версию». При первом включении магазин один раз показывает **API-токен** и **секрет подписи событий** — передайте их в настройки сервиса плагина. Магазин хранит только хеш токена и зашифрованный секрет; при утере нажмите «Выпустить новые ключи» (старый токен сразу перестаёт работать).

События отправляются только о том, что произошло после включения плагина: история задним числом не передаётся.

### Обновление и откат

Загрузите новую версию тем же способом. Она не заменяет работающую:

- если новая версия просит **новые права**, карточка покажет их, и до подтверждения продолжает работать прежняя версия;
- «Включить версию X» подтверждает права и переключает плагин без перезапуска;
- «Вернуть эту версию» переключает на любую загруженную версию, если она не требует прав сверх уже подтверждённых.

Одну и ту же версию загрузить повторно нельзя — издатель должен повысить `version`.

### Сбои

Если сервис плагина недоступен или отвечает ошибкой 5xx/429, событие повторяется через 30 с, 1, 2, 4, 8 минут (до 6 попыток). Ответ 4xx считается окончательным отказом. После 20 ошибок подряд магазин **автоматически останавливает плагин** («Остановлен из-за ошибок») — сбой внешнего сервиса не влияет на продажи. Исправьте сервис и включите плагин снова. Журнал доставок хранится 30 дней.

«Выключить» сразу закрывает плагину API и останавливает события. «Удалить» стирает плагин, все его версии, настройки и журнал доставок.

## Для издателя плагина

### Каталог

Издатель может опубликовать каталог своих пакетов — JSON `{"catalog": 1, "name": "…", "plugins": [{"id", "name", "version", "package_url", "sha256", "description", "homepage"}]}` по HTTPS — и подписать его тем же ключом:

```bash
python3 scripts/sign-plugin.py catalog publisher.key catalog.json catalog.signed.json
```

Подписывается канонический JSON полей `catalog`, `name`, `plugins`; в файл добавляются `public_key` и `signature`. Магазин принимает каталог, только если ключ есть среди доверенных и не отозван, а при установке сверяет SHA-256 скачанного пакета. Новая версия = новая запись в `plugins` и повторная подпись каталога.

### Манифест

```json
{
  "id": "example.crm-sync",
  "name": "CRM sync",
  "version": "1.0.0",
  "api_version": 1,
  "publisher": "Example Ltd",
  "description": "Передаёт новых клиентов и платежи в CRM.",
  "endpoint": "https://crm.example.com/corgi/events",
  "capabilities": ["users.read", "payments.read"],
  "events": ["user.registered", "payment.succeeded"],
  "settings": [
    {"key": "crm_api_key", "type": "secret", "label": "Ключ CRM", "required": true},
    {"key": "pipeline", "type": "string", "label": "Воронка CRM"}
  ]
}
```

- `id` — 3–64 символа `a-z 0-9 . -`, постоянный для всех версий; `version` — `X.Y.Z`.
- `endpoint` — публичный HTTPS-адрес, куда магазин отправляет события.
- `events` требуют прав: `user.registered` → `users.read`, `payment.succeeded` → `payments.read`, `subscription.activated` → `subscriptions.read`.
- `settings` — до 20 полей типов `string`, `secret`, `bool`, `int`.

Пример лежит в `docs/examples/plugin/`.

### Подпись пакета

```bash
python3 scripts/sign-plugin.py keygen publisher.key          # один раз; выводит открытый ключ
python3 scripts/sign-plugin.py sign publisher.key ./my-plugin my-plugin-1.0.0.zip
```

Закрытый ключ создаётся с правами `0600`. Храните его офлайн; открытый ключ передайте администраторам магазинов. Подпись покрывает SHA-256 каждого файла пакета.

### События

Магазин отправляет `POST` на `endpoint`:

```http
Content-Type: application/json
X-Corgi-Event: payment.succeeded
X-Corgi-Delivery: 42
X-Corgi-Timestamp: 1761120000
X-Corgi-Signature: v1=<hex HMAC-SHA256(secret, timestamp + "." + body)>

{"id":42,"event":"payment.succeeded","plugin":"example.crm-sync","version":"1.0.0","created_at":"2026-10-22T08:00:00Z","data":{"payment_id":7,"user_id":1}}
```

Проверяйте подпись секретом подписи и отклоняйте запросы с меткой времени старше 5 минут. Событие с тем же `id` может прийти повторно (при потере ответа) — обрабатывайте идемпотентно. Отвечайте `2xx` быстро, тяжёлую работу выполняйте асинхронно.

### API плагина

Все запросы — `Authorization: Bearer <API-токен>`.

| Метод | Путь | Право |
| --- | --- | --- |
| `GET` | `/api/plugin/v1/me` | — (ID, версия, права, свои настройки) |
| `GET` | `/api/plugin/v1/users/{id}` | `users.read` |
| `GET` | `/api/plugin/v1/users/{id}/subscriptions` | `subscriptions.read` |
| `GET` | `/api/plugin/v1/payments/{id}` | `payments.read` |
| `POST` | `/api/plugin/v1/notifications` `{user_id, title, body, dedupe_key}` | `notifications.send` |

`401` — токен неверен или плагин выключен; `403` — право не подтверждено; `429` — превышен лимит уведомлений.

## Проверка

`tests/test_plugins.py` (SQLite и PostgreSQL) проверяет:

- установку подписанного пакета и разовую выдачу ключей;
- отказ изменённому, недоверенному, несовместимому пакету и пакету с кодом;
- внутренний адрес событий;
- обязательные настройки и подтверждение прав;
- область действия токена;
- обновление с новыми правами и границы отката;
- события без истории и без дублей при повторном сканировании;
- HMAC-подпись, повторы, окончательный отказ и автоостановку;
- отзыв ключа издателя, уведомления, ротацию и удаление;
- инструмент подписи.

`admin/e2e/plugins.spec.ts` проходит путь в браузере: ключ издателя, загрузка пакета, подписанного `sign-plugin.py`, настройка, подтверждение, выдача ключей, выключение, отсутствие горизонтальной прокрутки на телефоне. Миграция `0067_plugin_runtime` проверяется roundtrip; откат запрещён, пока установлены плагины. Публичного каталога плагинов нет.
