## Смена записи DNS с проверкой (REQ-INFRA-0039)

«Серверы → Домены и сертификаты», кнопка «Запись A в …». Если имя уже указывает на какой-то адрес, а новый адрес не
принимает соединения на порту 443, запись не меняется: панель показывает, куда имя указывает сейчас, и предлагает
«Сменить без проверки» или «Оставить как есть». После смены в сообщении и в журнале действий остаётся прежний адрес —
по нему запись можно вернуть. Имя без записи, тот же адрес и частный адрес не проверяются.

Не сделано: такая же проверка при смене домена панели мастером установки.

## Раздел реестра INFRA (решение № 19)

Раздел сверен полностью (41 требование). В этом выпуске: PASS — история Git при переносе (0019), старые проекты и ветки
не удаляются (0022); PARTIAL — список дополнительной инфраструктуры (0001: нет AdGuard Home и каскада HAProxy), опись
исходных проектов (0017, 0018), сравнение «до и после» (0020: нет проверки на настоящем сервере), проверка перед сменой
DNS (0039); BLOCKED_EXTERNAL — SLO после замеров (0026: нужен VPS).
