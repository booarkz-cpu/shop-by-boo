# Релиз v28.128.0 — готовность нод к MASQUE и проверенная конфигурация

Дистрибутив: `v28.128.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8.

Дата: 2026-11-12. Задача владельца: все требования реестра — в статус PASS (этап 23). Раздел «MASQUE», `REQ-MASQUE-0001` – `REQ-MASQUE-0012`.

## Главное

MASQUE в Xray существует, и магазин умеет собрать для него рабочую конфигурацию. Включить протокол для покупателей
пока нельзя: панель Remnawave 3.4.10 не выдаёт для него пользователей и не пишет его в подписку. Поэтому переключателя
«включить MASQUE» в этом выпуске нет.

## Что изменилось

### Блок «MASQUE (CONNECT-IP)» в панели администратора

Вкладка «Смена протокола», под основным блоком. Показывает:

- у каких нод ядро Xray подходит. Нужно v26.10.21 или новее: версии v26.10.10 из задания не существует, это первый выпуск после неё;
- свободен ли выбранный порт в каждом профиле панели. По умолчанию 2087: порт 443 занят REALITY (TCP) и Hysteria2 (UDP);
- три причины, по которым протокол не включается;
- готовый inbound для Xray.

Блок только читает данные панели и ничего не меняет.

### Проверенная конфигурация

`backend/app/masque.py` собирает inbound сервера и outbound клиента по официальной схеме и отклоняет то, что отклонил бы Xray:
слишком узкий диапазон адресов, MTU меньше 1280, логин с двоеточием, адрес вместо домена.

`scripts/masque-selfcheck.sh` проверяет эти конфигурации на настоящем Xray. Запуск на runner GitHub с Xray 26.11.9:
конфигурации приняты, страница получена через туннель по HTTP/3 и по HTTP/2, неверный пароль отклонён.

### Отчёт

[MASQUE_IMPLEMENTATION_REPORT.md](../MASQUE_IMPLEMENTATION_REPORT.md): что подтверждено по официальным репозиториям, порты,
API Xray, подписка и клиенты, зондирование, sing-box, что не сделано.

## Реестр требований: раздел «MASQUE»

| Статус | Сколько | Требования |
| --- | ---: | --- |
| PASS | 4 | 0003 — подтверждение по официальным источникам; 0009 — зондирование; 0010 — другие движки; 0012 — отчёт |
| PARTIAL | 7 | 0002, 0004 – 0008, 0011 — проверочная часть есть, выдачи пользователям нет |
| NOT_IMPLEMENTED | 1 | 0001 — автоустановка MASQUE на ноду |

## Чем проверено

- `tests/test_masque.py` — версии, схема, отказы, порты рядом со всеми транспортами магазина.
- `admin/e2e/masque.spec.ts` — блок в браузере; отдельно проверено, что кнопки «включить» нет.
- `scripts/masque-selfcheck.sh` — настоящий Xray 26.11.9.

## Чего пока нет

- MASQUE не ставится на ноды и не попадает в подписку.
- На VPS с настоящим доменом и на телефоне не проверено.
- Ссылки для v2rayNG и NekoBox нет: общего формата для сервера с логином и паролем не существует.

## Что нужно от владельца

Ничего. Если хотите MASQUE до того, как его поддержит Remnawave, — это отдельное решение: вести пользователей MASQUE
напрямую через API Xray, мимо панели.
