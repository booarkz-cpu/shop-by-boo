# Релиз v28.150.0 — вопрос об SSH при установке, решения владельца № 16–19

Дистрибутив: `v28.150.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8.

Дата: 2026-11-14. Ответы владельца на вопросы от 2026-11-14 (`docs/OWNER_DECISIONS.md`, № 16–19).

## Установщик спрашивает про SSH (решение № 18)

- Сразу после вопроса об автообновлении: «Открыть SSH только для вашего адреса (yes / no)». Установщик показывает
  адрес, с которого вы сейчас подключены, и предупреждает: если адрес меняется (мобильный интернет, домашний без
  постоянного IP) — отвечайте «no».
- Enter — «no», SSH открыт для всех, как раньше. «yes» — SSH открывается только для вашего текущего адреса.
- `ADMIN_SSH_IP=<адрес>` при запуске означает «да» с этим адресом. Защита от потери доступа из v28.148.0 остаётся:
  ограничение включается, только если вы подключены именно с этого адреса.

## Чем проверено

`tests/test_admin_ssh_ip.py` — вопрос запускается без терминала (как с `INSTALL_NONINTERACTIVE=1`): по умолчанию SSH
открыт, «yes» берёт текущий адрес, заданный `ADMIN_SSH_IP` сохраняется, без SSH-сессии — предупреждение.
