# Релиз v28.120.0 — приложения для Android обновляются с GitHub без участия человека

Дистрибутив: `v28.120.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8.
Приложения Android и iOS: `3.7.0`. «Корги Люси: клиент»: `1.9.2`.

Дата: 2026-11-11. Задача владельца: автообновление приложений для Android и iOS с GitHub без участия пользователя (этап 22, часть 3).

## Что изменилось

- **Приложение магазина** и **приложение администратора** для Android 3.7.0: фоновая задача раз в сутки скачивает новую версию
  из выпуска на GitHub, сверяет SHA-256 и передаёт системному установщику.
- **«Корги Люси: клиент»** 1.9.2: скачанное обновление ставится само. Раньше нужно было нажать на уведомление.
- Кнопка «Обновить» в окне «Доступна версия …» теперь скачивает и проверяет файл сама, без браузера.

Подробно: [AUTO_UPDATE.md](../AUTO_UPDATE.md#11-приложения-без-участия-человека).

## Когда обновление проходит совсем без вопросов

| Условие | Что происходит |
| --- | --- |
| Android 12 и новее, приложение уже один раз обновило себя само | Без вопросов |
| Android 12 и новее, первое обновление | Одно подтверждение |
| Android 11 и старше | Подтверждение каждый раз: это ограничение системы |
| Работает VPN | Обновление откладывается, чтобы не оборвать VPN |

## iOS

Сделать автообновление с GitHub на iOS нельзя: приложение на iOS не может установить собственное обновление.
Без участия человека приложения на iOS обновляет только App Store. Для публикации нужен аккаунт Apple Developer.
В приложениях для iOS в этом выпуске изменился только номер версии.

## Чем проверено

- `AppUpdateTest`, `ApkCheckTest` — условия тихой установки, сверка SHA-256, разбор файла версии.
- `AdminScreensTest.updateManifestIsCheckedStrictly` — приложение администратора, на эмуляторе.
- Сборка и тесты интерфейса всех приложений в CI.

## Чего пока нет

- Тихая установка на настоящем телефоне не проверена.
- Версии 3.6.0 и старше и клиент 1.9.1 и старше фоновой установки не умеют: новую версию на них нужно поставить один раз.
- В Google Play такую сборку публиковать нельзя без правки: там разрешение на установку приложений ограничено.

## Что нужно от владельца

Один раз установить приложения 3.7.0 и клиент 1.9.2 и один раз подтвердить их первое обновление. Для iOS — аккаунт Apple Developer.
