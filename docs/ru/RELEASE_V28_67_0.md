# Выпуск v28.67.0 — портал подписки и домены

Дистрибутив: `v28.67.0`. Runtime/API: `21.5.1`. Head магазина: `0091_remnawave_domains` (одна новая миграция). Support Pro: `0008` / 3.8. Дата и commit фиксируются тегом выпуска.

Этап 11 мастер-задания.

## Что сделано

**Портал подписки** ([портал](new/SUBSCRIPTION_PORTAL.md), [шаблоны](new/SUBSCRIPTION_TEMPLATES.md)). Ссылка подписки в браузере открывает страницу клиента:
- тариф и статус, дата окончания, трафик, устройства;
- ссылка с копированием и QR-код;
- кнопки «Добавить в приложение» и инструкции;
- объявление, поддержка, личный кабинет.

VPN-приложения по той же ссылке получают подписку. Шаблоны: «Корги Люси», «Короткая», стандартная страница панели.

**Домены и сертификаты** ([домены](new/SUBSCRIPTION_DOMAIN.md)):
- домен портала добавляется в админке и работает без перезапуска: Caddy магазина выпускает сертификат при первом обращении, спросив backend (`/caddy/ask`); любое другое имя сертификата не получает;
- проверка DNS (A, AAAA, CNAME, TXT, CAA), сертификата и HTTPS, ежедневная проверка с оповещением;
- «Сделать адресом подписки», запись A в Cloudflare;
- маршруты всех Caddy: магазина, портала, серверов Remnawave.

**Защита** ([безопасность](new/SUBSCRIPTION_SECURITY.md)):
- перебор ссылок ставит адрес на паузу;
- утёкшую ссылку меняют клиент (в кабинете) и администратор;
- устаревшим приложениям можно отдавать заглушку «Обновите приложение»;
- страницы панели Remnawave закрываются секретной ссылкой (мастер установки).

Модули 15–17 Админ-центра (Domains, Certificates, Reverse Proxy) получили раздел: из панели управляются 29 из 30 модулей. Остался Node Extensions (этап 12).

## Обновление

Миграция `0091_remnawave_domains` добавляет таблицу и применяется обычным обновлением. Caddy получает новый `deploy/Caddyfile` (on-demand TLS) и переменную `CADDY_ASK_URL` из `docker-compose.yml`.

```bash
cd /opt/vpn-shop && bash scripts/backup.sh
sudo env APP_DIR=/opt/vpn-shop RELEASE_TAG=v28.67.0 bash /opt/vpn-shop/scripts/update-from-github.sh
```
