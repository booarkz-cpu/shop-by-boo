# Релиз v28.111.0 — «Корги Люси: клиент» 1.8.2: ядро Xray v26.10.31

Дистрибутив: `v28.111.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8. «Корги Люси: клиент»: `1.8.2` (versionCode 182).

Дата: 2026-11-08. Задача: N11 (автообновление ядра Xray).

## Что изменилось

- **Ядро клиента** собрано из [AndroidLibXrayLite v26.10.31](https://github.com/2dust/AndroidLibXrayLite/releases/tag/v26.10.31), коммит `2ffe5f794a32ba15b122e177b5acffc6f11c4959` (было `76a6e217`). В «О приложении» видна новая сборка ядра.
- **Наблюдатель ядра** (`xray-core-watch.yml`) нашёл этот выпуск, но правило репозитория не дало токену Actions создать ветку `auto/xray-core-*`. Теперь в таком случае он открывает задачу «Ядро Xray: AndroidLibXrayLite <тег>» (одну на тег) с командой обновления и завершается предупреждением, а не ошибкой.
- Клиент: версия 1.8.2 (versionCode 182). Магазин и другие приложения не менялись.

## Чем проверено

CI PR: сборка AAR из нового коммита, unit-тесты клиента, ktlint, сборка APK, настоящий VPN и UI-тесты на эмуляторе; разбор всех workflow (`tests/test_workflows_parse.py`).

## Что нужно от владельца

Чтобы обновления ядра приходили PR автоматически: разрешить GitHub Actions создавать ветки `auto/*` в наборе правил репозитория (или выдать токен GitHub App). До этого обновление приходит задачей, а PR открываю я.
