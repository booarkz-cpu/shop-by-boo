## Новые операции

- **Защита ноды (nftables)** — лимит новых соединений в секунду с одного адреса на портах ноды (по умолчанию 150, порты 443/4443/8443/2053); кто превысил — бан на 10 минут. Адрес магазина, панели, указанные адреса и CGNAT (100.64.0.0/10) не ограничиваются. Режим «Только считать». Своя таблица `inet corgi_guard`, переживает перезагрузку, ufw / fail2ban / CrowdSec не трогает.
- **MSS clamp** — меряет MTU пути до 1.1.1.1 и 77.88.8.8; если он меньше MTU интерфейса — включает ограничение MSS (таблица `inet corgi_mss`). Нода не перезапускается.
- **Файл подкачки** — нужного размера (256 МБ – 16 ГБ) после проверки свободного места, `vm.swappiness=10`.
- **BBR** в «Защите сервера» сначала смотрит виртуализацию и ядро: на OpenVZ/LXC (общее ядро с хостом) шаг пропускается с объяснением, а не падает.
- **Снапшот сервера → скачать** — копия базы панели и файлы всех компонентов (compose, .env, Caddyfile, сайт; без томов), зашифрованы в магазине (последние 5 на сервер); скачивание — с подтверждением 2FA.
- **Ежедневные снапшоты** в заданное время по Москве; по желанию — в чат копий Telegram («Резервные копии → Копия в Telegram»), зашифрованные паролем копий; без пароля ничего не отправляется.
- **Опасная зона** — удалить один компонент (панель — после копии её базы, страницу подписки, Caddy, ноду, сайт SelfSteal, Xray Checker) или очистить сервер целиком; только после ввода имени сервера и подтверждения 2FA. Тома, файлы и копии остаются.

- **Блокировка рекламы на нодах** — «Расширения Remnawave → Блокировка рекламы на нодах»: правило `geosite:category-ads-all → BLOCK` первым в профиле, для всех клиентов, без SSH; выключение убирает только его.
- **Автоподбор SNI для REALITY** — с самой ноды проверяет ~30 известных сайтов: TLS 1.3 + HTTP/2 и скорость; лучшие — в журнале и в состоянии модулей. Ничего не меняет на сервере.
