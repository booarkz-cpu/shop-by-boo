# Релиз v28.121.0 — «Корги Люси: клиент» 1.9.3: баннер в стиле бренда и Люси с глобусом

Дистрибутив: `v28.121.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8.
«Корги Люси: клиент»: `1.9.3`.

Дата: 2026-11-11. Задача владельца по снимку экрана клиента 1.9.0.

## Что изменилось

### Баннер главного экрана

Оформлен как баннеры приложений магазина и Mini App:

- лапка и подпись «Корги Люси», под ней оранжевая черта;
- заголовок «СВОБОДНЫЙ ГАВ В ИНТЕРНЕТЕ!» узким жирным шрифтом;
- наклейка корги справа, тёмный фон с тёплым свечением;
- прежний зелёный значок убран.

Нажатие на баннер по-прежнему подключает VPN.

### Люси с глобусом

Вместо трёх разных наклеек — одна, «Люси у глобуса» из набора бренда:

| Состояние VPN | Что видно |
| --- | --- |
| Выключен | Глобус стоит. Анимации нет |
| Подключение | Глобус светится: тёплое свечение пульсирует |
| Включён | Люси крутит глобус: по нему бегут меридианы, оборот за четыре секунды |

Вращение нарисовано линиями меридианов поверх наклейки. Сама картинка материков не движется: для этого нужна отдельная отрисовка глобуса.

Подробно: [ANDROID_CLIENT_APP.md](new/ANDROID_CLIENT_APP.md).
