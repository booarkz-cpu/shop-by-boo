## Файл резервной копии под паролем

В файле копии лежат ссылки подписок: у кого файл — у того и подписки. В «Резервном копировании» появилось поле
«Пароль для файла (необязательно)». С паролем (от 6 символов) файл шифруется; при восстановлении приложение спросит
пароль. Неверный пароль и изменённый файл отклоняются с понятным сообщением.

- Шифр AES-256-GCM, ключ из пароля — PBKDF2-HMAC-SHA256, 210 000 итераций, своя случайная соль у каждого файла.
- Без пароля файл пишется как раньше; прежние файлы открываются.
- Забытый пароль восстановить нельзя.
- Копия ссылкой и QR-кодом не шифруется.

## Пауза после ошибок обновления

Подписка, которая не обновилась (сервер недоступен, ошибка, пустой ответ), раньше опрашивалась при каждом фоновом
запуске. Теперь следующая автоматическая попытка ждёт 15 минут, потом 30 минут, час — до 6 часов. Первая удача
сбрасывает счётчик. Кнопка «Обновить» работает сразу, без ожидания.

## Исправление разбора StepBot

В v28.155.0 разбор источника StepBot назвал «не найденными» пять функций, которые в магазине есть под другими именами:
конструктор меню бота, импорт пользователей из SQLite, смена тарифа с расчётом, докупка трафика, авто-техрежим при
недоступной панели. Документ исправлен (`docs/REFERENCE_REPOSITORIES.md`, раздел 6). Построчная сверка функций — впереди.
