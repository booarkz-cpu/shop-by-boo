## A4: тексты личного кабинета — из админки

«Бот и кабинет → Личный кабинет → Тексты кабинета»: каждая надпись веб-кабинета (≈200) на русском, английском и украинском. Поиск, «только свои», пустое поле — стандартный текст. Клиенты видят изменения при следующем открытии кабинета, без пересборки. Только обычный текст, до 500 символов; каждое сохранение — в журнале действий (`cabinet.texts.updated`).

- API: `GET /api/public/cabinet-texts` (только свои тексты владельца), `GET` / `PUT /api/admin/cabinet-texts`.
- Список текстов с английским и украинским по умолчанию — `backend/app/assets/cabinet_strings.json`, его пишет `scripts/generate-cabinet-strings.py` из `cabinet/src/i18n.tsx`; тест сверяет, что список не отстаёт от кабинета.
- Если API текстов недоступен, кабинет показывает свои тексты.

## A3: смена сайта SelfSteal без переустановки

«Серверы → Установка Remnawave → задача установки → Модули серверов → Сайт SelfSteal»: другой сайт-шаблон (облачное хранилище, документация, блог о корги) на домене ноды SelfSteal. Переписываются только файлы Caddy на ноде, Caddy перезапускается; нода, ключи REALITY и подписки не меняются, при ошибке возвращается прежний сайт. Новый шаблон сохраняется в установке — «Обновить» его не теряет.

## A2: своё правило маршрута — на эмуляторе

Тест встроенного VPN приложения магазина на эмуляторе (`scripts/mobile/vpn-e2e.sh`) получил четвёртый шаг: правило клиента «блокировать адрес проверки» — VPN подключён, адрес молчит; правило снято — страница снова отвечает через туннель. Для подписок ссылками и в формате Xray JSON.
