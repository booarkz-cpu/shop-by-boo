# Выпуск v28.71.0 — Telegram-бот из админки (этап 13, часть А)

Дистрибутив: `v28.71.0`. Runtime/API: `21.5.1`. Head магазина: `0092_telegram_bot`. Support Pro: `0008` / 3.8. Дата и commit фиксируются тегом выпуска.

## Что сделано

[Telegram-бот: управление из админки](new/TELEGRAM_GUIDE.md):

- **Токен без перезапуска.** «Токен Telegram-бота» — в «Настройках без перезапуска → Telegram» (хранится зашифрованно). Процесс бота проверяет настройку каждые 15 секунд и сам переподключается с новым токеном. Без токена контейнер ждёт, а не падает.
- **Связь с Telegram видна.** Процесс бота пишет состояние в `telegram_bot_state` (миграция `0092_telegram_bot`): `getMe` раз в минуту, последнее обновление от клиентов, последняя ошибка с замаскированным токеном. «Состояние системы» показывает «ok» только тогда, когда Telegram ответил в последние 3 минуты, а не просто когда задан токен.
- **Раздел «Бот и кабинет → Telegram-бот»:**
  - проверка сейчас (`getMe`, `getWebhookInfo`) и удаление webhook другой установки;
  - меню команд на русском, английском и украинском (`setMyCommands`);
  - тестовое сообщение владельцу или в указанный чат;
  - клиенты из Telegram, ошибки бота.
- **Ошибки процесса бота** теперь попадают в «Журнал ошибок» (процесс `bot`).
