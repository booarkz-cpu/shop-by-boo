# Выпуск v28.20.0 — реальные платежи открыты сразу

Дистрибутив: `v28.20.0`. Runtime/API: `21.5.1`. Head магазина: `0073_e2e_v2` (без новых миграций). Support Pro: `0008` / 3.8. Дата и commit фиксируются тегом выпуска.

## Что изменилось

Решение владельца: реальные платежи работают сразу и всегда, без стенда.

- **Платежи открыты с момента установки.** Работают оплата тарифа через YooKassa, Platega и RollyPay, пополнение кошелька и автопродление — как только заданы ключи провайдера и адрес уведомлений. Отдельного допуска нет, по таймеру платежи не закрываются.
- **Аварийная остановка.** Кнопки «Остановить приём платежей» и «Открыть реальные платежи» есть в **Безопасность → Защита и 2FA** и в **Тарифы и оплата → Проверка платежей**. Их видит только администратор, оба действия пишутся в журнал (`payments.real.closed`, `payments.real.opened`). Во время остановки новые оплаты, пополнения и автопродления отвечают «Приём платежей временно остановлен», оплаченные подписки продолжают работать.
- **Staging E2E v2 — по желанию.** Проверка на стенде и приём её результата остались, но на приём платежей не влияют. Сохранение настроек проверки и новый код запуска платежи не закрывают.
- По-прежнему останавливают оплату технический режим и флаг `payments`.

Что не изменилось: каждая оплата подтверждается только после проверки у провайдера (сумма, валюта, номер заказа), уведомления проверяют подпись или IP, повтор уведомления не выдаёт доступ дважды, возврат отзывает доступ.

## Обновление

Миграций нет. После обновления реальные платежи открыты, даже если раньше были закрыты.

```bash
cd /opt/vpn-shop && bash scripts/backup.sh
sudo env APP_DIR=/opt/vpn-shop RELEASE_TAG=v28.20.0 bash /opt/vpn-shop/scripts/update-from-github.sh
```

Перед объявлением запуска сделайте одну покупку своей картой и верните её через **Тарифы и оплата → Возвраты**: так вы проверите оплату, уведомление, выдачу VPN и возврат на своих кассах.

Ожидаемые head: магазин `0073_e2e_v2`, Support Pro `0008`.
