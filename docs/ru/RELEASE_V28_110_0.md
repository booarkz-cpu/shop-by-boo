# Выпуск v28.110.0 — «Корги Люси: клиент» 1.8.1: маскот, App Lock, Geek Mode

Дистрибутив: `v28.110.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8. «Корги Люси: клиент»: `1.8.1` (versionCode 181).

По промпту владельца (N12, фаза 3): вторая часть. Этим выпуском enterprise-клиент N12 выполнен целиком (фазы 1–3, v28.104.0–v28.110.0).

## Что нового

- **Корги Люси на главном экране**: спит, когда VPN выключен; бежит на ракете, пока идёт подключение; радуется с кубком, когда всё работает. Выключается в «Оформлении».
- **App Lock**: вход в приложение и включение/выключение блокировки — только после отпечатка, лица или PIN-кода телефона (системный запрос; своего PIN приложение не хранит). Полминуты вне приложения — без повторного запроса.
- **Geek Mode**: редактор сырого JSON Xray для опытных. «Взять текущий», проверка перед сохранением; сломанный конфиг не запускается — подключается обычный.
- **Виджет**: маскот по состоянию и скорость загрузки/отдачи при подключении.
