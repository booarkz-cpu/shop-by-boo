# Сверка с картой покрытия и снимками для сравнения — v28.37.0

Карта покрытия ([WORKSPACE_COVERAGE.md](WORKSPACE_COVERAGE.md)) сравнивает магазин с четырьмя проектами на зафиксированных
коммитах. В v28.37.0 каждый снимок прочитан заново (исходники сервисов, маршрутов и страниц), функции сопоставлены с
модулями магазина, недостающие перенесены — **своей реализацией**, без копирования кода (лицензии проектов разные).
