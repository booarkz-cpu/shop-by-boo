# Выпуск v28.29.0 — документы магазина, сводка за неделю, проверка восстановления

Дистрибутив: `v28.29.0`. Runtime/API: `21.5.1`. Head магазина: `0076_growth` (без новых миграций). Support Pro: `0008` / 3.8. Мобильные приложения: 2.16.0. Дата и commit фиксируются тегом выпуска.

## Документы: вопросы, правила, политика, оферта

- Новый раздел **Бот и кабинет → Документы**: частые вопросы (текст и пары «вопрос — ответ»), правила, политика конфиденциальности и публичная оферта.
  - Текст на русском обязателен, английский и украинский — по желанию.
  - Простая разметка: заголовки, списки, жирный текст, ссылки.
- **Где видят клиенты:**
  - раздел «Информация» Mini App и личного кабинета; частые вопросы раскрываются по нажатию;
  - бот: команды `/faq`, `/rules`, `/privacy`, `/offer` и `/info`, новый тип кнопки **«Документ»** в дереве кнопок. Длинный текст приходит несколькими сообщениями.
- **Менять может только администратор** (новое право `legal.write`). Каждое сохранение получает номер версии и попадает в журнал действий.
- **Четыре новых баннера с корги Люси:**
  - «Частые вопросы» — в гарнитуре за ноутбуком;
  - «Правила» — в очках со свитком;
  - «Конфиденциальность» — со щитом и замком;
  - «Публичная оферта» — с письмом.

  Стандартных баннеров теперь 25. Свои картинки загружаются в «Баннерах бота».

## Эксплуатация

- **Сводка за неделю.** По понедельникам в 09:00 по Москве владельцу приходит сводка: выручка, оплаты, новые платящие клиенты, регистрации, активные и закончившиеся подписки, возвраты, открытые проблемы. Посмотреть и отправить сразу — «Аналитика → Запуск и оповещения».
- **Проверка восстановления копий.** Раз в неделю магазин восстанавливает последнюю резервную копию во временную базу PostgreSQL и сверяет её с магазином:
  - в копии должно быть не меньше клиентов, подписок и платежей, чем было на момент её создания;
  - временная база удаляется в любом случае.

  Если проверка не пройдена, приходит оповещение «Резервная копия не восстанавливается». В истории копий появилась кнопка «Проверить восстановление», а в «Запуске» — пункт «Проверка восстановления за неделю».
- **Админ-приложения Android и iOS:** вкладка «Запуск» — готовность к оплатам, получатели оповещений, тестовое оповещение, текущие проблемы.
- **Мобильные приложения 2.16.0:** все изменения v28.28.0 и v28.29.0. Новый номер сборки нужен, чтобы магазины приложений приняли обновление.

## Деньги

- Возврат старого платежа без сохранённого срока забирает срок его тарифа, а не весь оставшийся срок подписки.
- Нагрузочный тест оплаты `tests/test_payment_load.py` (PostgreSQL + Redis): 240 одновременных подтверждений по 40 платежам. Каждый платёж выдан ровно один раз, одна запись в журнале, одно продление в Remnawave. Масштаб задаётся через `LOAD_PAYMENTS` и `LOAD_DUPLICATES`.

## Обновление

Миграций нет. Для проверки восстановления пользователю базы из `DATABASE_URL` нужно право создавать базы (`CREATEDB`); у стандартной установки оно есть.

```bash
cd /opt/vpn-shop && bash scripts/backup.sh
sudo env APP_DIR=/opt/vpn-shop RELEASE_TAG=v28.29.0 bash /opt/vpn-shop/scripts/update-from-github.sh
```

После обновления заполните **Бот и кабинет → Документы**: платёжные системы требуют, чтобы оферта и политика конфиденциальности были опубликованы.
