# v21.5.1 stable — завершённая матрица документации

Исправляющий выпуск синхронизирует runtime, установщик, release manifest, публикационный workflow и текущие инструкции. Схема данных не меняется: магазин `0062_support_delivery_identity`, Support Pro `0007` / 3.7.

Главное изменение — [полный реестр критериев завершения](MATRIX_COMPLETION_21_5_1.md). Для каждой внешней проверки и отсутствующей подсистемы указаны граница, обязательная реализация и минимальная приёмка. [Карта покрытия](WORKSPACE_COVERAGE.md) остаётся фактическим перечнем текущих возможностей.

Исправлена устаревшая ссылка на migration head в корневом указателе документации. Команды новой установки и обновления используют точный тег `v21.5.1`.

Это не выпуск новых платёжных или native-возможностей. `production_ready`, `full_function_transfer`, `production_e2e_verified` и `signed` остаются `false`. Настоящие платежи нельзя открывать до application E2E v2 и приёмки каждого включённого агента.
