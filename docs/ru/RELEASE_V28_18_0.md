## Админ-панель

- **Редактор тарифов** (**Тарифы и оплата → Тарифы**): создание, изменение, скрытие и удаление тарифов. Срок 30, 90, 180, 365 дней или свой; трафик в ГБ (0 — без ограничения); число устройств; профиль Remnawave выбирается из списка Internal Squads панели, при недоступности списка UUID вводится вручную. Тариф без профиля помечается предупреждением.
- **Рефералы и партнёры** (**Маркетинг → Рефералы и партнёры**): реферальная программа, партнёры и сверка балансов перенесены сюда из «Безопасность → Восстановление» вместе с заявками на вывод.
- **Аварийный режим:** «Выключить» снимает и технический режим, если нет незавершённого или неудачного восстановления. Раньше магазин оставался в техническом режиме без кнопки выхода. Центр восстановления показывает фактическое состояние аварийного режима.
- **Автоматизация:** текст раздела честно говорит, что правила и кампании пока только сохраняются как план и не выполняются.

## Агент узла

`AGENT_OBSERVE_ACCESS_LOG=1` — агент берёт из журнала Xray пары «клиент → адрес подключения» (до 2000 клиентов и 8 адресов на клиента за цикл) и отправляет их в антиабуз. Магазин сопоставляет клиента с подпиской. Проверки числа сетей и устройств начинают работать без отдельного сборщика.

## API

- `GET /api/admin/remnawave/internal-squads` — список Internal Squads панели для выбора профиля тарифа (`{configured, squads, error}`).
- `POST /api/admin/incident-mode` возвращает `maintenance_mode` и `maintenance_kept`; `GET /api/admin/recovery` — поле `incident_mode`.
- Наблюдение агента (`ObservationIn`) принимает поле `client`.

## Обновление

Миграций нет. Используйте [проверяемый регламент обновления](DISTRIBUTION_UPGRADE_CURRENT.md):

```bash
cd /opt/vpn-shop && bash scripts/backup.sh
sudo env APP_DIR=/opt/vpn-shop RELEASE_TAG=v28.18.0 bash /opt/vpn-shop/scripts/update-from-github.sh
```

После обновления откройте **Тарифы и оплата → Тарифы** и проверьте, что у каждого тарифа выбран профиль Remnawave. Чтобы включить наблюдения из журнала Xray, добавьте на узлах `AGENT_OBSERVE_ACCESS_LOG=1` к переменным агента и перезапустите его.

## Границы выпуска

- Production gate по-прежнему закрыт: runner application E2E v2 не реализован, реальные платежи из панели не открываются.
- Правила автоматизации и кампании не выполняются: движка нет.
