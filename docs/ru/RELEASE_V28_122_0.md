# Релиз v28.122.0 — CI: действия закреплены по хешу, проверка лицензий, аттестация выпуска

Дистрибутив: `v28.122.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8.

Дата: 2026-11-11. Задача владельца: все требования реестра — в статус PASS (этап 23). Раздел CI/CD, требования `REQ-CI-0001` – `REQ-CI-0015`.

## Что изменилось

- **GitHub Actions закреплены за коммитом.** Все 136 вызовов в 19 workflow указывают полный хеш коммита, версия стоит в комментарии.
  Тег действия можно передвинуть на другой код, коммит — нельзя. Dependabot обновляет хеш и комментарий вместе.
- **Проверка лицензий зависимостей** в задаче безопасности CI: Python (магазин и Support Pro) и JavaScript (панель, Mini App, кабинет).
  Зависимость под GPL, AGPL, SSPL, BUSL и подобными останавливает сборку. LGPL и MPL разрешены.
- **Аттестация происхождения** архива дистрибутива. Проверка: `gh attestation verify <файл> --repo booarkz-cpu/shop-by-boo`.
- **Приложения собираются для каждой головы `main`.** Раньше сборка шла, только если коммит менял файлы приложений.
- **[VERSIONING.md](../VERSIONING.md)**: что имеет собственную версию, как она меняется и где журнал изменений.

## Исправленная неполадка

Выпуск v28.119.0 вышел без клиента и файлов версии приложений: между слиянием и публикацией в `main` попал коммит,
который менял только CI, и сборка приложений для него не запустилась. Выпуск v28.120.0 полный. Причина устранена.
