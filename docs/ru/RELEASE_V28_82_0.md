# Выпуск v28.82.0 — транспорты ноды: xHTTP, gRPC и Hysteria2 рядом с TCP + REALITY

Дистрибутив: `v28.82.0`. Runtime/API: `21.5.1`. Head магазина: `0093_ssh_key_rotation` (миграций нет). Support Pro: `0008` / 3.8.

Этап 19, часть A (задача владельца от 2026-11-05: «добавь возможность изменить tcp+reality+selfsni на xhttp, gRPC и Hysteria 2»; набор транспортов — как в remnawave-manager).

## Что сделано

У ноды с SelfSteal к VLESS + TCP + REALITY на 443 можно добавить:

| Транспорт | Порт | Что важно |
| --- | --- | --- |
| VLESS + xHTTP + REALITY | TCP 4443 | те же ключи REALITY и тот же сайт-маскировка |
| VLESS + gRPC + REALITY | TCP 8443 | те же ключи REALITY и тот же сайт-маскировка |
| Hysteria2 | UDP 443 | сертификат домена SelfSteal от Caddy ноды, обновляется сам |

- **При установке**: «Установка Remnawave → нода с SelfSteal» — галочки транспортов.
- **У готовой установки**: «Журнал → Модули серверов → Транспорты ноды» — выбранный набор заменяет текущий; без галочек остаётся только TCP + REALITY.
- Мастер сам открывает порты (если включён ufw), копирует сертификат для Hysteria2 и ставит таймер его обновления, добавляет inbound'ы в профиль, создаёт хосты, включает транспорты в те же сквады, где REALITY, назначает их ноде и перезапускает её. Ошибка откатывает изменения, включая прежний набор транспортов в панели.
- Клиенты получают новые серверы в подписке; приложения «Корги Люси» понимают их с v28.81.0.

Подробно: [REMNAWAVE_EXTENSIONS](new/REMNAWAVE_EXTENSIONS.md#транспорты-ноды-v28820).
