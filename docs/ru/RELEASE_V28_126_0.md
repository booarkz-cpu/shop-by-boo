## Что документы говорят прямо

- Магазин — один процесс API с модулями, а не набор отдельных служб по областям.
- Запрет на доступ к таблицам чужой области и отсутствие циклических зависимостей не проверяются.
- Шины событий нет: события — это webhook и записи в таблицах.
- Окружения staging и второго сервера магазина нет.
