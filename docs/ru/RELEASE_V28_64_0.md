# Выпуск v28.64.0 — актуальные версии языков, баз и компонентов

Дистрибутив: `v28.64.0`. Runtime/API: `21.5.1`. Head магазина: `0089_index_cleanup` (миграций нет). Support Pro: `0008` / 3.8. Дата и commit фиксируются тегом выпуска.

Задача владельца от 2026-11-02, выполнена между этапами 8 и 9. Версии сверены с официальными источниками на 2 ноября 2026 года. Digest образов получены в CI (`.github/workflows/resolve-image-digests.yml`). Подробности по каждому компоненту — в [стеке](../TECH_STACK.md).

## Обновление существующей установки

```bash
cd /opt/vpn-shop && bash scripts/backup.sh
sudo env APP_DIR=/opt/vpn-shop RELEASE_TAG=v28.64.0 bash /opt/vpn-shop/scripts/update-from-github.sh
```

**Закреплённые образы.** `scripts/pin-images.sh` записывает в `.env` закреплённые образы, и они важнее значений из `docker-compose.yml`. Новый шаг обновления `scripts/repin-images.sh` переводит `REDIS_IMAGE` и `CADDY_IMAGE` на версии выпуска:
- если тег уже совпадает с выпуском, ничего не меняется;
- если образ выбран вручную, его можно оставить: `KEEP_PINNED_IMAGES=1`.

**Redis.** Redis 8 читает данные Redis 7, но Redis 7 не прочитает данные, записанные Redis 8. Магазин держит в Redis только кратковременное состояние: блокировки, ограничения частоты, одноразовые коды. Поэтому откат допустим и на пустом томе Redis:

```bash
docker volume rm <проект>_redis_data
```

**Лицензия Redis.** Начиная с версии 8, Redis распространяется под AGPLv3, а также под RSALv2 и SSPLv1 на выбор. Магазин использует официальный образ без изменений, как отдельный сервис, — это допускается всеми тремя лицензиями. Если владельцу нужна лицензия BSD, совместимая замена — Valkey. Её можно подставить через `REDIS_IMAGE`.
