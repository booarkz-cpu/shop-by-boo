# Релиз v28.142.0 — MASQUE: блокировка торрентов действительно работает

Дистрибутив: `v28.142.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8.

Дата: 2026-11-14. Пункт плана MASQUE: «общее правило торрентов».

## Что было

В конфигурации Xray для MASQUE с самого начала стояло правило «BitTorrent → блокировать». Но Xray узнаёт BitTorrent
только при включённом распознавании протокола (sniffing), а у входа MASQUE оно было выключено. Правило ни разу не
срабатывало: торренты шли через туннель. Проверено: без распознавания на рукопожатие BitTorrent через туннель
приходил ответ сервера.

## Что стало

- Распознавание включено только для маршрутизации (`routeOnly`): адрес, который запросил клиент, не подменяется.
- BitTorrent через MASQUE обрывается на всех нодах; обычные сайты работают как раньше.
- Ноды с MASQUE воркер переустанавливает сам один раз (стек версии 4): синхронизация пользователей не перезапускает
  Xray, поэтому новая настройка доходит только так. Туннели переподключатся.

## Чем проверено

Настоящий Xray и HAProxy в CI (`scripts/ci/masque-check.sh`): через туннель к одному и тому же сайту рукопожатие
BitTorrent обрывается без ответа, а HTTP-запрос получает ответ. Без распознавания эта проверка падает — ошибка была
настоящей. `tests/test_masque_panel.py`. На живой ноде не проверено.
