# Выпуск v28.61.0 — интерфейс

Дистрибутив: `v28.61.0`. Runtime/API: `21.5.1`. Head магазина: `0089_index_cleanup` (миграций нет). Support Pro: `0008` / 3.8. Дата и commit фиксируются тегом выпуска.

Этап 7 мастер-задания. Правила интерфейса — [UI_UX_GUIDE](new/UI_UX_GUIDE.md).

## Что изменилось

**Дизайн-система.** Тёмная тема «Remna Dark» уже соответствовала заданию:
- фон `#090D16`, карточки `#0F172A`, синий акцент;
- шрифты Inter и JetBrains Mono — лежат в пакетах приложений.

Теперь это закреплено тестом `tests/test_design_tokens.py`: изменение палитры или шрифтов в админке или кабинете сразу видно в CI.

**Разделы серверов.** Раздел «Серверы» держал 11 разных блоков на одной странице. Теперь он разделён на четыре раздела:
- **«Серверы»** — узлы, автомасштабирование, прогноз нагрузки, пул WireGuard, фильтр рекламы;
- **«Remnawave: панель»** — профили конфигурации, хосты, внутренние сквады, статистика вызовов API панели;
- **«Портал подписки»** — прослойка подписок на своём домене: правила для приложений, блокировка устройств, каталог клиентов, журнал выдачи;
- **«Доступность и качество»** — проверки доступности, RIPE Atlas, качество подключений, скорость у клиентов.

«Мониторинг» теперь показывает только проверки сервисов. «Админ-центр» указывает новые разделы у модулей Remnawave, Subscription Portal и Monitoring.

**Состояния.** У каждого блока с данными есть загрузка, ошибка с причиной и кнопкой «Повторить», пустое состояние с подсказкой и строка успеха. Общие компоненты лежат в `admin/src/components/ui/state.tsx`; ими пользуются «Документы», «Автоматизация», «Запуск и оповещения» и «Админ-центр».

Новый тест `admin/e2e/all-sections.spec.ts` открывает каждый раздел меню — больше 70 — на ширине 1440 и 390 px. Он проверяет:
- заголовок раздела на месте;
- нет экрана ошибки;
- нет горизонтальной прокрутки;
- если данные не загрузились, показаны причина и «Повторить».

**Ответы без Remnawave.** Тест нашёл ошибку: без адреса панели раздел «Пользователи VPN» получал внутреннюю ошибку сервера. Причина — httpx не принимал пустой адрес («missing an 'http://' protocol»). Теперь:
- `RemnawaveNotConfigured` → ответ 503 «Remnawave не настроен: укажите адрес и токен панели (REMNAWAVE_URL, REMNAWAVE_TOKEN)»;
- любая необработанная ошибка панели → ответ 502 «Панель Remnawave недоступна или вернула ошибку». Ответ самой панели пишется в журнал сервера и клиенту не передаётся.

**Чего нет.** Мастера установки Remnawave и менеджера доменов в интерфейсе нет: их нет и в backend. Они появятся на этапах 10 и 11 вместе с работающей функцией.
