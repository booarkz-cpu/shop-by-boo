# Выпуск v28.73.0 — этап 14: проверка касс, журнал уведомлений, юридические документы

Дистрибутив: `v28.73.0`. Runtime/API: `21.5.1`. Head магазина: `0092_telegram_bot` (миграций нет). Support Pro: `0008` / 3.8.

## Что сделано

**Кассы — проверка по коду** ([PAYMENT_INTEGRATION](new/PAYMENT_INTEGRATION.md))
- По каждой кассе и способу оплаты сверено:
  - создание заказа;
  - подпись уведомления;
  - сумма и заказ;
  - повторная проверка у самой кассы перед выдачей;
  - выдача один раз;
  - возвраты, автоплатежи, sandbox.
- Новый контрактный тест `tests/test_payment_contract.py` прогоняет каждую кассу реестра через общую выдачу:
  - заказ другой кассы и другая сумма отклоняются;
  - касса не подтвердила оплату — 503 без выдачи;
  - подтверждённая оплата выдаётся один раз;
  - повторное уведомление — `duplicate`;
  - неудачная выдача остаётся на повтор и выдаётся при следующем уведомлении.

**Журнал уведомлений касс** — «Кассы → Журнал уведомлений», карточка «Уведомления касс» в мобильных админках, `GET /api/admin/payments/events`
- Принятые уведомления: касса, заказ, сумма, статус обработки, число попыток, ошибка.
- Отклонённые уведомления: неверная подпись, другая сумма или заказ, касса не подтвердила оплату. Раньше они не оставляли следа в магазине. Хранятся только касса, время, код ответа и причина — без тела и заголовков, последние 300.

**Юридические документы** — «Документы → Юридические документы», карточка в мобильных админках ([LEGAL_DOCUMENTS](new/LEGAL_DOCUMENTS.md))
- Проекты публичной оферты, политики конфиденциальности и правил пользования по законодательству РФ (ГК РФ, закон «О защите прав потребителей», 152-ФЗ, 149-ФЗ, 54-ФЗ) на русском, английском и украинском.
- Реквизиты продавца подставляются в тексты. Незаполненные не выдумываются — в тексте видно «[укажите …]».
- Документы записываются выключенными: их проверяет юрист, затем владелец включает каждый. Документ, изменённый вручную, не перезаписывается без подтверждения.

**Документы этапа:** [PAYMENT_INTEGRATION](new/PAYMENT_INTEGRATION.md), [PAYMENT_TESTING](new/PAYMENT_TESTING.md), [PAYMENT_SECURITY](new/PAYMENT_SECURITY.md), [LEGAL_DOCUMENTS](new/LEGAL_DOCUMENTS.md).
