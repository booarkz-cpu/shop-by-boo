## Что изменилось

**Вход в приложения без адреса и пароля**

- Адрес магазина вшивается в сборку: Android `-Pcorgi.shop_url=https://api.example.com` или `CORGI_SHOP_URL`, iOS — настройка сборки `CORGI_SHOP_URL`. Поле «Адрес API» на экране входа тогда скрыто.
- Одноразовая ссылка `corgi://login?base=…&code=…`: в боте команда `/app` и `/start app_login`, в кабинете и Mini App — «Безопасность → Войти в приложение». Ссылка живёт 5 минут и работает один раз; в Telegram она идёт через страницу `https://<API>/api/app/open`.
- Кнопки «Войти через Telegram / Яндекс / VK / Google» на экране входа — только для настроенных способов (`GET /api/public/app-login/methods`). OAuth, начатый из приложения (`?app=1`), возвращается в приложение.
- Google-вход: `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_REDIRECT_URI` (`https://<API_DOMAIN>/api/auth/google/callback`); принимается только подтверждённая почта, неподтверждённая регистрация с той же почтой не связывается.
- Безопасность: в базе хранится только хеш кода; код меняется на сессию только нативным клиентом с PKCE (`POST /api/auth/mobile/code` → `/api/auth/mobile/token`); ссылка другого магазина отклоняется, если адрес вшит в сборку.

**Push-кампании по сегментам** — «Приложения: push-кампании»

- Сегменты: подписка заканчивается в ближайшие N дней (без второй, более длинной подписки), закончилась за N дней, ещё не покупали, давно не заходили (N дней), установили приложение, все.
- Предпросмотр охвата (сколько получателей и у скольких включён push) до отправки; сообщение попадает в «Уведомления» и приходит push на все телефоны клиента; журнал отправленных кампаний.

**Аналитика приложений** — «Приложения: аналитика»

- Воронка: установка → вход → «Подключить» → открыли оплату → оплатили (по платежам магазина); экраны с долей дошедших до оплаты; Android/iOS, версии, по дням; периоды 7–180 дней.
- Анонимно: случайный номер установки (в базе — только ключевой хеш), платформа, версия, событие и экран. Без IP, моделей устройств и рекламных идентификаторов; хранение 180 дней; выключается блоком «Анонимная статистика приложения» в макете.

**Розыгрыши и бонусы в приложениях**

- Раздел «Розыгрыши и бонусы» со списком акций из «Розыгрышей» (колесо и конкурсы): участие, результат, приз на баланс.
- Баннер акции на главном экране (блок «home_promo»), пока есть открытый розыгрыш; новый баннер `app-giveaways`.
