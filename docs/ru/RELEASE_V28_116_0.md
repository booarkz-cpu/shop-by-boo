# Релиз v28.116.0 — «Корги Люси: клиент» 1.9.0: главный экран по мастер-промпту v6

Дистрибутив: `v28.116.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8. «Корги Люси: клиент» `1.9.0`.

Дата: 2026-11-11. Задача: раздел Design клиента в мастер-промпте v6 (`REQ-CLIENT-0006`–`0009` в [реестре требований](../REQUIREMENTS_MASTER_REGISTER.md)).

## Что изменилось в клиенте

| Было | Стало |
| --- | --- |
| Слоган «Свободный интернет без лишнего Гав!» | Слоган «Твой интернет. Твои правила. Твоя Люси» |
| Баннер «ЗАЩИТА В ОДНО КАСАНИЕ» | Баннер «Свободный Гав в интернете!» |
| Кнопка-метка «Безлимит» на баннере | Убрана |
| Счётчик «🔥 N дней» в шапке | Убран вместе с огоньком |

- Счётчик дней удалён целиком: приложение больше не записывает дни с подключением, а записанное раньше стирается при первом запуске новой версии.
- Касание баннера по-прежнему подключает VPN, если есть профиль.
- Переводы на английский и украинский обновлены.

## Чем проверено

- Тест на эмуляторе `mainScreenPartsAndAdBlocking`: новые баннер и слоган есть; счётчика, старого баннера и «Безлимит» нет.
- Модульные тесты клиента и ktlint.

## Что нужно от владельца

Ничего. В списке «убрать» мастер-промпта есть слово «маска»: такого элемента на главном экране нет. Если имелась в виду конкретная картинка — пришлите снимок.
