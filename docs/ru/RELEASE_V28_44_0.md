# Выпуск v28.44.0 — пополнение кошелька через Tribute

Дистрибутив: `v28.44.0`. Runtime/API: `21.5.1`. Head магазина: `0081_subscription_proxy` (новых миграций нет). Support Pro: `0008` / 3.8. Мобильные приложения: 3.4.0. Дата и commit фиксируются тегом выпуска.

## Что изменилось

**Tribute — донаты в Telegram на кошелёк**

- Владелец задаёт в «Система → Настройки без перезапуска» ссылку доната Tribute и API-ключ. После этого в кошельке кабинета и Mini App появляется кнопка «Пополнить донатом в Telegram».
- Клиент платит в Telegram. Tribute присылает уведомление, подписанное HMAC-SHA256. Магазин находит клиента по Telegram-аккаунту и пополняет его кошелёк на сумму доната.
- Каждый донат зачисляется один раз. Не зачисляются донаты в чужой валюте, от Telegram-аккаунтов, которых нет среди клиентов, а также другие события; всё это пишется в журнал.
- Tribute не входит в очередь касс: это пополнение баланса, а не оплата счёта.
- Реестр настроек: 226 полей, из них 134 live (+2).

Подробно — [billing_and_taxes.md](../modules/billing_and_taxes.md#tribute-пополнение-кошелька-донатом-в-telegram-v2844).
