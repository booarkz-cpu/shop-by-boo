## Что завершено

Строка матрицы «Plugin runtime/hotload» закрыта. [Регламент](PLUGINS_CURRENT.md).

### Модель безопасности

- Плагин — внешний HTTPS-сервис издателя. Магазин принимает только подписанный пакет-манифест и не выполняет код плагина.
- Пакет устанавливается, только если подпись Ed25519 сходится с активным доверенным ключом издателя. Изменённые после подписи файлы, лишние файлы (код), несовместимый `api_version`, неизвестные права и события, адрес не по HTTPS или во внутренней сети отклоняются.
- Права (`users.read`, `payments.read`, `subscriptions.read`, `notifications.send`) действуют только после явного подтверждения администратором. Ни одно право не открывает контакты, балансы, ссылки подписок и реквизиты.
- У каждого плагина свой API-токен (в базе — только хеш) и секрет подписи событий (зашифрован). Они показываются один раз, ротация сразу отзывает прежний токен. Настройки плагина зашифрованы и доступны только ему.

### Жизненный цикл без перезапуска

- Загрузка, настройка, подтверждение прав, включение, выключение, удаление.
- Новая версия с дополнительными правами ждёт подтверждения, до него работает прежняя.
- Откат к любой загруженной версии в пределах подтверждённых прав.
- Отзыв ключа издателя выключает его плагины.

### События

- «Новый клиент», «Успешный платёж», «Подписка активирована». События берутся из outbox-сканирования без изменения существующих процессов; история до включения плагина не передаётся, повторное сканирование не создаёт дублей.
- Доставка HMAC-SHA256 с меткой времени, повтор с паузой до 6 попыток, окончательный отказ на 4xx, автоматическая остановка плагина после 20 ошибок подряд.

### Интерфейс и инструменты

- Раздел админки **Обслуживание → Плагины**: издатели, загрузка, права версии, настройки, включение, откат, ротация ключей, удаление; разовый показ ключей.
- `scripts/sign-plugin.py` создаёт ключ издателя и подписывает пакет; пример манифеста — `docs/examples/plugin/`.

### Миграция

`0067_plugin_runtime`: `plugin_publishers`, `plugin_packages`, `plugin_installs`, `plugin_deliveries`, `plugin_event_cursors`. Откат запрещён, пока установлены плагины. Новых переменных окружения нет.

## Обновление

Сделайте согласованный backup и используйте [проверяемый регламент обновления](DISTRIBUTION_UPGRADE_CURRENT.md). После запуска проверьте:

```bash
docker compose exec -T backend alembic current
docker compose ps
curl -fsS https://API_DOMAIN/health/ready
```

Ожидаемые head: магазин `0067_plugin_runtime`, Support Pro `0007`.

Публичного каталога плагинов нет. Автотесты имитируют сервис плагина и не проверяют конкретные внешние системы. Внешние payment/SMTP/Remnawave E2E и production gate остаются за оператором. Полный статус — [матрица покрытия](WORKSPACE_COVERAGE.md) и [реестр завершения](MATRIX_COMPLETION_21_5_1.md).
