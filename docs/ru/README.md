# VPN Shop — v27

Актуальная пошаговая инструкция: [VPN Shop](../../README.md). Общий каталог: [DOCUMENTATION.md](../../DOCUMENTATION.md).

Дистрибутив v27 использует runtime/API `21.5.1`. Стабильный канал текущего ядра не подтверждает полный перенос функций или production E2E. Платёжный gate остаётся закрытым. Используйте текущие три агента: YooKassa, Platega, RollyPay; прежние агенты не принимают новые покупки.

Предыдущая редакция сохранена как [исторический документ](../archive/instructions_before_21_0_1/docs__ru__README.md); её команды и обещания не являются текущей инструкцией.
