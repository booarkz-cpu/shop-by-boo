# VPN Shop — v28.33.0

Запуск с нуля: [руководство по запуску](LAUNCH_GUIDE.md). Работа с разделами панели: [инструкции по модулям](modules/README.md). Обзор: [VPN Shop](../../README.md). Общий каталог: [DOCUMENTATION.md](../../DOCUMENTATION.md).

Дистрибутив v28.33.0 использует runtime/API `21.5.1`. Стабильный канал текущего ядра не подтверждает полный перенос функций или production E2E. Реальные платежи открыты с момента установки; администратор может остановить их аварийной кнопкой. Используйте текущие три агента: YooKassa, Platega, RollyPay; прежние агенты не принимают новые покупки.

Новое в выпуске:
- [push-кампании по расписанию и A/B-тест текстов](modules/12-notifications-push.md#стиль-push-уведомлений-и-кампании);
- воронка приложений «установка → вход → тариф → оплата → подключение» ([аналитика](../modules/analytics.md));
- [сверка чеков «Мой налог» по списку доходов](modules/07-payments.md#чеки-в-налоговую);
- встроенный VPN на iOS и push с картинками — готовы к подписи владельца ([модуль 16](modules/16-mobile-apps.md));
- подсказка о работе VPN в фоне на Xiaomi, Samsung, Huawei и возврат в приложение после оплаты;
- [установка с нуля до продакшена](../INSTALLATION.md) и [архитектура модулей](../modules/README.md).
