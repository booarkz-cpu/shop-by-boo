# Руководства VPN Shop by Corgi Lucy

**Русский** · [English](../en/README.md) · [Українська](../uk/README.md)

Здесь собраны инструкции для владельца магазина. Начните с установки, если у вас новый VPS. Для работающего магазина выберите нужную операцию в таблице.

## Скачать мобильные приложения

В [разделе загрузок](../../README.md#скачать-мобильные-приложения) есть магазин, самостоятельный VPN-клиент и Lucy Admin для Android. Для магазина и Lucy Admin на iOS доступны IPA для подписи и ZIP для симулятора. Рядом с каждым файлом указана его контрольная сумма.
