# Выпуск v28.101.0 — клиент «Корги Люси» обновляется сам

Дистрибутив: `v28.101.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8. «Корги Люси: клиент»: `1.6.1` (versionCode 161).

По просьбе владельца (N11): автообновление ядра Xray и функций клиента.

## Что нового

- **Ядро Xray следит за AndroidLibXrayLite само.** Новый workflow «Xray core watch» раз в сутки (03:17 UTC) берёт последний выпуск [2dust/AndroidLibXrayLite](https://github.com/2dust/AndroidLibXrayLite) и коммит его тега. Если коммит отличается от закреплённого в `scripts/mobile/build-xray-aar.sh`, открывается pull request `auto/xray-core-<тег>`: новый коммит, следующая версия клиента (versionCode + 1), строка в заметках клиента. Затем запускаются CI и сборка клиента — AAR собирается из нового коммита, работают unit-тесты и настоящий VPN на эмуляторе. Вливается только при полностью зелёном CI, как и всё остальное.
- **Клиент скачивает новую версию сам.** Раз в сутки по Wi-Fi: проверка манифеста выпуска, загрузка APK только с выпусков этого репозитория, проверка SHA-256; затем уведомление «Обновление готово». Нажатие — системный установщик Android (`PackageInstaller`): поставить приложение молча Android не даёт, подтверждает пользователь.
- **Geo-файлы обновляются ежедневно**, если они скачаны.
- **«О приложении»**: раздел «Обновления» (два переключателя и «Установить» для скачанной версии); в «Информации» — коммит сборки ядра AndroidLibXrayLite, дата последней проверки обновлений и дата geo-файлов.
