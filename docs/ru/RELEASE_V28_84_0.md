# Выпуск v28.84.0 — защита серверов, самовосстановление и управление нодами (из remnawave-manager)

Дистрибутив: `v28.84.0`. Runtime/API: `21.5.1`. Head магазина: `0093_ssh_key_rotation` (миграций нет). Support Pro: `0008` / 3.8.

Этап 19, часть B: недостающее из [remnawave-manager](https://github.com/booarkz-cpu/remnawave-manager) (MIT, © Корги Люси) перенесено в мастер установки и админку.

## Что сделано

- **Защита сервера** («Установка Remnawave → Модули серверов → Защита сервера», любые серверы установки):
  - fail2ban для SSH: 3 ошибки за 10 минут — бан на 2 часа;
  - автоматические обновления безопасности, без перезагрузки;
  - BBR;
  - SSH только с ваших адресов, через ufw. Адрес магазина разрешается всегда, чтобы магазин не потерял сервер. Если ufw выключен, шаг останавливается и ничего не меняет.

  Только свои файлы настроек; откат возвращает прежние файлы и правила.
- **Самовосстановление.** Таймер на самом сервере, каждые 2 минуты: поднимает остановленные контейнеры, перезапускает панель после трёх неудачных проверок `/health`. Работает, даже когда магазин недоступен.
- **Управление нодами** в «Мониторинге нод»: «Выключить» / «Включить», «Изменить» (имя, адрес) — рядом с «Перезапустить»; каждое действие в журнале.

Не переносится из remnawave-manager: вариант с nginx (у нас Caddy), сторонние скрипты от root, отдельный Prometheus (у магазина свой мониторинг), пользователи панели (их ведёт магазин).

Подробно: [REMNAWAVE_EXTENSIONS](new/REMNAWAVE_EXTENSIONS.md#защита-сервера-v28840).
