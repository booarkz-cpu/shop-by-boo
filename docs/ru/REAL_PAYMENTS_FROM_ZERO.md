# Подготовка платежей — v21.5.1

Актуальная пошаговая инструкция: [Подготовка платежей](WORKSPACE_PAYMENTS.md). Общий каталог: [DOCUMENTATION.md](../../DOCUMENTATION.md).

Реальные платежи открыты с момента установки, как только заданы ключи провайдера; администратор может остановить их аварийной кнопкой. Проверка на стенде — по желанию ([E2E v2](STAGING_E2E_V2_IMPLEMENTATION.md)). Используйте текущие три агента: YooKassa, Platega, RollyPay; прежние агенты не принимают новые покупки.

Предыдущая редакция сохранена как [исторический документ](../archive/instructions_before_21_0_1/docs__ru__REAL_PAYMENTS_FROM_ZERO.md); её команды и обещания не являются текущей инструкцией.
