# Выпуск v28.97.0 — смена домена панели

Дистрибутив: `v28.97.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8.

Последняя операция N7 этапа 20, разрешённая владельцем. Всё — в **«Серверы → Установка» → «Сменить домен панели»**.

## Что нового

- **Сменить домен панели** — по шагам, с планом и подтверждением:
  1. Проверка: новый домен указывает на сервер панели (при сертификате Let's Encrypt — обязательно).
  2. Копия базы панели.
  3. Файлы панели (`PANEL_DOMAIN`, `FRONT_END_DOMAIN`, а без отдельной страницы подписки — `SUB_PUBLIC_DOMAIN`) и Caddy пишутся заново, панель и Caddy перезапускаются, проверка `https://<новый домен>`.
  4. Магазин переписывает у себя ссылки подписок `https://<старый>/api/sub/…` → `https://<новый>/api/sub/…` (ссылки отдельной страницы подписки не меняются).
- **Прежний домен остаётся** (по умолчанию): Caddy отдаёт по нему подписки `/api/sub/…` — ссылки, уже добавленные клиентами в приложения, работают — и API магазина (запросы с токеном), всё остальное переадресует 308 на новый домен. Хранится до трёх прежних доменов.
- **«Прежние домены больше не нужны»** — то же действие убирает их из Caddy, когда клиенты обновили ссылки.
- После смены — «Подключить магазин» у установки, чтобы магазин ходил в панель по новому домену (подсказка в карточке).
