# Выпуск v28.48.0 — корпоративные тарифы

Дистрибутив: `v28.48.0`. Runtime/API: `21.5.1`. Head магазина: `0083_corporate_seats`. Support Pro: `0008` / 3.8. Мобильные приложения: 3.4.0. Дата и commit фиксируются тегом выпуска.

## Что изменилось

**Корпоративные тарифы** — «Корпоративный → Компании» в админке, «Компания» в кабинете и Mini App

- **Компания.** У компании есть реквизиты (ИНН, КПП, адрес), тариф, число мест и пул устройств — места × устройства на одно место.
- **Администратор компании:**
  - приглашает сотрудников по ссылке;
  - назначает каждому число устройств из пула;
  - убирает сотрудников;
  - видит счета.
- **Сотрудник** получает собственную подписку на тарифе компании. Если сотрудников больше, чем мест, лишние ждут, пока появится место.
- **Оплата по счёту.**
  - Оператор выставляет счёт на нужное число месяцев. Счёт открывается как печатная страница, его можно сохранить в PDF.
  - Когда деньги пришли, оператор нажимает «Оплачен» — в веб-админке или в мобильной. Доступ всех сотрудников продлевается.
  - Если компания не оплачена, доступ сотрудников приостанавливается.
- Реквизиты продавца для счетов заполняются в той же карточке.

Подробно — [corporate.md](../modules/corporate.md), что сделать владельцу — [OWNER_ACTIONS.md](OWNER_ACTIONS.md).
