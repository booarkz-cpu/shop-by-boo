# Релиз v28.123.0 — безопасность: сканирование образов и секретов, исправленные образы, модель угроз

Дистрибутив: `v28.123.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8.

Дата: 2026-11-12. Задача владельца: все требования реестра — в статус PASS (этап 23). Раздел «Безопасность», `REQ-SEC-0001` – `REQ-SEC-0015`.

## Что изменилось

### Новые проверки в CI

- **Секреты и зависимости.** Trivy ищет в репозитории секреты и уязвимости высокой и критической серьёзности. Сейчас находок нет.
- **Образы.** Каждый образ, который собирает магазин, сканируется. Уязвимость, для которой уже есть исправление, останавливает сборку.
- **Список компонентов (SBOM)** в формате CycloneDX сохраняется артефактом `sbom`: 312 компонентов.
- Исключения записываются в `.trivyignore` с причиной и сроком действия.

### Исправленные образы

Первое же сканирование нашло уязвимости в образах. Исправлено:

| Что | Исправление |
| --- | --- |
| Устаревшие пакеты системы во всех образах | Обновляются при сборке образа |
| pip, setuptools и wheel с вложенными уязвимыми библиотеками | Удаляются из готового образа: для работы магазина не нужны |
| Caddy со старыми библиотеками Go | Обновлён до 2.11.9 |

Осталась одна находка — библиотека внутри Caddy 2.11.9, для которой выпуска Caddy с исправлением ещё нет. Она записана исключением до 2027-01-15.
Подробно: [SECURITY_FINDINGS.md](../SECURITY_FINDINGS.md).
