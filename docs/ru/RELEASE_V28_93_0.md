# Выпуск v28.93.0 — «Установка», часть 2: экстренное восстановление, чек-лист «Анти-РКН», каскад

Дистрибутив: `v28.93.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8.

Задача владельца N7 этапа 20, часть вторая. Всё — в **«Серверы → Установка»**.

## Что нового

- **Экстренное восстановление** — у каждого снапшота файлов кнопка «Восстановить»: файлы компонентов возвращаются на сервер, затем компоненты перезапускаются. Перед этим текущие файлы упаковываются на сервере в `/root/corgi-before-restore-<время>.tar.gz` и возвращаются, если что-то пошло не так. Архив проверяется по SHA-256; путь вне каталогов мастера (`/opt/remnawave*`, `/opt/remnanode`) — отказ без изменений. Подтверждение 2FA.
- **Анти-РКН: чек-лист нод** — по каждой ноде девять пунктов из того, что магазин уже знает: свой сайт SelfSteal; проверка снаружи «в порядке» не старше 7 дней; порт ноды только для панели; отпечаток браузера; запасной протокол; защита ноды; защита сервера; автообновление; ежедневные снапшоты. У невыполненного пункта — «Исправить»: открывается карточка, которая это делает. По сети здесь ничего не проверяется.
- **Каскад нод (мост)** — карточка ведёт в «Расширения Remnawave → Маршрутизация на сервере» (Shadowsocks-мост вход → выход и правила для российских адресов, через API панели).

## Что пока не сделано из N7 и почему

| Операция | Причина |
| --- | --- |
| MTProto-прокси | Нужен образ, закреплённый по digest; Docker Hub недоступен из среды разработки — закрепим через CI отдельным шагом |
| geo-файлы и списки zapret на нодах | Нужно проверить путь ресурсов Xray в образе remnanode на живой ноде, иначе можно подменить встроенные файлы неверно |
| Psiphon | Сторонний клиент с закрытыми частями — нужен аудит лицензии и бинарников |
| CDN (Cloudflare) | Нужен аккаунт и токен Cloudflare владельца |
| Смена домена панели | Меняет ссылки подписок всех клиентов — нужна согласованная миграция со страницей подписки |
