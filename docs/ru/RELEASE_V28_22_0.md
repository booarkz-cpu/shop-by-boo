# Выпуск v28.22.0 — баннеры разделов бота

Дистрибутив: `v28.22.0`. Runtime/API: `21.5.1`. Head магазина: `0074_automation_engine` (без новых миграций). Support Pro: `0008` / 3.8. Дата и commit фиксируются тегом выпуска.

## Новое

- **Баннеры бота.** Каждый раздел бота приходит сообщением «картинка + текст + кнопки». В комплекте 13 стандартных баннеров с мультяшной корги Люси и крупной надписью раздела: «Добро пожаловать», «Меню», «Тарифы», «Подписка», «Промокод», «Мой кабинет», «Кошелёк», «Платежи», «Подарки», «Пригласи друзей», «Поддержка», «Устройства», «Опросы» ([модуль 14](modules/14-bot-miniapp.md#баннеры-бота)).
- **Раздел «Бот и кабинет → Баннеры бота».** Предпросмотр каждого баннера, загрузка своего изображения (PNG, JPG, WEBP до 8 МБ; магазин проверяет и пересохраняет его в JPEG), «Вернуть стандартный», флажок «Показывать» и общий выключатель. Свой баннер можно задать и для каждой кнопки-папки или кнопки-поля из дерева меню.
- **Навигация в одном сообщении.** Нажатие на кнопку-папку меняет картинку, текст и кнопки в том же сообщении (`editMessageMedia`), новые сообщения не копятся.
- Telegram получает каждый файл один раз, дальше бот шлёт его по `file_id`. Подпись длиннее 1024 символов уходит отдельным сообщением после баннера. Если баннер не удалось отправить, раздел придёт текстом.
- Картинка, загруженная раньше в «Изображение для /start», автоматически становится баннером приветствия.

## Обновление

Миграций нет. Контейнер `bot` теперь подключает том `media_data` только на чтение: обновление пересоздаёт контейнер само.

```bash
cd /opt/vpn-shop && bash scripts/backup.sh
sudo env APP_DIR=/opt/vpn-shop RELEASE_TAG=v28.22.0 bash /opt/vpn-shop/scripts/update-from-github.sh
```

Если вы обновляете `docker-compose.yml` вручную, добавьте сервису `bot` строку `- media_data:/data/media:ro` в `volumes`.

Ожидаемые head: магазин `0074_automation_engine`, Support Pro `0008`.
