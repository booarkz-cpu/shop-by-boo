# Релиз v28.134.0 — клиент 1.9.5: пинг сервера показывается один раз

Дистрибутив: `v28.134.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8.

Дата: 2026-11-13. Ошибка со снимка экрана владельца: «Пинг сервера графически отображается дважды».

## Что было

На главном экране «Корги Люси: клиент» у выбранного сервера рядом с «116 ms» стояли два одинаковых значка сигнала.
Один рисовал блок пинга, второй — сама карточка сервера. Из-за нехватки места подпись «VLESS • TCP • REALITY»
обрывалась на «VLESS • TCP •».

## Что стало

- Значок сигнала один — тот, что рядом с цифрами пинга.
- Подпись протокола, если не помещается, обрезается многоточием.

## Чем проверено

UI-тест клиента проверяет, что у выбранного сервера не больше одного значка сигнала. Сборка клиента и тесты в CI.
На телефоне не проверено.

## Как обновиться

Клиент обновится сам, если включено автообновление; иначе — файл `corgi-lusi-client` из этого выпуска.
