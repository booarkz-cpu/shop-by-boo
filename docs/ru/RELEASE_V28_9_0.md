# Выпуск v28.9.0 — сетевая аналитика узлов

Дистрибутив: `v28.9.0`. Runtime/API: `21.5.1`. Head магазина: `0068_network_intel`. Support Pro: `0007` / 3.7. Дата и commit фиксируются тегом выпуска.

## Что завершено

Строка матрицы «Расширенная DNS/ASN/reputation карта» закрыта. [Регламент](NETWORK_INTEL_CURRENT.md).

- Раздел админки **Инфраструктура → Сеть узлов: ASN и репутация**: адреса узлов Remnawave с DNS (A/AAAA), ASN, владелец, префикс, анонс BGP и страна RIR из RIPEstat; репутация IP, жалобы, тип адреса и отметка Tor из AbuseIPDB (при наличии ключа).
- Предупреждения: плохая репутация, Tor, несовпадение страны в панели и RIR, неанонсированный префикс, несколько узлов в одной ASN, только внутренние адреса, ошибка DNS.
- Кэш по IP и источнику со сроком (7 дней для сетевых данных, 24 часа для репутации) и отметкой свежести. При ошибке источника остаются последние данные с отметкой «устарели»; повтор с увеличивающейся паузой.
- Лимит запросов на окно для каждого источника и пауза по HTTP 429 с учётом `Retry-After`.
- Внутренние, зарезервированные и документационные адреса никогда не отправляются наружу; IPv6 поддерживается.
- Ручное обновление адреса узла (не чаще раза в 2 минуты, с записью в журнал).
- Сводка сетей и стран клиентов за 7 дней без отдельных IP-адресов.
- Атрибуция источников в интерфейсе и регламенте: RIPEstat (`sourceapp=corgi-vpn-shop`), AbuseIPDB.

### Настройки и миграция

- Новые переменные `.env`: `NETWORK_INTEL_ENABLED` (по умолчанию `true`), `ABUSEIPDB_API_KEY`. Реестр настроек — 153 поля: 96 live, 55 deployment, 2 workflow.
- Миграция `0068_network_intel`: кэш `network_intel` и состояние лимитов `network_intel_sources`; откат безопасен.

## Обновление

Сделайте согласованный backup и используйте [проверяемый регламент обновления](DISTRIBUTION_UPGRADE_CURRENT.md). Для проверки репутации добавьте `ABUSEIPDB_API_KEY` в `.env` и перезапустите `backend` и `worker`. После запуска проверьте:

```bash
docker compose exec -T backend alembic current
docker compose ps
curl -fsS https://API_DOMAIN/health/ready
```

Ожидаемые head: магазин `0068_network_intel`, Support Pro `0007`.

Автотесты имитируют RIPEstat, AbuseIPDB и DNS. Данные реальных адресов узлов, доступ worker к источникам и соблюдение лимитов вашей учётной записи AbuseIPDB проверяет оператор. Внешние payment/SMTP/Remnawave E2E и production gate остаются за оператором. Полный статус — [матрица покрытия](WORKSPACE_COVERAGE.md) и [реестр завершения](MATRIX_COMPLETION_21_5_1.md).
