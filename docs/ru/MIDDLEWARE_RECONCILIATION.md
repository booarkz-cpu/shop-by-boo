# Сверка с remnawave-subscription-middleware — v28.38.0

Проект: [Mrvibecodic/remnawave-subscription-middleware](https://github.com/Mrvibecodic/remnawave-subscription-middleware), прочитан на коммите `9a8072e` от 28.10.2026. Это прослойка на PHP перед доменом подписки Remnawave.

В репозитории нет файла лицензии, поэтому по умолчанию все права у автора. Магазин переносит только идеи: реализация своя, на Python, внутри магазина, код не копировался. Эндпоинты панели проверены на живом Remnawave 3.4.7 в CI.

Статусы:
- **Перенесено** — есть в v28.38.0: код, тесты, интерфейсы;
- **Было** — уже было в магазине;
- **Не переносится** — с указанием причины.
