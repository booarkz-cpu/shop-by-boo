# Платежи

Настройка кассы, переменные окружения и порядок проверки без денег описаны в [инструкции по платежам](../wiki/ru/Payments.md). Возможности каждой интеграции и статус её проверки приведены в [реестре провайдеров](../PAYMENT_PROVIDER_INVENTORY.md).

Для включённой кассы используйте [регламент приёмки](PAYMENTS_LIVE_CHECKLIST.md). Результаты проверок привязывайте к конкретной кассе и среде. Общий каталог инструкций — [DOCUMENTATION.md](../../DOCUMENTATION.md).

Предыдущая редакция сохранена как [исторический документ](../archive/instructions_before_21_0_1/docs__ru__PAYMENTS.md); её команды и обещания не являются текущей инструкцией.
