# Выпуск v28.38.0 — прослойка подписки, журнал изменений, сессии и аномалии, срок с первого подключения, WireGuard, приложения 3.4.0

Дистрибутив: `v28.38.0`. Runtime/API: `21.5.1`. Head магазина: `0081_subscription_proxy`. Support Pro: `0008` / 3.8. Мобильные приложения: 3.4.0. Дата и commit фиксируются тегом выпуска.

Описание модулей — [docs/modules/subscription_proxy.md](../modules/subscription_proxy.md). Что взято из remnawave-subscription-middleware и Remnawave Admin — [сверка](MIDDLEWARE_RECONCILIATION.md).

## Что изменилось

**Прослойка подписки** — «Серверы → Прослойка подписки»

- Клиенты обновляют подписку через ваш домен (`SUB_PROXY_DOMAINS` или `https://<API_DOMAIN>/sub/<shortUuid>`), магазин забирает её у панели по внутреннему адресу. Ссылка панели продолжает работать.
- Ссылка зеркала показывается клиентам в кабинете, Mini App, боте, приложениях и у реселлеров.
- Блок устройства по HWID с заглушкой и вашим текстом; HWID из User-Agent для клиентов без своих заголовков.
- Правила заголовков по приложению; доп. ключи для сквада и серверы второй подписки — только для активных подписок и списков ссылок.
- Журнал запросов (14 дней) и каталог версий клиентов с отметкой «устарел».

**Вебхуки и журнал изменений** — «Интеграции»

- Пересылка вебхуков панели на несколько адресов, каждому — своя подпись.
- «Кто менял пользователя»: изменения полей с меткой «магазин» или «извне», CSV с обезличиванием; лента «События подписок» на дашборде.
- «Мониторинг → Запросы к панели»: кто в магазине и как часто вызывает API панели.

**Клиенты и тарифы**

- Срок с первого подключения: подписка активна сразу, срок идёт с первого подключения (ожидание до 30 дней).
- Льготный доступ через ограниченный сквад; сквад тарифа возвращается с оплатой.
- Сессии и аномалии: IP, провайдеры и страны по нодам, правила «больше N» и «× лимит устройств», «Сейчас онлайн», сброс соединений, география клиентов.
- Трафик по дням и серверам в карточке клиента, кабинете, Mini App и приложениях.
- Пул WireGuard / AmneziaWG и ключи подключения с QR; команда бота `/keys`.

**Кассы**

- CloudPayments и Lava (карты, СБП): уведомление принимается только с правильной подписью и после повторной проверки статуса через API кассы; обе встают в очередь касс и способы оплаты. Ключи — в «Настройках» или `.env` (`CLOUDPAYMENTS_*`, `LAVA_*`), подробно — [оплата](../modules/billing_and_taxes.md#cloudpayments-и-lava-v2838).

**Серверы и эксплуатация**

- Полный редактор хостов (адрес, порт, инбаунд, SNI, Host, путь, тег) и Internal Squads (название, инбаунды).
- Rich-уведомления в Telegram: заголовок, цитата, таблица и кнопки в нужный раздел админки.
- Порог срабатываний торрентов в час: игры и опрос DHT не отмечаются.
- Провайдер для отчётов о связи с iOS определяется по ASN внешнего IP.
- Тестовый стенд отдаёт те же заголовки безопасности, что продакшен (сканирование ZAP).

## Обновление

Автообновление поставит выпуск само ночью; вручную — «Выпуски → Автообновление → Проверить и обновить сейчас» или

```bash
bash /opt/vpn-shop/scripts/backup.sh
sudo env APP_DIR=/opt/vpn-shop RELEASE_TAG=v28.38.0 bash /opt/vpn-shop/scripts/update-from-github.sh
```

Миграция `0081_subscription_proxy` только создаёт новые таблицы — обновление без простоя работает. Новые необязательные ключи `.env`: `SUB_PROXY_DOMAINS` (домены зеркала подписки для Caddy), `CLOUDPAYMENTS_PUBLIC_ID`, `CLOUDPAYMENTS_API_SECRET`, `LAVA_SHOP_ID`, `LAVA_SECRET_KEY`, `LAVA_WEBHOOK_SECRET`. Остальное включается в админке и выключено по умолчанию. Для сессий, срока с первого подключения и журнала изменений нужен вебхук панели и токен API с доступом к `connections` и `bandwidth-stats`.

Что можете сделать только вы (подпись приложений, Hetzner, переключение, кассы, домен зеркала) — [OWNER_ACTIONS.md](OWNER_ACTIONS.md).
