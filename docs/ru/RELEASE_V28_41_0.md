# Выпуск v28.41.0 — кассы AuraPay и Anore

Дистрибутив: `v28.41.0`. Runtime/API: `21.5.1`. Head магазина: `0081_subscription_proxy` (новых миграций нет). Support Pro: `0008` / 3.8. Мобильные приложения: 3.4.0. Дата и commit фиксируются тегом выпуска.

## Что изменилось

**Кассы AuraPay и Anore** — «Платёжные агенты»

- Карта и СБП через AuraPay и Anore. Касса встаёт в очередь касс и в выбор способа оплаты, как только заданы ключи: «Система → Настройки без перезапуска» (секреты хранятся зашифрованно) или `.env`.
- Уведомления подписаны HMAC-SHA256:
  - AuraPay — значения полей по алфавиту ключей, секретный ключ №2;
  - Anore — тело целиком; заголовок `Anore-Event` должен совпадать с событием в теле.
- Запросы к Anore тоже подписаны.
- Подписка выдаётся только после повторной проверки платежа в API кассы. Проверяются статус, заказ и сумма, у Anore ещё валюта и сумма в рублях.
- Реестр настроек: 219 полей, из них 127 live (+6 ключей касс).

Подробно — [billing_and_taxes.md](../modules/billing_and_taxes.md#aurapay-и-anore-v2841), что сделать владельцу — [OWNER_ACTIONS.md](OWNER_ACTIONS.md).

## Проверки

- `tests/test_payments_aurapay_anore.py` — на моках API касс:
  - страница оплаты;
  - подписи запросов и уведомлений;
  - порядок полей в подписи AuraPay;
  - повторная проверка платежа;
  - отказ при неверной подписи, чужом событии или чужом заказе.
- Боевая проверка — на договоре и ключах владельца.

## Не вошло
