# Карта функционального покрытия

Для всех открытых строк определены конкретные критерии завершения и минимальная приёмка: [реестр v21.5.1](MATRIX_COMPLETION_21_5_1.md). Статус повышается только после реализации и указанного evidence.

В v28.4.0 production-код очищен от `pass`, `NotImplementedError`, TODO/FIXME и урезанных шаблонов; контракт проверяется `scripts/check-runtime-placeholders.py`. Архитектурно корректные no-op миграции используют явный `return None`, а обработчики отказов журналируют результат вместо молчаливого подавления.

Проверены актуальные исходники четырёх указанных проектов. Ниже отмечены реально имеющиеся части магазина и незавершённые требования. Это не заявление о полном переносе. Код этих проектов не скопирован: существующая лицензия магазина сохранена. Рекламные ссылки, логотипы и внешнее брендирование этих проектов в интерфейсах не добавляются.

## Устранение дублей

- Один клиентский интерфейс вместо отдельных реализаций кабинета и Mini App.
- Один каталог новых внешних агентов.
- Одна функция привязки реферала для Telegram и кабинета.
- Одна карточка клиента из поиска вместо фиксированного пользователя и отдельного дублирующего входа.
- Неиспользуемая копия исходников админки удалена.
- Системные страницы клиентского меню объединяются по kind и slug.

Физически не удалены legacy settlement-адаптеры, исторические записи и Support Pro. Это совместимость. Support Pro теперь использует основной мост для связанных обращений; самостоятельные каналы и remote mapping имеют отдельные границы. Магазинная история поддерживает previewed merge/split.

## Реестр оставшейся работы

Незавершённые области перечислены без скрытых «прочих» пунктов: проверка ваших касс (по желанию — staging E2E v2) и внешний SMTP/VPN E2E; проверка email-канала и моста Zendesk/Freshdesk на реальных учётных записях; проверка распознавания торрентов и глубокого анализа и терминала узлов на ваших серверах; проверка приёма почты (MX) и почтового домена и отчётов DMARC на реальном домене; проверка push, виджета и профилей на реальных устройствах; подписанные мобильные пакеты и визуальная приёмка. Критерии для каждой области: [матрица завершения](MATRIX_COMPLETION_21_5_1.md).
