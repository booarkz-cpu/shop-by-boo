# Выпуск v28.24.0 — баннеры с фирменной Люси и свежие скриншоты

Дистрибутив: `v28.24.0`. Runtime/API: `21.5.1`. Head магазина: `0075_app_config` (без новых миграций). Support Pro: `0008` / 3.8. Дата и commit фиксируются тегом выпуска.

## Что изменилось

- **19 баннеров в фирменном стиле.** Корги Люси из фирменного рисунка на солнечной террасе, белая подпись «Корги Люси · Свободный Гав!», название раздела на жёлтой ленте с лапками, наклейка-символ раздела, реплика Люси в облачке и сердечки. Разделы бота: «Добро пожаловать!», «Меню», «Тарифы», «Подписка», «Промокод», «Мой кабинет», «Кошелёк», «Платежи», «Подарки», «Пригласи друзей», «Поддержка», «Устройства», «Опросы»; разделы Mini App: «Главная», «Пополнение баланса», «Пробный период», «Подключение», «Серверы», «Информация». Свои баннеры, загруженные в «Баннерах бота», не меняются.
- **Генератор.** `scripts/bot-banners/prepare.py` вырезает Люси и фон из рисунка (`scripts/bot-banners/source/`), `scripts/bot-banners/render.py` собирает баннеры; шрифт Balsamiq Sans (OFL).
- **Свежие скриншоты README:** все разделы админ-панели (66 снимков, включая «Конфигурацию Mini App» и «Баннеры бота»), кабинет (21, включая «Информацию»), Mini App (7) и чаты бота с новыми баннерами (`scripts/screenshots/bot_chat.py`).
- Кабинет: баннер раздела на широком экране не шире 760 px.

## Обновление

Миграций нет.

```bash
cd /opt/vpn-shop && bash scripts/backup.sh
sudo env APP_DIR=/opt/vpn-shop RELEASE_TAG=v28.24.0 bash /opt/vpn-shop/scripts/update-from-github.sh
```

Ожидаемые head: магазин `0075_app_config`, Support Pro `0008`.
