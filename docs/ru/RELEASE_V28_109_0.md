## Что нового

- **Долгое нажатие на плитку** в шторке открывает список серверов.
- **Управление из Tasker и других приложений**: широковещательные Intent `shop.corgi.client.action.CONNECT`, `…DISCONNECT`, `…TOGGLE`, необязательный extra `server` — номер сервера. Выключено по умолчанию («Подключение» → «Управление из других приложений»), потому что отправить их может любое приложение на телефоне.
- **Экспорт логов .zip**: «Журналы туннеля» → «.zip» — все журналы и короткая справка о приложении и устройстве одним архивом, сохраняется туда, куда выберет пользователь.

Дальше в фазе 3: виджеты, App Lock, маскот, Geek Mode.
