## Изменения

«Скачать мои данные» теперь включает email, дату его подтверждения email_verified_at и VK ID основного владельца. Раньше эти сведения присутствовали у объединённых login_aliases, но отсутствовали в основном user-объекте. Telegram/Yandex и существующие категории сохранены. Парольный хеш и passkey handle в выгрузку не добавлены.

Для ответов /api/me/privacy/ применяется Cache-Control: no-store в существующем middleware. Это запрещает HTTP-кешам сохранять ответ; уже скачанный пользователем JSON остаётся отдельной чувствительной копией. Авторизация и удаление аккаунта не меняются.

Регрессии проверяют связанные/отсутствующие идентификаторы, отсутствие чужих данных и контрольных секретов, а также HTTP200/401 через реальный обработчик/FastAPI/middleware на SQLite/PostgreSQL. Карта данных актуализирована по коду.

## Ломающие изменения

Нет. В user-объект выгрузки добавлены три поля, прежние поля и категории сохранены. Клиентам, кешировавшим privacy-ответы, следует учитывать no-store. Подтверждение доступа остаётся обязательным.
