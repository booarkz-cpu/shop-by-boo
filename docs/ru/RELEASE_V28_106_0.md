# Выпуск v28.106.0 — «Корги Люси: клиент» 1.7.2: доверенные Wi-Fi

Дистрибутив: `v28.106.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8. «Корги Люси: клиент»: `1.7.2` (versionCode 172).

По промпту владельца (N12, фаза 2 «Trusted Networks»): дома VPN на паузе, вне дома — сам включается.

## Что нового

- **«Подключение» → «Доверенные Wi-Fi»**: список имён сетей (SSID, до 20). В них туннель встаёт на паузу; в мобильной сети и любом другом Wi-Fi — сразу включается снова. Включается обратно только то, что поставила на паузу эта функция: выключенный вручную VPN остаётся выключенным.
- Срабатывает по системному сигналу смены сети — даже когда приложение закрыто.
- **Разрешения.** Имя Wi-Fi Android показывает приложениям только с доступом к геолокации; чтобы пауза срабатывала в фоне — «Разрешить всегда». Кнопка «Добавить текущую сеть» спрашивает разрешение; имя можно вписать и вручную. Для публикации в Google Play фоновая геолокация требует отдельной декларации в консоли.
