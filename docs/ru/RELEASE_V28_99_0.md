# Выпуск v28.99.0 — свой сервер Psiphon на нодах

Дистрибутив: `v28.99.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8.

По просьбе владельца (N7): установка psiphond на ноды через админ-панель. Всё — в **«Серверы → Установка» → «Сервер Psiphon (psiphond)»** (экспертный режим).

## Что это и чего это не делает

- Это **ваш собственный сервер Psiphon**, а не публичная сеть Psiphon Inc.: к нему подключаются только клиенты, которым вы дали его конфиг (`TargetServerEntry`). Обычные приложения Psiphon из магазинов приложений к нему не подключатся — нужен ConsoleClient Psiphon или своя сборка клиента Psiphon.
- psiphond не связан с Remnawave: пользователи, лимиты и оплата магазина на него не действуют. Это отдельный «аварийный» способ подключения для тех, кому вы сами выдадите конфиг.

## Что нового

- **Установка на ноду** планом с подтверждением: порт (по умолчанию TCP 10443; порты ноды заняты — план откажет) и протокол — **OSSH** (обфусцированный SSH) или **TLS-OSSH** (внутри TLS).
- psiphond **собирается на ноде из исходников** [Psiphon-Labs/psiphon-tunnel-core](https://github.com/Psiphon-Labs/psiphon-tunnel-core) (GPL-3.0) из закреплённого коммита `fc35a756…` в закреплённом образе Go (`golang:1.26-bookworm@sha256:5de7c99e…`): готовые бинарники ниоткуда не скачиваются, коммит сверяется после загрузки. Первая сборка — несколько минут.
- Работает как служба `corgi-psiphon` под своим системным пользователем без привилегий (`NoNewPrivileges`, `ProtectSystem=strict`, пустой набор capabilities); ufw, если включён, открывает только его порт.
- Ключи сервера создаются один раз (`/opt/corgi-psiphon`, права 0600) и сохраняются при повторном «Включить»; запись сервера в журнал шагов не попадает.
- После установки в карточке — **«Скачать конфиг клиента»** (JSON для ConsoleClient: локальные SOCKS 1080 и HTTP 8080, только этот сервер). Список — `GET /api/admin/install/psiphon` (право `provision_nodes`).
- «Выключить» останавливает и удаляет службу, файлы и правило порта (системный пользователь `corgi-psiphon` остаётся — без входа и без файлов).
