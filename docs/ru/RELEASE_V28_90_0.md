# Выпуск v28.90.0 — маскировка нод, порт ноды только для панели, клиент 1.5.0, лицензия 2.9

Дистрибутив: `v28.90.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8. Приложения магазина: 3.5.0, «Корги Люси: клиент» — **1.5.0**.

Задачи владельца этапа 20 (2026-11-07): N2, N3, N4, N5, N6, N9 ([BACKLOG](new/BACKLOG.md)). Всё управляется из админки.

## N5: одна нода — все протоколы, отпечаток браузера, порт ноды только для панели

«Установка Remnawave» → мастер (SelfSteal) или «Модули серверов → Протоколы и маскировка»:

- **Все протоколы одной кнопкой** — «Все протоколы на этой ноде»: VLESS + TCP + REALITY (443), xHTTP + REALITY (4443), gRPC + REALITY (8443), Hysteria2 (UDP 443) и новый VLESS + TCP + TLS (2053).
- **Отпечаток браузера (uTLS)**: Firefox по умолчанию; Chrome, Safari, iOS, Android, Edge, QQ, случайный. Ставится во все хосты ноды в панели, в том числе созданные раньше (кроме Hysteria2 — у QUIC отпечатка нет); при ошибке прежние значения возвращаются.

«Модули серверов → Порт ноды для панели» (и галочка в мастере):

- Служебный порт ноды (2222) закрыт для всех, кроме адреса панели, **всегда** — своя таблица nftables `inet corgi_node_port` (переживает перезагрузку), а не только при включённом ufw. Если ufw включён, в нём то же правило.
- Сразу на всех нодах установки; дополнительные адреса — например, новый адрес панели перед переездом.
- Если после правила панель не видит ноду, правило снимается само и проверка сообщает об этом.
- Проверка в CI: `scripts/ci/node-port-guard.sh` запускает этот же скрипт в network namespaces: панель подключается к порту, посторонний — нет, другие порты ноды открыты, `delete` открывает порт.

## N6: TLS 1.2 / TLS 1.3

Для «VLESS + TCP + TLS» — версии TLS «от» и «до» в админке (`minVersion` / `maxVersion`). REALITY и Hysteria2 работают только по TLS 1.3 — так устроены протоколы; админка это объясняет.

## N9: «Корги Люси: клиент» 1.5.0 — новый главный экран

По промпту и скриншоту владельца:

- Архитектура MVVM: `VpnViewModel` + `VpnUiState` на StateFlow (статус, время сессии, скорость и трафик, блокировка рекламы, стрик); экран (`HomeContent`) только рисует состояние. Подключение настоящее (VPN-сервис и Xray), без имитации.
- Три состояния с анимацией (`updateTransition`, `AnimatedVisibility`): кнопка 180 dp — серая, с кольцом при подключении, оранжевый градиент со свечением; статистика появляется при подключении; пятна-градиенты фона.
- Слоган — сразу под названием; баннер «ЗАЩИТА В ОДНО КАСАНИЕ» с бейджем «Безлимит» нарисован приложением (текст больше не обрезается); карточка сервера с иконкой сигнала по задержке; «🔥 N дней» — стрик дней с подключением (считается на телефоне); «Поделиться»; тактильный отклик.
- «Блокировка рекламы» — настоящая: правило `geosite:category-ads-all → block` первым в конфигурации Xray (нужны geo-файлы — экран подскажет); при включении во время подключения — «заработает после переподключения».
- Превью `@Preview` всех трёх состояний в светлой и тёмной теме; фон #09090B, карточки #18181B.
- ktlint (закреплён по SHA-256) в CI клиента для нового кода; шаблон описания PR; `scripts/open-pr.sh` — ветка → коммит выбранных файлов → PR (прямой push в main и `git add .` не используются).

## N3: автообновление сторонних модулей

Dependabot теперь следит за всем: pip, npm (админка, кабинет, Mini App), Gradle трёх Android-приложений, базовые образы всех Dockerfile, образы compose-файлов, GitHub Actions. Сверено: «Обновления → Автообновление Remnawave» (v28.74) обновляет панель, все ноды (включая добавленные «Добавить ноду») и страницу подписки — по расписанию и кнопкой, с копией базы панели и откатом; настройки модулей (протоколы, отпечаток, сайт SelfSteal, ядро Xray) сохраняются, потому что обновление берёт последние параметры установки.
