# Выпуск v28.105.0 — «Корги Люси: клиент» 1.7.1: Smart Failover

Дистрибутив: `v28.105.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8. «Корги Люси: клиент»: `1.7.1` (versionCode 171).

По промпту владельца (N12, фаза 2 «Smart Network & Automation»): авто-переключение при обрыве сервера.

## Что нового

- **«Подключение» → «Авто-переключение»** (по умолчанию выключено). Пока туннель работает, раз в 10 секунд «URL проверки» открывается через туннель — через служебный SOCKS-вход Xray на 127.0.0.1 с паролем этого подключения (тот же, что показывает внешний IP).
- Нет ответа дольше заданного — **15, 30, 60 или 120 с** — клиент сам выбирает **самый быстрый другой сервер** провайдера по последним замерам пинга (без замеров — следующий в списке), пишет в журнал «failover», запоминает выбор и поднимает туннель заново. Пользователю ничего делать не нужно.
- Для «Автовыбора» не нужно: балансировщик Xray уже уходит с упавшего сервера. Для полного JSON-конфига и подписок с готовыми конфигами не выполняется.
