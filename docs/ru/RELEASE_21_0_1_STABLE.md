# v21.0.1 stable — рефералы, резервирование и документация

Дата: 2026-10-03. Обновление stable текущего ядра после v21.0.0. [Матрица](WORKSPACE_COVERAGE.md) сохраняет фактические границы остальных незавершённых областей.

## Реализовано

- До пяти реферальных уровней, снимки получателей/процентов при создании checkout, покупке кошельком и intent автопродления.
- Повтор начисления без второй награды, отмена всех уровней при полном возврате, отрицательный баланс после clawback уже выведенной награды.
- Обезличенный граф собственной сети в кабинете, настройка программы в админке, статистика с исключением отменённых наград. [Инструкция](REFERRALS_CURRENT.md).
- Согласованный CLI backup двух баз и файлов, секреты внутри зашифрованного bundle, потоковый AES-GCM/scrypt, проверка целостности и возобновление writers при ошибке. [Регламент](BACKUP_CURRENT.md).
- Закреплённый stable wrapper установки; актуальные команды SSH/Termius, каталог API из OpenAPI, регистр руководств, ясное отделение прошлых инструкций. Исправлены перепутанные loopback-порты кабинета и Mini App.

## Миграция и совместимость

Head магазина `0054_referral_levels`, Support Pro `0007`. Старая одноуровневая история и старые intents не получают дополнительные уровни задним числом. Downgrade при наличии новых финансовых строк запрещён. Сначала выполните согласованный backup и проверку на отдельном контуре. [Обновление](WORKSPACE_UPGRADE.md).

ZIP содержит исходники, а не установленный сервер или подписанные APK/IPA. Вложения: исходный архив, SHA256, detached manifest с точным commit и успешным CI run, статус мобильной подписи. Публикация производится после полного CI на merge commit main.

## Проверки

Новые финансовые сценарии проверяют снимки условий, ограниченные аккаунты, приватность, возвраты, повторы и PostgreSQL-конкуренцию. Backup-тесты проверяют сохранение обеих баз/файлов/секретов, возобновление writers и отказ на повреждение/обрезанный поток/чужой пароль. Полный CI также проверяет прежнее ядро, миграции, Support Pro, зависимости, web/Chromium, контейнеры и mobile compilation. Внешний restore drill на VDS владельца ещё нужен.

## Сохраняющиеся ограничения

`production_ready=false`, `full_function_transfer=false`, `production_e2e_verified=false`, `signed=false`. Application E2E v2, полный партнёрский кабинет, объединение аккаунтов, клиент/native passkeys, внешние каналы/merge-split поддержки, импорт и расширенные операторские/native функции остаются незавершёнными. Подписанные production APK/IPA требуют Android/Apple credentials владельца; компиляция не заменяет подпись и проверку VPN-туннеля.

Лицензия 2.3 уточняет включение авторских реферальных и backup-модулей без изменения разрешений. [LICENSE](../../LICENSE).
