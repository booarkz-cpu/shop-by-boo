# Релиз v28.131.0 — MASQUE: учёт трафика в лимите тарифа и число устройств как в тарифе

Дистрибутив: `v28.131.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8.

Дата: 2026-11-13. Решения владельца от 2026-11-12: трафик MASQUE в лимите тарифа — настройка в панели; одновременных
туннелей у подписки — как устройств в тарифе ([OWNER_DECISIONS.md](../OWNER_DECISIONS.md), решения 1 и 2).

## Главное

Раньше MASQUE был безлимитным и без ограничения устройств. Теперь магазин считает его трафик и ограничивает число
одновременных туннелей так же, как тариф ограничивает устройства.

## Что изменилось

### Трафик MASQUE и лимит тарифа

- Раз в 5 минут магазин забирает с каждой ноды, сколько прошло по каждой подписке, и копит это.
- В блоке «MASQUE: ноды и подписка» появилась настройка **«Засчитывать трафик MASQUE в лимит тарифа»**. Она включена.
- Когда она включена, трафик MASQUE складывается с трафиком, который насчитала панель Remnawave. Как только сумма
  достигает лимита тарифа, доступ MASQUE у подписки снимается. Остальные протоколы отключает сама панель по своему счёту.
- Когда панель начинает новый период, счётчик MASQUE обнуляется и доступ возвращается.
- Когда настройка выключена, MASQUE безлимитный.

### Устройств — как в тарифе

Одновременных туннелей у подписки столько, сколько устройств разрешает её тариф. Лишнее устройство туннель не получает;
когда одно из работающих отключается, место освобождается. Если в тарифе устройства не ограничены, ограничения нет.

Лимиты применяются на ходу: ни Xray, ни HAProxy при этом не перезапускаются.

### Ссылка MASQUE в боте

Команда `/keys` показывает и ссылку MASQUE, если она есть у покупателя и лимит тарифа не исчерпан.

### Безопасность: API Xray без порта

Управляющий API Xray слушал порт на 127.0.0.1. Основное ядро ноды работает в сети хоста, и при старой его версии
покупатель VPN мог обратиться к 127.0.0.1 ноды — а пароля у этого API нет. Теперь API — unix-сокет в каталоге,
доступном только двум контейнерам MASQUE.

### Обновление уже установленных нод

Ноды, на которые MASQUE ставился выпусками v28.129.0 и v28.130.0, магазин переустановит сам при первом проходе после
обновления. Туннели на них переподключатся один раз.

## Чем проверено

- `scripts/ci/masque-check.sh` на настоящих Caddy, Xray 26.11.9 и HAProxy 3.2: при лимите в одно устройство второй
  клиент туннель не получает, первый продолжает работать, после его ухода второй подключается; лимит снимается на ходу;
  HAProxy не перезагружается; трафик читается и обнуляется; Xray поднимается после перезапуска; у API нет TCP-порта.
- `tests/test_masque_panel.py` — счётчик, правило лимита, новый период, переустановка старой ноды.
- `admin/e2e/masque-panel.spec.ts`, `cabinet/src/masque.test.tsx`.

## Что важно знать

- Доступ MASQUE снимается не мгновенно: трафик читается раз в 5 минут, панель опрашивается не чаще раза в 15 минут
  на подписку. За это время можно выйти за лимит.
- Если панель не отвечает, с лимитом сравнивается один трафик MASQUE.
- Без данных панели о периоде счётчик MASQUE обнуляется с началом календарного месяца.
- Счётчик трафика на ноде живёт в памяти Xray: если Xray перезапустился между двумя чтениями, трафик за эти минуты
  не учтётся.
- Лимит туннелей считается на каждой ноде отдельно.

## Чего пока нет

- Ссылки MASQUE в приложениях Android и iOS; поддержки в клиенте «Корги Люси».
- Проверки на VPS с настоящим доменом и на телефоне.

## Что нужно от владельца

Ничего. Если MASQUE должен быть безлимитным — снимите настройку «Засчитывать трафик MASQUE в лимит тарифа».
