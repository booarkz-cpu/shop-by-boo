## Обновление приложений без участия человека

Все три приложения Android (клиент, приложение магазина, приложение администратора):

- проверяют GitHub каждые 6 часов по любой сети (было: раз в сутки; клиент — только по Wi‑Fi) и при каждом запуске;
- скачивают APK, сверяют SHA-256 и передают системному установщику сами — окна «Обновить?» больше нет;
- ставят обновление и при включённом VPN: туннель пропадает на несколько секунд перезапуска и включается снова сам;
- на Android 14+ закрепляют за собой обновления (`setRequestUpdateOwnership`), чтобы следующие шли без вопросов.

Где без человека нельзя — ограничение Android, не приложения: Android 11 и старше всегда спрашивают; самое первое
обновление на части телефонов требует одного подтверждения; «Установка неизвестных приложений» разрешается один раз.
iOS не позволяет приложению ставить себе обновления: там это делает App Store (нужен аккаунт Apple Developer).
Подробно — `docs/AUTO_UPDATE.md`, раздел 11.



## Сверка нод MASQUE

MASQUE — свой стек магазина на нодах, а не объект панели Remnawave, но расходится так же: ноду переустановили, стек
остановили руками, порт поменяли. «Расширения Remnawave» → «Сверка с панелью» теперь проверяет и его:

- каждая нода с установленным MASQUE отвечает на `corgi-masque.sh status`;
- расхождения: «стек MASQUE не запущен», другой порт, другое число пользователей, ошибка SSH;
- раз в 6 часов сама и по кнопке «Проверить сейчас»; о новом расхождении приходит одно сообщение администраторам;
- сверка идёт, даже если на панели Remnawave магазин ничего не настраивал;
- «Где исправить» ведёт в «Смена протокола» → «MASQUE: ноды и подписка». Проверка ничего не меняет.

Что делать при каждом расхождении — таблица в `docs/MASQUE_PANEL.md`, раздел «Сверка».
