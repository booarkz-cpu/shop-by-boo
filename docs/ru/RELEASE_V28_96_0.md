# Выпуск v28.96.0 — ночное обновление российских списков

Дистрибутив: `v28.96.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8.

Владелец выбрал ночное окно для обновления списков блокировок (N7, продолжение v28.95.0).

## Что нового

- **«Серверы → Автообновление Remnawave» → «В то же время обновлять российские списки блокировок»** (по умолчанию выключено).
  - В выбранное время (МСК) магазин берёт последнюю сборку `runetfreedom/russia-v2ray-rules-dat` с SHA-256 от GitHub и ставит её модулем «Российские списки» — тем же планом, что и вручную: проверка суммы, перезапуск ноды, откат файлов при ошибке.
  - Только там, где списки уже установлены, и только если сборка новее; не чаще раза за ночь.
  - Установка, которая этой ночью обновляет Remnawave, пропускается (нода перезапускается один раз) и получает списки следующей ночью.
  - Итог — в Telegram администраторам, если включены уведомления; если GitHub недоступен — сообщение, повтор следующей ночью.
