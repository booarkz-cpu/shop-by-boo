# Меню Telegram и Mini App

В админке откройте **Бот и кабинет → Дерево кнопок**. Нужны права `manage_content` (admin/operator). Меню бота и приложения сохраняются независимо. На каждое дерево допускается 30 кнопок и четыре уровня вместе с конечной кнопкой. Существующие плоские настройки сохраняют своё поведение после обновления.

## Telegram

Создайте папку с названием, затем кнопку и выберите папку в поле «Родитель бота». Виды: папка, HTTPS ссылка, Mini App, настроенное включённое поле. Для Mini App можно оставить действие пустым при настроенном `MINI_APP_URL`. Порядок сортируется по числу и ID. Подменю открывается только в личном чате владельца callback; кнопка «←» возвращает на предыдущий уровень. Выключенная папка скрывает всех потомков. Ссылка не выдаёт секретов и проверяется тем же серверным валидатором публичных URL.

Перенос выполняется сохранением нового родителя. Сервер отвергает циклы, родителя не-папку, превышение глубины с учётом всего переносимого поддерева и превращение папки с детьми в действие. Для удаления сначала перенесите или удалите детей; массового неявного удаления Telegram-ветки нет. Изменения сериализуются advisory lock PostgreSQL.

Стиль: обычный, синий (`primary`), зелёный (`success`), красный (`danger`). Custom emoji ID — строка из 5–32 цифр из Telegram; Unicode emoji можно вписать в обычную иконку. При отказе Telegram принять custom emoji бот повторяет отправку без этого поля, сохраняя название и действия. Другие ошибки отправки не скрываются.

[Telegram Bot API](https://core.telegram.org/bots/api#inlinekeyboardbutton) ограничивает custom emoji правами бота: дополнительное имя через Fragment либо владелец с Premium при отправке напрямую в личные/групповые чаты. Конкретное отображение цветов и emoji зависит от клиента Telegram и прав платформы. Проверьте на настоящем боте: локальный CI внешние права Telegram не выдаёт.

## Mini App

Добавьте корневую кнопку, выберите папку и добавьте дочерние кнопки. Действия: тарифы, HTTPS ссылка, промокод, включённое поле, папка. У каждой кнопки есть стабильный ID, название, стиль и необязательные иконки. В «Перенести в папку» выберите другой родитель или корень; свои потомки недоступны как родители. Удаление кнопки удаляет её подменю из текущего редактируемого дерева. Изменения применяются после «Сохранить меню приложения».

Предпросмотр использует тот же компонент, что кабинет/Mini App: открывайте папки, возвращайтесь назад, проверяйте названия, стили и итоговое действие. В предпросмотре действие показывает описание, не совершая покупку. Настоящие действия используют существующие механизмы приложения. Папки без детей показывают сообщение о пустом меню.

Сохранение отправляет только дерево и fingerprint предыдущей сохранённой версии. При параллельном изменении ответ 409 не перезаписывает чужое меню и остальные настройки приложения. «Загрузить актуальное меню» после подтверждения заменяет локальные несохранённые изменения сохранённым деревом. Не используйте общий старый редактор контента параллельно с деревом: его полный payload тоже может менять меню.

## Безопасные миниатюры custom emoji

Mini App показывает статическую PNG миниатюру, а не анимацию Telegram. Публичный маршрут разрешает только ID из настроенного меню. Сервер получает sticker/thumbnail через Telegram API, проверяет путь файла, размер до 512 КиБ и изображение до 512×512, удаляет метаданные преобразованием в PNG. Bot token остаётся на сервере; браузер получает только `/media/menu-emoji-<hash>.png`. Редиректы не разрешаются. Ошибки и неподдерживаемые типы дают обычную иконку/название.

Кэш успешного разрешения — один час, ошибки — минуту, до 64 ID в памяти. PNG сохраняется в `MEDIA_DIR` и входит в backup медиа. Смена/удаление ID прекращает его разрешение через API; ранее опубликованный PNG остаётся общедоступным статическим файлом. Файл не содержит исходных метаданных или токена. Удаляйте неиспользуемые миниатюры только после проверки ссылок и backup.

## API

| Запрос | Назначение |
| --- | --- |
| `GET /api/admin/content` | Дерево бота, настройки приложения, `miniapp_buttons_fingerprint` |
| `POST /api/admin/menu` | Создание кнопки бота |
| `PUT /api/admin/menu/{id}` | Полное обновление/перенос кнопки бота |
| `DELETE /api/admin/menu/{id}` | Удаление кнопки без детей |
| `PUT /api/admin/miniapp/menu` | `{buttons, fingerprint}`; новое дерево/новый fingerprint |
| `GET /api/public/menu-emoji/{id}` | Разрешённая безопасная миниатюра или 404/502/503 |

Кнопка бота: `title`, `item_type`, `action`, `parent_id` (null для корня), `sort_order`, `enabled`, `style`, `icon_custom_emoji_id`, `icon`. Кнопка приложения: `id`, `title`, `type`, `style`, `icon_custom_emoji_id`, `icon`, `url`, `code`, `field_key`, `children`. Не передавайте произвольные поля. Field требует существующего включённого ключа; URL требует публичного HTTPS; promo требует непустого кода. Дерево записывается атомарно вместе с аудитом.

## Production-проверка и откат

1. Сделайте [согласованный backup](BACKUP_CURRENT.md), примените `alembic upgrade head`, убедитесь в `0084_subscription_freeze`.
2. Проверьте старые кнопки в корне. Создайте папку с полем/ссылкой, откройте и вернитесь в настоящем Telegram.
3. Выключите папку и убедитесь, что старый callback не открывает скрытые данные. Проверьте запрет цикла/пятого уровня/удаления непустой папки.
4. Сохраните Mini App меню, проверьте предпросмотр и настоящий Mini App, включая «Назад». Проверьте конфликт в двух вкладках.
5. Проверьте custom emoji с правами бота и недоступный ID: Mini App должен показывать обычную иконку/название. В ответах/DOM не должно быть bot token.
6. Downgrade 0061 разрешён только без папок, родителей, стилей и иконок. При настроенном дереве он блокируется; восстановите согласованный snapshot всех исходников/БД/медиа. Не удаляйте структуру SQL-командами для обхода защиты.
