# Магазин «Корги Люси» с телефона: Android и Termux

Пошагово для новичка: как с телефона на Android подключиться к своему серверу (VPS), поставить магазин, обновлять его,
смотреть журналы и разбираться, если что-то не работает. Всё, что ниже, делается в приложении Termux — это терминал
Linux на телефоне. Сам магазин работает на сервере, а не на телефоне: телефон нужен только как пульт.

Требование мастер-промпта: REQ-INFRA-0007. Инструкция не проверялась на настоящем телефоне: команды те же, что в
[INSTALLATION.md](../../INSTALLATION.md), а Termux здесь лишь способ их набрать.

## 1. Что понадобится

- Телефон на Android 7 или новее.
- Сервер (VPS) с Ubuntu 22.04/24.04 или Debian 12, его IP-адрес и пароль `root` — их присылает хостинг.
- Домен, A-записи которого указывают на IP сервера (раздел «DNS и сеть» в [INSTALLATION.md](../../INSTALLATION.md)).

## 2. Поставить Termux

1. Скачайте Termux из **F-Droid** (f-droid.org → поиск «Termux») или со страницы выпусков проекта Termux на GitHub.
   Версия из Google Play устарела и не обновляет пакеты — её не используйте.
2. Откройте Termux. Появится чёрный экран с приглашением `~ $` — сюда вводятся команды.
3. Обновите пакеты и поставьте нужные программы (на вопросы отвечайте Enter):

```bash
pkg update -y && pkg upgrade -y
pkg install -y openssh git curl
```

Подсказка: длинную команду удобно скопировать и вставить долгим нажатием на экран → «Вставить».

## 3. Подключиться к серверу

```bash
ssh root@203.0.113.10        # вместо 203.0.113.10 — IP вашего сервера
```

- В первый раз спросят «Are you sure you want to continue connecting» — напишите `yes` и Enter.
- Введите пароль `root` (при вводе символы не видны — так и задумано) и Enter.
- Приглашение сменится на `root@имя-сервера:~#`: теперь команды выполняются на сервере.
- Выйти с сервера обратно в Termux: `exit`.

### Вход по ключу вместо пароля (рекомендуется)

В Termux (не на сервере):

```bash
ssh-keygen -t ed25519            # трижды Enter
ssh-copy-id root@203.0.113.10    # один раз введите пароль
```

Дальше `ssh root@203.0.113.10` пускает без пароля. Ключ лежит только в Termux — никому его не отправляйте.

Если связь рвётся, когда экран гаснет: опустите шторку уведомлений → Termux → «Acquire wakelock».

## 4. Установить магазин

На сервере (после `ssh`) выполните команду из раздела «Установка одной командой» в
[INSTALLATION.md](../../INSTALLATION.md#4-установка-одной-командой) — там всегда номер текущего выпуска. Она выглядит так
(`vX.Y.Z` — этот номер):

```bash
curl -fsSL https://raw.githubusercontent.com/booarkz-cpu/shop-by-boo/vX.Y.Z/install.sh -o /root/shop-install.sh \
  && BRANCH=vX.Y.Z bash /root/shop-install.sh
```

Установщик сам ставит Docker, скачивает магазин и задаёт вопросы: домены, токен бота, адрес и токен панели Remnawave,
цены тарифов, ключи касс. На любой вопрос можно нажать Enter и заполнить позже в панели администратора. В конце он
печатает адреса и данные первого входа — сделайте снимок экрана или скопируйте их.

Установка идёт 5–15 минут. Связь с телефона может оборваться (сменилась сеть, погас экран), а вместе с ней
остановится и команда. Поэтому установку запускайте внутри `tmux` — тогда она продолжится на сервере сама:

```bash
apt-get install -y tmux
tmux                                  # открылся «экран» tmux, в нём запустите команду установки выше
# связь оборвалась → снова ssh root@… и затем:
tmux attach                           # вы снова видите установку на том же месте
```

## 5. Проверить, что всё работает

```bash
cd /opt/vpn-shop
bash scripts/doctor.sh           # здоровье API и ответы панели, кабинета и Mini App
docker compose ps                # все службы должны быть «running» или «healthy»
```

## 6. Обновить

Обычно ничего делать не нужно: агент автообновления на сервере ставит новые выпуски ночью сам (включается при
установке; состояние — «Выпуски» в панели администратора). Обновить сразу:

```bash
sudo env APP_DIR=/opt/vpn-shop bash /opt/vpn-shop/scripts/update-from-github.sh
```

Перед обновлением скрипт проверяет место на диске, делает снимок и копию базы; при сбое сам возвращает прежнюю версию.

## 7. Журналы

```bash
cd /opt/vpn-shop
docker compose logs --tail 100 backend     # API и панель
docker compose logs --tail 100 bot         # Telegram-бот
docker compose logs --tail 100 worker      # выдача доступа, оплаты, фоновые задачи
docker compose logs -f backend             # следить в реальном времени; выйти — Ctrl+C
```

Ctrl на телефоне: в Termux над клавиатурой есть строка дополнительных клавиш (`CTRL`, `ESC`, `TAB`); если её нет —
проведите от левого края экрана и нажмите «Keyboard».

## 8. Если что-то не работает

| Что видно | Что сделать |
| --- | --- |
| `ssh: connect to host … Connection timed out` | Проверьте IP; в панели хостинга сервер включён и порт 22 открыт |
| `Permission denied (publickey,password)` | Неверный пароль `root`; сбросьте его в панели хостинга |
| Обновление пишет «Мало места на диске» | Нужен сервер с диском от 20 ГБ или очистка: `docker system prune` |
| Сайт не открывается по домену | A-запись домена указывает не на этот IP или ещё не обновилась (подождите до часа) |
| `doctor.sh` сообщает об ошибке | Таблица «Решение проблем» в [INSTALLATION.md](../../INSTALLATION.md) |

Пароли, токены и содержимое `.env` никому не присылайте — даже в поддержку. Для помощи достаточно вывода `doctor.sh`:
он секреты не печатает.
