# Remnawave — итог

Что магазин умеет с Remnawave на выпуске v28.114.0 и как это проверено.

| Возможность | Где в админке | Проверка | Статус |
| --- | --- | --- | --- |
| Подключение к панели, пользователи, продление, блокировка, разблокировка | «Пользователи», «Remnawave» | живая панель последней версии в CI | PASS |
| Мастер установки: панель, нода, страница подписки, 7 режимов, план с SHA-256, откат | «Серверы → Установка Remnawave» | установка по SSH на сервер CI | PASS (CI); на настоящем VPS — BLOCKED_EXTERNAL |
| Обновить, перезапустить, запустить, остановить, журналы контейнеров, копия базы панели, восстановление | там же | `tests/test_rw_installer.py`, живой тест мастера | PASS (CI) |
| Автообновление панели и нод (только проверенные версии) | «Обновления» | `tests/test_rw_autoupdate.py` | PASS (CI) |
| Доступ к панели: открыт, секретная ссылка, вход через TinyAuth, вход через магазин | мастер установки | настоящие Caddy и TinyAuth в CI | PASS (CI) |
| Хосты и Internal Squads | «Remnawave → Панель» | `tests/test_admin_coverage_ops.py`, живая панель | PASS |
| Домены, DNS (Cloudflare, Bunny, Gcore), сертификаты, портал подписки | «Домены и сертификаты», «Портал подписки» | on-demand TLS в CI; DNS — поддельные API | PASS (CI); с настоящими ключами DNS — BLOCKED_SECRETS |
| Расширения: профили, плагины нод, SelfSteal, IPv6, ядро Xray, WARP, NetBird, Xray Checker, серверный роутинг | «Расширения Remnawave» | живой тест модулей нод | PASS (CI) |
| Страница подписки Orion | мастер | SHA-256 закреплён | PASS (CI) |

Из `eGamesAPI/remnawave-reverse-proxy` перенесено всё, кроме вариантов с nginx (в магазине один Caddy) и интерактивного меню CLI внутри контейнера панели (нужные действия выполняются через API).
