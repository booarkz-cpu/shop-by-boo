# Менеджер расширений Remnawave

Этап 12. Раздел «Серверы → Расширения Remnawave» (`admin/src/rw-extensions.tsx`), backend — `backend/app/rw_extensions.py`, маршруты `/api/admin/rw/extensions/...`. Всё управляется из админки, без SSH и терминала.

Функции, которые есть в API панели Remnawave, вызываются через API панели: состояние хранит сама панель, магазин её не дублирует. Функции на сервере ноды (SelfSteal, IPv6, ядро Xray, WARP, NetBird, Xray Checker) выполняет мастер установки по SSH закрытым списком шагов ([DEPLOYMENT_AGENT](DEPLOYMENT_AGENT.md)).

Источник списка функций — `eGamesAPI/remnawave-reverse-proxy` (MIT, Copyright (c) 2025 eGames): меню «Расширения ноды», «Подписки: правила и страница», WARP, IPv6, Xray Checker, NetBird. Код скрипта не переносился: реализация своя, по API панели и шагам мастера.

## 2. Профили конфигурации

- **Список:** каждый профиль, его inbound (тег, протокол, порт) и ноды, которые его используют. Профиль, занятый нодами, не удаляется.
- **Конфигурация:** «Конфигурация» показывает JSON профиля. Сохранение отправляет его в панель (`PATCH /api/config-profiles`); панель проверяет конфигурацию и перезапускает ноды профиля.
- **Назначить нодам:** для каждой ноды выбирается inbound профиля (`PATCH /api/nodes`, `configProfile`).
- **Хост:** `POST /api/admin/rw/extensions/profiles/{uuid}/host` создаёт хост панели для inbound — адрес и SNI, которые получат клиенты. Остальные хосты правятся в «Remnawave: панель».

### Конструктор VLESS + REALITY

| Поле | Значение |
| --- | --- |
| Название | 2–30 символов: латиница, цифры, пробел, `_`, `-` (требование панели) |
| Домены SNI | `serverNames`, до 10 доменов |
| Маскировка | **SelfSteal** — `dest` = `/dev/shm/selfsteal.sock`, `xver: 1` (сайт-шаблон самой ноды); **чужой сайт** — `dest` = `домен:порт`, `xver: 0` |
| Порт | 443 по умолчанию |
| shortIds | 1–8 случайных по 16 шестнадцатеричных символов |
| Минимальная версия клиента | `minClientVer`, вида `25.1.1` |
| Блокировки | `geoip:private` и BitTorrent → `BLOCK` |
| DNS | DoH `https://dns.google/dns-query`, только IPv4 |

Ключи x25519 выдаёт панель (`GET /api/system/tools/x25519/generate`). Закрытый ключ попадает в профиль, открытый показывается после создания: панель сама подставляет его в подписки.

## 3. Права и журнал

| Действие | Право | Журнал |
| --- | --- | --- |
| Смотреть | `read` | — |
| Профили, ключи, назначение нодам, хост, плагины | `provision_nodes` | `rw.profile.*`, `rw.node.profile`, `rw.plugin.*`, `rw.node.plugin` |
| Правила подписки, страница, шаблоны | `settings.runtime.write` | `rw.subscription_settings.updated`, `rw.subpage_config.*`, `rw.template.*` |

Если панель отклонила запрос (например, неверная конфигурация), её сообщение показывается администратору. Без подключения к панели раздел отвечает 503 и объясняет почему.
