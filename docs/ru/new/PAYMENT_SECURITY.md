# Безопасность платежей

## Правила, которые держит код

1. **Оплату подтверждает касса, а не уведомление.** Перед выдачей магазин сам спрашивает у кассы статус, сумму, валюту и номер заказа (`verify_succeeded`). Сообщение клиента, кнопка «Я оплатил» или одно уведомление подписку не выдают.
2. **Подпись каждого уведомления.** У каждой кассы свой способ (таблица в [PAYMENT_INTEGRATION.md](PAYMENT_INTEGRATION.md)): HMAC, RSA, MD5-подпись по документации кассы, секрет в заголовке или список IP. Сравнение — `hmac.compare_digest`. Неверная подпись даёт 403 и запись в журнале «Отклонённые».
3. **Совпадение заказа и суммы.** Уведомление чужой кассы или с другой суммой отклоняется (`gateways/common._settle`, обработчики касс в `payments_api.py`).
4. **Ровно один раз.** Событие кассы регистрируется атомарно: уникальный ключ «касса + событие», `INSERT … ON CONFLICT`. Выдача идёт под блокировкой пользователя и платежа. Повторное уведомление не выдаёт второй раз.
5. **Данные карт магазин не видит.** Оплата проходит на странице кассы; у магазина только сумма, статус и идентификатор платежа (PCI DSS — у кассы).
6. **Ключи касс** хранятся в «Настройках без перезапуска» в зашифрованном виде (`encrypt_secret`), в журналы и ответы API не попадают.
7. **Production gate.** Приём оплаты в production открывается только после проверки готовности («Проверка платежей»). Sandbox магазина в production запрещён при запуске.
8. **Антифрод** (`payment_fraud.py`): подбор карт, новые аккаунты, много аккаунтов с одного адреса, чарджбэки, стоп-лист. Действует и на пополнение кошелька.
9. **Журнал без лишнего.** Для отклонённых уведомлений хранятся только касса, время, код ответа и причина. Тело и заголовки не хранятся: в них может быть что угодно.
10. **Права.** Возвраты — `payments.refund`, повтор выдачи — `payments.retry`, сверка — `payments.reconcile`, журнал уведомлений — `payments.read`. Каждое действие записывается в журнал действий администратора.

## Что проверить владельцу

- Адрес уведомлений в кабинете каждой кассы ведёт на домен API магазина по HTTPS.
- Для YooKassa и Freekassa список IP актуален («Настройки без перезапуска»).
- Рабочие и тестовые ключи не перепутаны: проба кассы показывает режим, а в «Платежах» видна касса каждого заказа.
