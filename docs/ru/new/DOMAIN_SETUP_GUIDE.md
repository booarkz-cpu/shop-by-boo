# Домены: что и куда направить

Как устроены домены и сертификаты внутри — [SUBSCRIPTION_DOMAIN](SUBSCRIPTION_DOMAIN.md). Здесь — что сделать владельцу у регистратора или в DNS.

## Какие домены нужны

| Домен (пример) | Запись | Куда указывает | Для чего | Обязателен |
| --- | --- | --- | --- | --- |
| `shop.example.com`, `api.`, `admin.`, `cabinet.` | A (и AAAA, если есть IPv6) | сервер магазина | кабинет, API, админка, Mini App | да (задаются при установке магазина) |
| `panel.example.com` | A | сервер панели Remnawave | панель (мастер ставит Caddy с Let's Encrypt) | да, для Let's Encrypt |
| `sub.example.com` | A | сервер страницы подписки (или панели) | страница подписки Remnawave | по желанию |
| `link.example.com` и другие | A | **сервер магазина** | портал подписки магазина: ссылки клиентов, зеркало | по желанию; добавляются без перезапуска |
| домен для SelfSteal / REALITY | A | сервер ноды | маскировка ноды под сайт | для режима SelfSteal |

## Порядок

1. **DNS.** Создайте записи A у регистратора или в Cloudflare.
   - Для доменов, где сертификат выпускает Let's Encrypt (HTTP-01), прокси Cloudflare («оранжевое облако») выключите: проверке нужен прямой доступ к серверу на портах 80 и 443.
2. **Проверка.** «Серверы → Домены и сертификаты → Проверить». Видны запись DNS, совпадение с сервером, ответ HTTPS и срок сертификата. Мастер установки сам проверяет DNS доменов панели и страницы подписки перед установкой.
3. **Сертификат.**
   - Домены панели и страницы подписки — Caddy их сервера при установке.
   - Домены портала — Caddy магазина при первом обращении, только для доменов, включённых в разделе.
   - Продление — автоматически.
4. **Сроки.** За 14 дней до окончания сертификата «Состояние системы» показывает предупреждение.

## Частые ошибки

| Признак | Причина |
| --- | --- |
| Сертификат не выпускается | запись указывает на другой сервер; включён прокси Cloudflare; закрыт порт 80 |
| Портал открывается без сертификата | домен не включён в «Доменах и сертификатах» — Caddy магазина не выпускает сертификат для чужих имён |
| Клиенты из РФ не открывают домен панели | используйте портал подписки на своём домене и зеркала ([SUBSCRIPTION_PORTAL](SUBSCRIPTION_PORTAL.md)) |

Выпуск сертификатов через DNS (DNS-01, Cloudflare) — этап 18. Проверка на настоящем домене — BLOCKED_EXTERNAL.
