# «Корги Люси: клиент» — какие данные хранит и куда обращается

Документ описывает Android-клиент версии 1.10.1. Всё ниже сверено с кодом приложения
(`apps/vpn-client/android/app/src/main/java/shop/corgi/client/`). Клиент — отдельное приложение: в нём нет учётной записи,
оплаты и связи с сервером магазина.

## Что клиент не обещает

- **Анонимность.** VPN прячет трафик от сети, в которой находится телефон (Wi-Fi, оператор), но владелец VPN-сервера
  видит, куда идёт трафик. Сайты по-прежнему узнают человека по входу в аккаунт, cookie и отпечатку браузера.
- **Обход любых блокировок.** Работа зависит от сервера и протокола в подписке. Сервер может быть заблокирован, а клиент
  этого не исправит.
- **Защиту от вредоносных программ на телефоне.** Приложение с root-доступом или с доступом к экрану может прочитать
  то же, что видит человек.

Эти оговорки относятся к любому VPN-клиенту. Клиент только подключает к серверу из подписки.

## Что хранится на телефоне

| Что | Где | Защита |
|---|---|---|
| Подписки: ссылки, серверы, ключи | настройки приложения | шифруются ключом Android Keystore (AES-256-GCM) с 1.10.0 |
| Логин и пароль локального прокси | настройки приложения | шифруются так же |
| Остальные настройки, конфиг Geek Mode | настройки приложения | не шифруются; в конфиге Geek Mode могут быть ключи серверов |
| История трафика | файл приложения | только объём по дням (через VPN и напрямую), 90 дней, без адресов |
| Журнал сети | файл приложения | **выключен по умолчанию**; включённый хранит домены и маршруты, не шифруется |
| Журналы приложения и ядра | файлы приложения | срок хранения выбирается (по умолчанию 1 час) |
| Случайный идентификатор установки (HWID) | настройки приложения | создаётся на телефоне; не связан с IMEI, номером и аккаунтом Google |

Системная резервная копия Android выключена (`android:allowBackup="false"`): данные приложения не попадают в облако
Google и при переносе телефона не копируются.

## Куда клиент обращается

| Адрес | Когда | Что уходит |
|---|---|---|
| Адрес подписки (его вводит человек) | при добавлении, по кнопке «Обновить», по расписанию (по умолчанию раз в 6 часов) | User-Agent клиента; если включено «Отправлять HWID» (включено по умолчанию) — HWID, «Android», версия Android, производитель и модель |
| Серверы из подписки | при подключении и проверке пинга | трафик VPN |
| `www.gstatic.com/generate_204` (или адрес из настроек) | проверка туннеля после подключения и пинг | пустой запрос через туннель |
| `ipinfo.io` | после подключения, чтобы показать внешний адрес и страну | запрос через туннель: виден адрес сервера VPN, а не телефона |
| `github.com/booarkz-cpu/shop-by-boo/releases` | проверка обновлений клиента каждые 6 часов (можно выключить) | обычный запрос файла |
| `github.com/runetfreedom/russia-v2ray-rules-dat` (или адреса из настроек) | файлы geoip/geosite раз в день (можно выключить) | обычный запрос файла |
| `speed.cloudflare.com` | только по кнопке Speedtest | тестовые данные |
| DNS-серверы из настроек (по умолчанию 1.1.1.1 и 8.8.8.8) | при работе VPN | запросы имён |

Аналитики, рекламы, отчётов о сбоях и других отправок на сторонние серверы в клиенте нет.

## Что уходит с телефона только по нажатию

- **Резервная копия** (файл, ссылка, QR-код). В неё входят подписки и настройки, кроме логина и пароля локального прокси.
  Файл можно закрыть паролем (AES-256-GCM, ключ из пароля по PBKDF2). Ссылка и QR-код паролем не закрываются: кто
  их получит, получит подписки.
- **Копирование ссылки подписки и «Поделиться»**: ссылка уходит туда, куда её отправит человек.
- **Экспорт журналов в .zip.** С 1.10.1 каждая строка очищается перед записью в архив: ссылки серверов
  (`vless://`, `vmess://` и другие), UUID (остаются первые четыре знака), адреса в интернете (IPv4 и IPv6),
  места назначения после `tcp:`/`udp:`, адреса `https://`, значения полей `password`, `id`, `key`, `token`, `uuid`.
  Время, уровни и тексты ошибок остаются. Локальные адреса (`127.0.0.1`, `192.168.x.x`, `10.x.x.x`) не скрываются.

## Разрешения

| Разрешение | Зачем |
|---|---|
| VPN (`BIND_VPN_SERVICE`) | сам туннель; Android спрашивает при первом подключении |
| Уведомления | состояние VPN и обновления; спрашивается, когда включают уведомления |
| Геолокация, в том числе фоновая | Android отдаёт имя Wi-Fi только с этим разрешением; нужно лишь для «Доверенных Wi-Fi» и спрашивается при включении функции |
| Список приложений | «Прокси по приложениям» |
| Установка пакетов | самообновление клиента |
| Запуск после перезагрузки | автоподключение, если оно включено |

## Как проверено

- Шифрование хранилища — тест `VaultTest` на эмуляторе в CI.
- Очистка журналов — модульный тест `RedactTest` (строки ядра, ссылки, UUID, адреса, архив целиком).
- Адреса и заголовки — по коду (`Store.kt`, `Settings.kt`, `Updates.kt`, `ExternalIp.kt`, `SpeedTest.kt`).

На телефоне не проверено: сетевой трафик клиента не записывали снифером на настоящем устройстве.
