# Шаблоны портала подписки

С v28.67.0 (этап 11). Что видит клиент, открыв ссылку подписки в браузере, задаётся в «Серверы → Портал подписки». Настройки хранятся в конфигурации прослойки (`sub_proxy.config` → `portal`). Значения по умолчанию — `sub_portal.DEFAULT`. Устройство портала — [SUBSCRIPTION_PORTAL](SUBSCRIPTION_PORTAL.md).

## 1. Шаблоны

| Шаблон | Ключ | Что на странице |
| --- | --- | --- |
| Корги Люси (полная страница) | `corgi` | Объявление, подписка, ссылка и QR-код, приложения и шаги, устройства, помощь |
| Короткая | `minimal` | Объявление, подписка, ссылка и QR-код |
| Стандартная страница панели Remnawave | `panel` | Портал не показывается: браузер получает ответ панели (по её правилам SRR) |

Возврат к стандартной странице — шаблон `panel` или выключенный портал.

Цвета — тёмная тема Remna (палитра раздела [UI_UX_GUIDE](UI_UX_GUIDE.md)). Логотип и название — из «Оформления».

## 2. Тексты и блоки

| Поле | Ограничение | По умолчанию |
| --- | --- | --- |
| Заголовок | до 80 символов | «Ваша подписка» |
| Объявление | до 300 символов | пусто |
| Ссылка поддержки | только `https://` | личный кабинет |
| Трафик, устройства | вкл/выкл | вкл |
| Предупреждать до окончания | 0–30 дней | 3 |

Все тексты выводятся экранированными: HTML в них не работает.

## 3. Приложения

До 20 строк: название, платформы, ссылка добавления, где скачать.
- **Ссылка добавления** — схема приложения с `{url}`, например `happ://add/{url}`. На место `{url}` подставляется ссылка подписки (URL-кодированная). Принимаются только ссылки вида `схема://…{url}…`; `javascript:` и подобные отклоняются.
- **Где скачать** — только `https://`.

По умолчанию:

| Приложение | Платформы | Добавление |
| --- | --- | --- |
| Happ | iOS, Android, Windows, macOS | `happ://add/{url}` |
| v2RayTun | iOS, Android, Windows | `v2raytun://import/{url}` |
| Hiddify | Android, iOS, Windows, macOS, Linux | `hiddify://import/{url}` |
| v2rayNG | Android | `v2rayng://install-config?url={url}` |
| Clash Verge | Windows, macOS, Linux | `clash://install-config?url={url}` |

Ссылки «Скачать» по умолчанию — страницы выпусков на GitHub у открытых приложений. У Happ и v2RayTun их нет: владелец указывает сам.

## 4. Связь с правилами подписки

Заголовки ответа VPN-клиентам (`profile-title`, `announce`, `profile-update-interval`…) задаются правилами по приложению в «Прослойке подписки». Портал на них не влияет.

## 5. Шаблоны других проектов

Шаблоны Orion и legiz из `eGamesAPI/remnawave-reverse-proxy` — это темы официальной страницы подписки Remnawave (subscription-page). Портал магазина — своя страница, поэтому они не переносятся. Тему официальной страницы на сервере Remnawave можно будет выбирать в менеджере расширений (этап 12).
