# Проверка сервера перед установкой (preflight)

Preflight — первый шаг каждой установки и кнопка «Проверить» в реестре серверов. Скрипт `PREFLIGHT` в `backend/app/rw_steps.py` только читает и ничего не меняет. Вывод — строки `ключ=значение`, разбирает их `parse_facts`, решение принимает `evaluate`. Мастер — [REMNAWAVE_INSTALLATION_WIZARD](REMNAWAVE_INSTALLATION_WIZARD.md).

## 1. Подключение

- SSH через `paramiko` с сохранённым отпечатком ключа сервера (`SHA256:…`). Если ключ другой, подключение обрывается до входа: доверия при первом подключении нет.
- Не root — команды выполняются через `sudo -n`; если `sudo` спрашивает пароль, проверка говорит об этом.
- Таймаут подключения — 20 секунд, проверки — 2 минуты.

## 2. Что проверяется

| Ключ | Что | Ошибка (установка остановится) | Предупреждение |
| --- | --- | --- | --- |
| `ssh` | Вход с сохранённым отпечатком | Нет соединения, ключ не принят, отпечаток не совпал | — |
| `os` | `/etc/os-release` | Не Debian 12–13 и не Ubuntu 22.04–26.04, Docker нет | Другая ОС, но Docker с compose уже есть |
| `arch` | `uname -m` | Не `x86_64` и не `aarch64` | — |
| `cpu` | `nproc` | 0 | — |
| `ram` | `/proc/meminfo` | Меньше половины нужного: панель — 2048 МБ, нода — 512 МБ | Меньше нужного |
| `disk` | Свободно на `/` | Панель — меньше 10 ГБ, нода — меньше 5 ГБ | — |
| `root` | `id -u` | Нет прав root | — |
| `docker` | `docker version`, `docker compose version` | — | Docker нет — будет установлен |
| `port_N` | `ss -ltnp`: 80, 443 (Caddy), 3000, 3001, 6767 (панель), 3010 (страница подписки), порт ноды | Порт занят чужим процессом | Порт занят прежней установкой мастера: она будет обновлена |
| `service_X` | Работают nginx, apache2, caddy, haproxy, angie | На сервере панели или страницы подписки: спор за 80/443 | На сервере ноды |
| `dns_D` | `getent ahostsv4` домена на сервере | Let's Encrypt: домен не указывает на сервер | Внутренний сертификат |
| `ufw` | `ufw status` | — | Сведения: включён ли |

Контейнеры прежней установки (`remnawave`, `remnanode`, `remnawave-subscription-page`, `remnawave-caddy`) распознаются по имени. Порт 443, занятый другим контейнером (например общим Caddy магазина), — ошибка: мастер не заменяет и не дублирует чужой прокси.

## 3. Где виден результат

- Реестр: состояние сервера (`ready` или `check_failed`, `unreachable`), ОС, архитектура, ресурсы, «Отчёт» со всеми проверками.
- Установка: журнал шага `preflight` — каждая проверка строкой `ok: …`, `warn: …` или `error: …`. При ошибке установка останавливается до любых изменений (`test_preflight_failure_stops_before_any_change`).
- «Диагностика» — тот же скрипт без остановки, плюс состояние контейнеров.
