# Automation Center

«Система → Automation Center» показывает на одном экране всё, что магазин делает сам. Для каждого процесса видно, включён ли он, когда сработает, чем кончился последний запуск и в каком разделе он настраивается (кнопка в строке). Ниже — сводка «Состояния системы»: сколько проверок в норме и какие требуют внимания.

Данные: `GET /api/admin/automation-center` (право `ops.diagnostics`, только чтение), код — `backend/app/automation_center.py`, экран — `admin/src/automationCenter.tsx`.

## Процессы

| Процесс | Что показывает | «Внимание» или «не работает», когда | Где настраивается |
| --- | --- | --- | --- |
| Автообновление магазина | установленная и последняя версия, время, последний запуск | агент не отвечает 5 минут; последний запуск не удался (выполнен откат); режим восстановления | «Обновления» |
| Автообновление Remnawave | сколько установок требуют обновления, последнее обновление | последнее обновление не удалось; выключено, а обновления есть | «Обновления» |
| Релизы Remnawave на GitHub | новее ли релизы, чем проверенные магазином | есть более новый релиз (ждёт выпуска магазина); GitHub не ответил | «Обновления» |
| Версия Remnawave | версия подключённой панели против проверенной в CI | новее или старше проверенной; панель не отвечает | «Remnawave: панель» |
| Резервные копии | расписание, последняя успешная | копия опоздала в 1,5 раза против расписания; последний запуск не удался | «Резервные копии» |
| Фоновый обработчик (worker) | сколько worker на связи | ни одного: расписания, обновления и копии стоят | «Фоновые процессы» |
| Оповещения о сбоях | куда уходят (Telegram, почта) | — (не настроены — «выключено») | «Запуск и оповещения» |

Статусы: **работает**, **внимание** (работает, но нужно посмотреть), **не работает**, **выключено** (функция не используется, ничего не сломано).

Платежи, Telegram-бот, ноды, сертификаты, база, Redis и миграции проверяет «Состояние системы». В Automation Center они попадают, когда требуют внимания. Процессы, у которых свой раздел, — расписание Telegram-копий, сверка платежей, автопродление, рассылки — запускает тот же worker. Его состояние — в строке «Фоновый обработчик».

Тесты — `tests/test_rw_autoupdate.py::test_automation_center_lists_processes`.
