# Личный кабинет: руководство

Личный кабинет — веб-приложение клиента по адресу `https://<CABINET_DOMAIN>`. Тот же код работает как Telegram Mini App (`NEXT_PUBLIC_SURFACE=miniapp`).

Все действия кабинет выполняет через API магазина (`/api/auth/*`, `/api/me/*`). Оплаты, выдача доступа и ограничения подписки работают на сервере. Ограничения выполняет панель Remnawave.

Связанные документы:
- [ADMIN_PANEL_GUIDE](ADMIN_PANEL_GUIDE.md) — как владелец настраивает кабинет;
- [API](API.md);
- [UI_UX_GUIDE](UI_UX_GUIDE.md) — правила интерфейса.

## Вход и аккаунт

| Способ | Как работает | Что нужно владельцу |
| --- | --- | --- |
| Email и пароль | Регистрация и вход в кабинете | SMTP для писем, «Настройки без перезапуска» |
| Подтверждение email | Письмо со ссылкой, ссылка одноразовая; в базе хранится только хэш токена | SMTP |
| Восстановление пароля | Письмо со ссылкой. После смены пароля все сессии закрываются | SMTP |
| Telegram | Вход из Mini App или кнопкой «Продолжить с Telegram» | `BOT_TOKEN`, `BOT_USERNAME` |
| Яндекс ID, VK ID, Google | Кнопки входа появляются, когда владелец ввёл ключи сервиса | Client ID, secret и redirect URI в «Настройки без перезапуска»; для Google — с v28.63.0 |
| Ключ доступа (passkey) | Вход без пароля | — |

Защита от захвата аккаунта:
- если email уже зарегистрирован, но не подтверждён, вход через Google с тем же адресом отклоняется. Сначала нужно подтвердить email в кабинете;
- Google-аккаунт без подтверждённого email не принимается.

**Сессии.** Раздел «Безопасность → Входы в кабинет и приложения»:
- показывает каждый вход: устройство, IP, время входа и последнюю активность; текущий вход отмечен;
- «Завершить» закрывает одну сессию. Если закрыть текущую, кабинет попросит войти снова;
- «Выйти на всех устройствах» закрывает все сессии;
- если у сессии сменилось устройство (браузер), сервер закрывает её сам;
- каждое завершение записывается в журнал действий.

Состав и порядок разделов владелец настраивает в «Бот и кабинет → Личный кабинет». Если сервер недоступен, кабинет показывает встроенный список разделов.

## Устройства и лимит

Лимит устройств подписки выполняет панель Remnawave. При выдаче доступа магазин передаёт `hwidDeviceLimit` = число устройств тарифа. Панель считает устройства по HWID, который присылает VPN-приложение, и не пускает устройство сверх лимита.

Чтобы лимит работал, в панели должен быть включён HWID-лимит (`HWID_DEVICE_LIMIT_ENABLED=true`). Без него панель принимает любое число устройств, а список в кабинете пуст.

**Устройства подписки** в разделе «Устройства»:
- список устройств, которые засчитала панель: платформа, модель, версия ОС, первое и последнее подключение;
- «Подключено N из M»;
- «Удалить» освобождает место одного устройства, «Удалить все» — всех.

Как это устроено:
- **API:** `GET /api/me/hwid-devices`, `POST /api/me/hwid-devices/{id}/delete`, `POST /api/me/hwid-devices/reset`. Запросы к панели — `POST /api/hwid/devices/delete` и `delete-all` с телом `{"userId": <число>}` (Remnawave 3.x).
- **Безопасность:**
  - HWID клиенту не показывается: вместо него используется короткий отпечаток (16 символов SHA-256);
  - удалить можно только устройство своей подписки;
  - каждое удаление записывается в журнал действий.
- **Ошибки:** если панель не подключена, кабинет отвечает 503. Если панель не ответила — 502, при этом текст ответа панели клиенту не передаётся.

**Приложения магазина**, где клиент вошёл в аккаунт, перечислены там же. «Отключить» закрывает доступ приложения на этом устройстве.

## Тарифы Lucy

| Тариф | Устройств | Трафик | Срок | Продаётся |
| --- | --- | --- | --- | --- |
| Lucy Mini — тест | 1 | по умолчанию без лимита; владелец может задать лимит | пробный период, 3 дня | нет: выдаётся только как пробный период |
| Lucy Max | 2 | без лимита | срок владельца, по умолчанию 30 дней | да |
| Lucy Ultra | 4 | без лимита | тот же | да; цена за устройство ниже, чем у Lucy Max |

**Как владелец включает.** Раздел «Тарифы → Тарифы Lucy» (`POST /api/admin/lucy-plans`, право `manage_plans`):
- **Цены.** Владелец вводит цены Max и Ultra — магазин их не придумывает. Сервер отклоняет цены, при которых Ultra не выгоднее Max по цене за устройство.
- **Что делает кнопка.** Создаёт недостающие тарифы и обновляет существующие с теми же названиями.
- **Пробный период.** Lucy Mini становится пробным тарифом: пробный период выдаётся только на нём и не дольше его срока. Кнопка «Пробный период на любом тарифе» возвращает прежний порядок.
- **Существующие подписки.** Оплаченные подписки сохраняют лимиты, с которыми их купили. Новые условия действуют с новых оплат.

**Кто выполняет ограничения:**
- **Устройства** — панель Remnawave через `hwidDeviceLimit`, при включённом HWID-лимите (см. выше).
- **Трафик** — `trafficLimitBytes = 0`, то есть без лимита в панели. Трафик безлимитный, если его не ограничивают узлы и их хостинг.
- **Срок** — `expireAt` пользователя в панели.

Тест `tests/live/test_remnawave_live.py::test_lucy_limits_and_customer_devices` проверяет это на настоящей панели последней версии в CI:
- лимит 2 и 4 устройства и безлимитный трафик сохраняются у пользователя панели;
- удаление одного и всех устройств работает.

## Тексты кабинета

Каждую надпись кабинета на русском, английском и украинском владелец меняет в админке: «Бот и кабинет → Личный кабинет → Тексты кабинета» (с v28.88.0). Пустое поле возвращает стандартный текст. Клиенты видят изменения при следующем открытии кабинета, без пересборки.

## Чего в кабинете нет

- **Вход в Android- и iOS-приложения через Яндекс, VK и Google.** Этот код лежит в ветке `feat/v28.31.0-mobile` и в `main` не перенесён. Перенос — на этапе 17 вместе с остальной доработкой приложений. В веб-кабинете и Mini App эти способы входа работают.
- **Отдельный выбор устройства для нового подключения.** Его не будет: устройство появляется в списке само при первом подключении VPN-приложения.
