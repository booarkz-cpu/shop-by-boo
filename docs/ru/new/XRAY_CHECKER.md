# Xray Checker

С v28.70.0 (этап 12). Модуль серверов мастера установки: «Серверы → Установка Remnawave → задача установки → Журнал → Модули серверов → Xray Checker». Сам Xray Checker — `kutovoys/xray-checker` (MIT); идея модуля — `xray_checker` из `eGamesAPI/remnawave-reverse-proxy` (MIT, Copyright (c) 2025 eGames).

## 1. Установка

1. Выберите сервер установки, адрес подписки для проверки (например, служебного пользователя со всеми нодами) и интервал (60–86400 с).
2. План пишет `/opt/remnawave-xray-checker/docker-compose.yml` и `.env`, запускает контейнер `remnawave-xray-checker` и ждёт ответа API.

Настройки:

- `network_mode: host`; метрики и API только на `127.0.0.1:2112` с Basic Auth (`METRICS_PROTECTED=true`). Пароль создаёт магазин и хранит в зашифрованных секретах установки.
- Подписка обновляется каждые 300 с; проверка — `PROXY_CHECK_METHOD=ip`, тайм-аут 30 с.

Адрес подписки — секрет: он хранится в зашифрованных секретах установки и в плане не виден. Повторная установка без адреса использует прежний.

Обновление установки («Обновить») переписывает файлы Xray Checker вместе с остальными. «Выключить» останавливает контейнер.

## 2. Результаты и уведомления

- «Результаты Xray Checker» — магазин по SSH читает `GET /api/v1/proxies` на `127.0.0.1:2112` и показывает каждый сервер подписки: адрес, протокол, на связи или нет, задержку (`GET /api/admin/rw/installations/{id}/xray-checker`).
- Раз в час магазин проверяет все установки с Xray Checker. Новые недоступные серверы уходят в уведомления владельцу (`send_alert`). Та же авария повторно не сообщается; после восстановления следующая авария сообщается снова.
