# Remnawave с нуля: пошаговое руководство владельца

От пустого VPS до магазина, который продаёт подписки на свои ноды. Всё делается в админке магазина, без команд на серверах. Подробности по каждому шагу — в связанных документах.

## 0. Что подготовить

- **VPS:** один (панель и нода вместе) или несколько (панель отдельно, ноды отдельно). Debian 12–13 или Ubuntu 22.04–26.04, x86_64/arm64.
- **Вход:** root или пользователь с `sudo` без пароля, ключ Ed25519 или пароль.
- **Домены:** для панели и, по желанию, для страницы подписки — см. [DOMAIN_SETUP_GUIDE](DOMAIN_SETUP_GUIDE.md).
- **Подтверждение опасных действий.** Включите 2FA в «Защите и 2FA»: запуск плана на серверах подтверждается кодом ([RBAC](RBAC.md#подтверждение-опасных-действий-step-up)).

## 1. Добавить серверы

«Серверы → Установка Remnawave → Серверы для Remnawave»:
1. Укажите адрес, порт, пользователя и ключ или пароль.
2. Сверьте отпечаток ключа сервера с консолью хостинга и сохраните.
3. Нажмите «Проверить». Отчёт покажет ОС, ресурсы, Docker, занятые порты и DNS.

Подробно — [мастер установки](REMNAWAVE_INSTALLATION_WIZARD.md), [проверка сервера](REMNAWAVE_PREFLIGHT.md).

## 2. Сменить ключ на ключ магазина

«Сменить ключ» в строке сервера. Магазин создаст свой ключ для этого сервера и проверит вход им. После этого пароль или ваш ключ магазин больше не хранит ([SECRETS_MANAGEMENT](SECRETS_MANAGEMENT.md)).

## 3. Установить

1. **Режим:** «Панель и нода», «Только панель», «Только нода», с отдельной страницей подписки или распределённо — [режимы](REMNAWAVE_INSTALLATION_MODES.md).
2. **Домены и сертификат:** Let's Encrypt для настоящих доменов или внутренний для проверки.
3. **План:** «Составить план», прочитать, что изменится, «Запустить по этому плану», подтвердить кодом. Журнал шагов виден сразу; при ошибке изменения откатываются.

## 4. Подключить магазин

«Подключить магазин к этой панели» → «Применить». Магазин начнёт создавать пользователей в этой панели без перезапуска. Пароль администратора панели — «Показать вход в панель», с подтверждением.

## 5. Добавлять ноды

Режим «Добавить ноды» на уже подключённую панель: магазин регистрирует ноду в панели, открывает порт только для адреса панели и проверяет связь. Модули нод — IPv6, ядро Xray, WARP, NetBird, Xray Checker — в «Расширениях Remnawave» ([REMNAWAVE_EXTENSIONS](REMNAWAVE_EXTENSIONS.md)).

## 6. Обслуживание

| Что | Где |
| --- | --- |
| Обновление панели и нод | «Обновления → Автообновление Remnawave» — ночью или кнопкой ([AUTO_UPDATE](AUTO_UPDATE.md)) |
| Копии базы панели | автоматически при обновлении; хранятся на сервере панели и, зашифрованными, в магазине |
| Диагностика, восстановление базы, переустановка, удаление | кнопки установки в «Установке Remnawave» |
| Состояние | «Состояние системы», [Automation Center](AUTOMATION_CENTER.md), [мониторинг](REMNAWAVE_MONITORING.md) |

**Проверено:** установка в CI на настоящую панель и ноду (живые тесты `remnawave-live.yml`). На вашем VPS с вашими доменами — BLOCKED_EXTERNAL, пока не появятся тестовые серверы.
