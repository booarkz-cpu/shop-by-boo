# «Корги Люси: клиент» — третье Android-приложение

Отдельный VPN-клиент для любых подписок, не только магазина. Задача владельца от 2026-11-05: приложение «по образцу INCY». Каталог — `mobile/android-client`.

## Отдельность от существующих приложений

| | Клиент магазина | Админка | **Корги Люси: клиент** |
| --- | --- | --- | --- |
| Каталог | `mobile/android-user` | `mobile/android-admin` | `mobile/android-client` |
| `applicationId` | `shop.remnawave.user` | `shop.remnawave.admin` | `shop.corgi.client` (отладочная сборка — `.preview`) |
| Сборка в CI | `ci.yml`, `android-vpn-e2e.yml` | `ci.yml` | `android-client.yml` (своя) |
| Вход в магазин | да | да | нет: подписка, ссылки или JSON |

Код существующих приложений, их ключи, выпуски и имена файлов не меняются. Движок общий только как файл: `libv2ray.aar` собирается тем же `scripts/mobile/build-xray-aar.sh` (кэш общий) и копируется в `mobile/android-client/app/libs`. Код движка (`engine/Xray.kt`) и разбора ссылок написан для клиента отдельно — так изменения в нём не могут сломать сборку клиента магазина.

## Почему не форк INCY

Репозиторий `INCY-DEV/incy-platforms` (проверен 2026-11-05, коммит `6d2d0c3`) содержит только ссылки на сборки, манифест версий и настройки Obtainium; исходного кода приложения и лицензии там нет, само приложение закрытое. Поэтому код, значки и название не берутся: приложение написано с нуля на нашем движке, по функциям, которые INCY описывает публично.

## Версия 1.6.0 — исправления и удобство по промпту владельца (N10)

- **Кнопка подключения не нажимается, пока меняются серверы** (`core/ConfigGate.kt`): удаление провайдера, обновление подписки — кнопка полупрозрачная и не работает; удаление активного провайдера разрывает туннель, кнопка ждёт выбора нового сервера («Сервер удалён — выберите другой»).
- **Пульс вокруг кнопки** во время «Подключение…».
- **Внешний адрес и флаг страны** под статусом после подключения: проверка идёт через отдельный SOCKS-вход Xray на 127.0.0.1 с паролем этого подключения (`core/ExternalIp.kt`, ipinfo.io).
- **Мультивыбор провайдеров** долгим нажатием на экране «Серверы» и удаление нескольких после подтверждения.
- **Полоски сигнала** рядом с пингом: 3 зелёные — меньше 100 мс, 2 жёлтые — 100–300 мс, 1 — медленнее, красная — нет ответа.
- **Маршрутизация**: удаление правила свайпом влево или «⋮ → Удалить», всегда с подтверждением; загрузка geo-файлов с плавной полосой прогресса и процентом («Обновление баз данных гео-роутинга…»).
- **Прокси по приложениям** — отдельный экран: карточки «Только через туннель» / «Обход», все установленные приложения с иконками, поиск, вкладки «Пользовательские» / «Системные», счётчик выбранных, экспорт и импорт списка (JSON); разрешение `QUERY_ALL_PACKAGES` — для VPN это разрешённый Google Play случай.
- **Подключаться при смене сети** (Wi-Fi ↔ мобильная) — `vpn/NetworkReceiver.kt`; Android может не разрешить запуск в фоне. Kill Switch — системные «Постоянная VPN» и «Блокировать соединения без VPN» (ссылка в «Подключение»).
- Проверки: unit-тесты `ConfigGateTest`, `GeoProgressTest`, `AppListTest`, `ExternalIpTest`, `VpnViewModelTest`; на эмуляторе — удаление правила с подтверждением, блокировка кнопки после удаления активного провайдера, экран приложений.

## Версия 1.5.0 — главный экран по промпту владельца (v28.90.0)

- **MVVM.** `ui/home/VpnViewModel.kt`: `VpnUiState` (статус «Отключено / Подключение / Подключено», время сессии, скорость и трафик, блокировка рекламы, стрик) в StateFlow; `toggleVpn()` и `toggleAdBlock()`. Туннель — через интерфейс `VpnEngine` (`AndroidVpnEngine` — настоящий VPN-сервис; в тестах и превью — подделка). `ui/home/HomeScreen.kt`: `HomeContent` только рисует состояние.
- **Экран.** Название с версией, слоган сразу под ним; справа «🔥 N дней» и «Поделиться». Баннер «ЗАЩИТА В ОДНО КАСАНИЕ» с «Безлимит» и корги рисует приложение (касание подключает). Бейдж статуса и кнопка 180 dp с анимацией состояний (`updateTransition`), кольцо при подключении, оранжевое свечение при подключении. Статистика (время, ↓ и ↑ в секунду и всего) появляется при подключении. Карточка сервера — с иконкой сигнала по задержке. Переключатель «Блокировка рекламы». Пятна-градиенты фона, фон #09090B.
- **Блокировка рекламы** — правило `geosite:category-ads-all → block` первым в конфигурации Xray, во всех режимах маршрутизации; нужны geo-файлы («Маршруты → Скачать geo-файлы»). Во время подключения — «заработает после переподключения».
- **Стрик** — дни подряд с подключением; хранится только на телефоне.
- **Превью** `@Preview` трёх состояний в светлой и тёмной теме.
- **Качество.** ktlint (`scripts/mobile/client-ktlint.sh`, версия закреплена по SHA-256) для нового кода в CI клиента; тесты `VpnViewModelTest`, `SessionAndStreakTest`, `AdBlockTest`; на эмуляторе — `mainScreenPartsAndAdBlocking`.

## Скачать и обновлять

- APK: [corgi-lusi-client.apk](https://github.com/booarkz-cpu/shop-by-boo/releases/latest/download/corgi-lusi-client.apk) — в каждом выпуске магазина, подписан ключом `corgi`; рядом `corgi-lusi-client.apk.sha256` и манифест `corgi-lusi-client.json`.
- [Obtainium](https://github.com/ImranR98/Obtainium): «Добавить приложение» → адрес `https://github.com/booarkz-cpu/shop-by-boo` → «Фильтр APK по регулярному выражению»: `^corgi-lusi-client\.apk$` → сохранить. Obtainium сам проверит новые выпуски.
- **Свой выпуск клиента** (с v28.89.0): на каждую новую версию клиента «Mobile packages» создаёт выпуск `client-v<версия>` (например, `client-v1.4.0`) с тем же APK, `.sha256` и манифестом, ссылка которого ведёт на этот выпуск. Он никогда не становится «последним выпуском» — ссылки `releases/latest/download/…` магазина не меняются. Чтобы Obtainium следил только за клиентом, добавьте ещё «Фильтр названий выпусков»: `^client-v`.
