# «Корги Люси: клиент» — третье Android-приложение

Отдельный VPN-клиент для любых подписок, не только магазина. Задача владельца от 2026-11-05: приложение «по образцу INCY». Каталог — `mobile/android-client`.

## Отдельность от существующих приложений

| | Клиент магазина | Админка | **Корги Люси: клиент** |
| --- | --- | --- | --- |
| Каталог | `mobile/android-user` | `mobile/android-admin` | `mobile/android-client` |
| `applicationId` | `shop.remnawave.user` | `shop.remnawave.admin` | `shop.corgi.client` (отладочная сборка — `.preview`) |
| Сборка в CI | `ci.yml`, `android-vpn-e2e.yml` | `ci.yml` | `android-client.yml` (своя) |
| Вход в магазин | да | да | нет: подписка, ссылки или JSON |

Код существующих приложений, их ключи, выпуски и имена файлов не меняются. Движок общий только как файл: `libv2ray.aar` собирается тем же `scripts/mobile/build-xray-aar.sh` (кэш общий) и копируется в `mobile/android-client/app/libs`. Код движка (`engine/Xray.kt`) и разбора ссылок написан для клиента отдельно — так изменения в нём не могут сломать сборку клиента магазина.

## Почему не форк INCY

Репозиторий `INCY-DEV/incy-platforms` (проверен 2026-11-05, коммит `6d2d0c3`) содержит только ссылки на сборки, манифест версий и настройки Obtainium; исходного кода приложения и лицензии там нет, само приложение закрытое. Поэтому код, значки и название не берутся: приложение написано с нуля на нашем движке, по функциям, которые INCY описывает публично.

## Что умеет (версия 1.1.0)

| Функция | Как сделано |
| --- | --- |
| Подписки по ссылке, QR, «Поделиться», ссылке из браузера | `Profile.fromText`: адрес `https://` — подписка; ссылки по одной в строке или base64; QR — сканер Google (без разрешения камеры); `vless://…`, `corgiclient://import?url=…` и текст из «Поделиться» открывают приложение |
| Несколько подписок, автообновление | Каждая подписка обновляется сама (по умолчанию раз в 12 часов, при запуске приложения), прошлые серверы остаются при ошибке |
| Протоколы | VLESS (REALITY, TLS, Vision), VMess, Trojan, Shadowsocks (оба формата ссылок), SOCKS5, WireGuard; транспорты tcp, ws, grpc, xhttp, httpupgrade. Hysteria2 и TUIC распознаются и пропускаются с пометкой: в Xray-core их нет |
| Автовыбор сервера | «Самый быстрый»: observatory + балансировщик leastPing Xray |
| Задержка серверов | Время TCP-соединения с сервером |
| Маршруты | «Всё через VPN», «Всё, кроме локальной сети», «Российские сайты напрямую», «Свои правила»: домен, IP/CIDR, `geosite:`, `geoip:` → прокси, напрямую или блок |
| Свои geo-файлы | `geoip.dat` и `geosite.dat` по ссылкам из настроек (по умолчанию runetfreedom/russia-v2ray-rules-dat), только https; без файлов правила `geo*` не применяются |
| Полный JSON Xray | Outbounds, routing, observatory, балансировщики — как в файле; inbounds заменяются туннелем, `api`/`stats` убираются |
| Фрагментация TLS ClientHello | `freedom` с `fragment` и `sockopt.dialerProxy` у TLS-серверов; длина и интервал настраиваются |
| DNS | Свои серверы (до 4) |
| Приложения через VPN | Все, только выбранные или все, кроме выбранных |
| Kill switch | Честно через систему: кнопка открывает настройки «Постоянная VPN» и «Блокировать соединения без VPN» |
| Плитка быстрых настроек | Подключить или отключить одним касанием |
| Android TV | Запуск с экрана ТВ (LEANBACK), без сенсорного экрана; «QR для ТВ» — показать подписку QR-кодом, чтобы перенести её на телевизор или телефон |
| Виджет на рабочем столе (1.1.0) | Состояние и сервер; касание подключает или отключает |
| Проверка обновлений (1.1.0) | Раз в день и по кнопке: манифест `corgi-lusi-client.json` последнего выпуска; новая версия — карточка «Скачать обновление» (подписанный APK, Android сам сверяет подпись) |
| Подписка на ТВ с телефона (1.1.0) | «С телефона»: телевизор поднимает одноразовую страницу в локальной сети и показывает QR; телефон открывает её, вставляет подписку — она появляется на ТВ. Ключ 128 бит в адресе, 5 минут, одна подписка |
| Языки и тема | Русский, английский, украинский по языку системы; тема системная, тёмная или светлая, цвета бренда |

## Скачать и обновлять

- APK: [corgi-lusi-client.apk](https://github.com/booarkz-cpu/shop-by-boo/releases/latest/download/corgi-lusi-client.apk) — в каждом выпуске магазина, подписан ключом `corgi`; рядом `corgi-lusi-client.apk.sha256` и манифест `corgi-lusi-client.json`.
- [Obtainium](https://github.com/ImranR98/Obtainium): «Добавить приложение» → адрес `https://github.com/booarkz-cpu/shop-by-boo` → «Фильтр APK по регулярному выражению»: `^corgi-lusi-client\.apk$` → сохранить. Obtainium сам проверит новые выпуски.
