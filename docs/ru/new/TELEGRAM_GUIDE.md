# Telegram-бот: управление из админки

С v28.71.0 (этап 13). Раздел «Бот и кабинет → Telegram-бот» (`admin/src/telegram-bot.tsx`), backend — `backend/app/telegram_bot.py` (`/api/admin/telegram/...`), процесс бота — `backend/app/bot.py` (контейнер `bot`, aiogram 3, long polling).

Тексты, меню, баннеры и документы бота настраиваются в соседних разделах: «Меню бота и Mini App», «Дерево кнопок», «Баннеры бота», «Документы» ([руководство по модулю](../modules/14-bot-miniapp.md)).

## 1. Подключение бота

1. В @BotFather: `/newbot`, получите токен.
2. «Настройки без перезапуска → Telegram»: «Токен Telegram-бота» и «Username Telegram-бота». Токен хранится зашифрованно (AES-GCM) и в браузер не возвращается.
3. Бот подключается сам, без перезапуска контейнера: процесс бота проверяет настройку каждые 15 секунд. При новом токене он завершает сессию (опрос, рассылки) и начинает новую.
4. «Telegram-бот → Проверить сейчас» показывает, что ответил Telegram (`getMe`, `getWebhookInfo`).

Токен из `.env` (`BOT_TOKEN`) по-прежнему работает: значение из «Настроек без перезапуска» его заменяет.

Если токен не задан, контейнер `bot` не останавливается и ждёт токен. Раньше в production он падал с ошибкой.

## 2. Связь с Telegram

Процесс бота пишет состояние в таблицу `telegram_bot_state` (миграция `0092_telegram_bot`):

| Поле | Что значит |
| --- | --- |
| Состояние | `running` — работает, `idle` — ждёт токен, `error` — Telegram отклонил токен или недоступен |
| Последний ответ Telegram | Бот вызывает `getMe` раз в минуту |
| Последнее сообщение от клиента | Время последнего обновления от Telegram; счётчик пишется раз в минуту |
| Отпечаток токена | Первые 12 символов SHA-256 токена; сам токен не показывается нигде |
| Последняя ошибка | Текст ошибки, токен в нём заменён на `***` |

«Аналитика → Состояние системы», строка «Telegram-бот»:

| Статус | Когда |
| --- | --- |
| ok | Бот работает и Telegram ответил в последние 3 минуты |
| warn | Токен задан, но процесс бота ещё не сообщил о связи |
| error | Telegram отклонил токен, или ответа нет больше 3 минут (контейнер остановлен, нет сети) |
| off | Токен не задан |

Ошибки процесса бота попадают в «Журнал ошибок» (процесс `bot`) и в блок «Ошибки бота».

## 3. Webhook

Бот получает обновления опросом (long polling). При каждом подключении он удаляет webhook, оставшийся от другой установки. Если webhook появился снова (тот же токен используется на другом сервере), «Проверить сейчас» его покажет, а «Удалить webhook» уберёт. Второй экземпляр с тем же токеном нужно остановить: Telegram отдаёт обновления только одному получателю.

## 4. Меню команд

Кнопка «Меню» в чате с ботом. Списки на русском, английском и украинском. Русский список Telegram показывает всем, у кого язык не английский и не украинский. Список задаёт порядок и описания команд.

«Сохранить и применить» сразу вызывает `setMyCommands` (пустой список — `deleteMyCommands`) и сохраняет меню. Стандартное меню — команды, на которые отвечает бот: `start`, `buy`, `subscription`, `keys`, `promo`, `status`, `info`, `app`.

## 5. Тестовое сообщение

Бот пишет владельцу («Telegram ID владельца» в настройках) или в указанный chat ID. Telegram не даёт боту писать первым: сначала отправьте боту `/start`.

## 6. Тексты бота

С v28.72.0. «Telegram-бот → Тексты бота»: каждое сообщение и кнопка бота (около 100 текстов, по разделам) на русском, английском и украинском. Реестр — `backend/app/bot_texts.py`, правки владельца хранятся в `app_settings.bot_texts`.

- **Язык клиента** берётся из его Telegram (`language_code`): украинский, английский, остальным русский (или «Язык по умолчанию» магазина).
- **Подстановки** в фигурных скобках (`{name}`, `{date}`) сохраняются. Неизвестная подстановка отклоняется при сохранении.
- **HTML:** можно только теги Telegram `<b> <i> <u> <s> <code> <pre> <a href>`.
- **Сброс:** пустое поле или стандартный текст возвращают стандартный вариант.
- **Применение:** бот берёт новые тексты в течение минуты, без перезапуска.

Функции бота и Mini App по списку этапа: [TELEGRAM_MINI_APP](TELEGRAM_MINI_APP.md).
