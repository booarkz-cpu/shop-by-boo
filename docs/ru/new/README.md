# Документы исполнения мастер-задания (docs/ru/new)

Рабочие реестры задания «VPN Shop by Corgi Lucy» из 18 этапов. Статусы задач: `NOT_STARTED`, `IN_PROGRESS`, `IMPLEMENTED`, `TESTING`, `PASS`, `FAIL`, `BLOCKED_ACCESS`, `BLOCKED_PERMISSIONS`, `BLOCKED_SECRETS`, `BLOCKED_EXTERNAL`, `NOT_RUN`, `NOT_APPLICABLE`. `IMPLEMENTED` не означает `PASS`: `PASS` ставится только после реальной проверки.
