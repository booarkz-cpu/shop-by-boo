# Выпуск v28.62.0 — System Control Center

Дистрибутив: `v28.62.0`. Runtime/API: `21.5.1`. Head магазина: `0089_index_cleanup` (миграций нет). Support Pro: `0008` / 3.8. Дата и commit фиксируются тегом выпуска.

Дополнение к этапу 6 по новой редакции мастер-задания: состояние всех частей установки на одном экране и документы по админ-панели.

## Что изменилось

**Состояние системы.** Раздел «Аналитика → Состояние системы» раньше проверял три вещи: базу, Redis и Remnawave. Теперь он проверяет 14 частей:

| Часть | Что проверяется |
| --- | --- |
| Backend | отвечает; номер выпуска и API |
| Frontend | админка, кабинет и Mini App отдают страницу |
| PostgreSQL | отвечает на запросы |
| Миграции | отметка в базе совпадает с миграцией выпуска |
| Redis | отвечает на `PING` |
| Remnawave | панель отвечает и принимает токен |
| Узлы | сколько включённых узлов на связи |
| Caddy | принимает HTTPS для доменов магазина |
| Сертификаты TLS | проходят проверку цепочки; предупреждение за 14 дней до конца срока |
| Платежи | какие агенты настроены и работают |
| Фоновые задачи | есть ли живой обработчик, нет ли зависших и невыполненных задач |
| Резервные копии | возраст последней успешной копии |
| Telegram-бот | заданы ли токен и имя |
| Обновления | вышел ли новый выпуск на GitHub |

У каждой строки:
- статус: «в норме», «внимание», «ошибка» или «не настроено»;
- причина одним предложением;
- кнопка раздела, где это исправляется.

Проверки только читают состояние. У каждой проверки свой предел времени. Токены, пароли и ответы внешних сервисов в ответ не попадают.

**Документы.**
- [ADMIN_PANEL_GUIDE](new/ADMIN_PANEL_GUIDE.md) — вход, устройство панели, «Состояние системы», типичные задачи и честный список того, что пока требует консоли сервера.
- [ADMIN_MODULES](new/ADMIN_MODULES.md) — 30 модулей с разделами, операциями, API и правами. Генерируется из кода.
- [RBAC](new/RBAC.md) — как проверяются права, три роли и таблица 49 прав. Тест сверяет таблицу с кодом.

**Найдено при работе.** Четыре права есть в ролях, но ни один маршрут их не требует: `manage_payments`, `manage_backups`, `security.stepup`, `sessions.self`. Они ничего не открывают и описаны в RBAC. Роли на работающих установках не менялись.

