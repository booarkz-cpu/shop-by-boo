# Выпуск v28.46.0 — возвраты и автопродление через CloudPayments

Дистрибутив: `v28.46.0`. Runtime/API: `21.5.1`. Head магазина: `0081_subscription_proxy` (новых миграций нет). Support Pro: `0008` / 3.8. Мобильные приложения: 3.4.0. Дата и commit фиксируются тегом выпуска.

## Что изменилось

**Возвраты через API (CloudPayments)**
- Кнопка «Выполнить» в разделе «Возвраты» возвращает деньги через API CloudPayments и снимает подписку. Заходить в кабинет кассы не нужно.
- Повторное нажатие не вернёт деньги второй раз: CloudPayments узнаёт повтор по заголовку `X-Request-ID`.
- Статус возврата сверяется через API кассы.

**Автопродление через CloudPayments**
- Клиент с включённым автопродлением платит картой через CloudPayments, и магазин сохраняет токен этой карты в зашифрованном виде.
- За несколько дней до окончания подписки магазин списывает оплату этой картой.
- Карта ЮKassa, если она уже сохранена, остаётся главной.
- Правила те же, что у ЮKassa: после трёх отказов банка автопродление выключается.
- Нужно, чтобы в договоре с CloudPayments были включены рекуррентные платежи.

**Что не вошло**
- У остальных дополнительных касс возврат через API не реализован. Возврат делается в кабинете кассы и отмечается в админке.
- Автопродление через подписки Cashera и Lava не реализовано: эти кассы списывают по своему расписанию, а не по расписанию магазина.

Подробно — [billing_and_taxes.md](../modules/billing_and_taxes.md).

## Проверки

- `tests/test_cloudpayments_refund_recurring.py`:
  - возврат и защита от повторного возврата;
  - успешное списание токеном, отказ банка, статус;
  - сохранение токена: только при включённом автопродлении и не поверх карты ЮKassa;
  - проход автопродления списывает через CloudPayments.
- Прежние тесты автопродления ЮKassa проходят без изменений.
