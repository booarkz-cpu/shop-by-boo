## Копии каждый час сразу (решение № 15)

- Если администратор не выбирал расписание копий, магазин делает копию **каждый час** и хранит **48** последних
  (двое суток). Выбранное расписание, в том числе «Выкл.», не меняется.
- Копии шифруются, поэтому нужен пароль. Новый установщик создаёт его сам (`BACKUP_PASSWORD` в `.env`) и показывает в
  итоге установки — его нужно сохранить отдельно от сервера. Магазин один раз переносит его в пароль копий панели;
  пароль, заданный в панели, не заменяется.
- На уже установленном магазине без пароля копии не запускаются и не падают каждую минуту — приходит одно оповещение
  «задайте пароль копий».

## SSH только с адреса владельца (из remnawave-manager, пункт 32)

- `ADMIN_SSH_IP=<адрес> bash deploy/install-vps.sh` открывает SSH-порт только для этого адреса.
- Ограничение включается, только если вы сейчас подключены именно с этого адреса (или запуск не через SSH): установщик
  не может отрезать вам доступ. Иначе — предупреждение, SSH остаётся открытым для всех.
- `scripts/open-ports.sh` больше не открывает SSH заново (ни `ufw allow OpenSSH`, ни прямое правило iptables на порт 22),
  когда SSH ограничен.
