## Что не изменилось для установленного сервера

- **Обновление идёт как обычно.** Программа обновления прежних выпусков читает версию из `backend/app/main.py` и
  принимает скачанный выпуск, только если этот файл в нём есть. Файл остался по старому пути: в нём одна строка с
  версией. Сам бэкенд — в `services/backend/`.
- **Секреты Support Pro** остаются в `support-pro/.env`. Переносить файл не нужно.
- **Службы Docker** называются по-прежнему (`backend`, `worker`, `bot`, `support_pro` …); тома с данными, домены,
  адреса и настройки Caddy не менялись. Меняется только папка, из которой собирается образ.
- **Откат** работает и на снимок, сделанный до этого выпуска.

После обновления на сервере останутся старые папки `backend/` и `support-pro/` с прежним кодом: обновление копирует
новые файлы поверх и ничего не удаляет. Они не используются; удалять их не обязательно.
