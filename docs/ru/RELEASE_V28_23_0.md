# Выпуск v28.23.0 — PostgreSQL 18 и Mini App на данных

Дистрибутив: `v28.23.0`. Runtime/API: `21.5.1`. Head магазина: `0075_app_config`. Support Pro: `0008` / 3.8. Дата и commit фиксируются тегом выпуска.

## PostgreSQL 18

- Магазин, Support Pro, тестовый стенд и CI работают на `postgres:18.6-alpine` (последний стабильный выпуск PostgreSQL на дату выпуска) с закреплённым digest. CI проверяет, что digest соответствует тегу.
- В образ backend ставится `postgresql-client-18` из официального репозитория PGDG (ключ проверяется по отпечатку): `pg_dump` из панели должен быть не старше сервера.
- Образы PostgreSQL 18 хранят данные в `/var/lib/postgresql/18/docker`, поэтому базы переезжают на новые тома `postgres18_data` и `support_postgres18_data`.
- **Перенос данных при обновлении — автоматический.** `scripts/upgrade-postgres.sh` (его вызывает `update.sh`) останавливает сервисы, снимает дамп со старой базы во временном контейнере PostgreSQL 16 без сети, восстанавливает его в PostgreSQL 18, сверяет число строк в каждой таблице и делает `ANALYZE`. Закреплённый `POSTGRES_IMAGE=postgres:16…` в `.env` и `.env.images` меняется на PostgreSQL 18. Старые тома не удаляются — они нужны для отката. Дамп сохраняется в `.rollback/`. Подробно — [модуль 27](modules/27-releases-updates.md#обновление).

## Mini App на данных

- `GET /api/app-config` — одна JSON-конфигурация Mini App и кабинета: тема (неоново-зелёный акцент), навигация с иконками, баннеры разделов, карточки акций с таймером, категории серверов с флагами, суммы и способы пополнения, условия рефералов, кнопки поддержки, документы и согласие с офертой, тексты интерфейса. С подписанным `X-Telegram-Init-Data` ответ содержит имя клиента для приветствия. Ответ кэшируется по `ETag`.
- Кабинет: провайдер `useAppConfig` (последний сохранённый конфиг → сеть → встроенный `mock-config.json`), скелетоны при загрузке, плашка «Нет связи» с повтором, защита раздела от ошибки отрисовки.
- Разделы: Главная (приветствие из Telegram, акции, статус подписки, серверы), Серверы (категории, флаги, онлайн), Кошелёк (кнопки сумм, СБП, карта, криптовалюта, Telegram Stars, промокод или подарочная карта), Пригласи друзей (условия, ссылка, «Поделиться», статистика, вывод), Поддержка (кнопки связи и форма обращения), Информация (FAQ, правила, конфиденциальность, оферта).
- **Баннеры Mini App.** Шесть новых баннеров с корги Люси: «Главная», «Пополнение баланса», «Пробный период», «Подключение», «Серверы», «Информация»; остальные разделы используют баннеры бота. Все меняются в «Баннерах бота»; копии лежат в `cabinet/public/assets/banners/` и показываются, если API недоступен.
- **Конфигурация Mini App** в админке (**Бот и кабинет → Конфигурация Mini App**): структурный редактор и JSON с предпросмотром ответа.
- **Telegram Stars.** Пополнение кошелька Stars: счёт `createInvoiceLink` по курсу администратора, `openInvoice` в Mini App, проверка `pre_checkout_query`, зачисление по `successful_payment` один раз, возврат `refundStarPayment`. Бот запрашивает у Telegram только используемые типы обновлений.
- **Согласие с офертой.** Чекбокс перед тарифами и пополнением, журнал `user_consents`; при обязательном согласии оплата, пополнение, покупка с баланса, подарок и счёт Stars без согласия отклоняются (`409 consent_required`).
- **СБП через YooKassa** — способ «СБП» сразу открывает оплату через СБП (`payment_method_data.type`).
- Переключатели «Разрешить вывод средств» и «Форма обращения» действуют и в интерфейсе, и на сервере.
- Скрипт снимков `scripts/screenshots/miniapp.mjs` и новые снимки Mini App в `docs/img/`.

## Обновление

Миграция `0075_app_config` добавляет `user_consents` и `payments.stars_amount`. Перенос на PostgreSQL 18 выполняется при обновлении; на время переноса магазин остановлен (обычно 1–5 минут).

```bash
cd /opt/vpn-shop && bash scripts/backup.sh
sudo env APP_DIR=/opt/vpn-shop RELEASE_TAG=v28.23.0 bash /opt/vpn-shop/scripts/update-from-github.sh
docker compose exec -T db psql -U vpnshop -d vpnshop -c 'SHOW server_version'   # 18.6
```

Ожидаемые head: магазин `0075_app_config`, Support Pro `0008`.
