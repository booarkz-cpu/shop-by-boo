# Выпуск v28.49.0 — антифрод платежей, нагрузка на реальном сервере, отчёт об учениях

Дистрибутив: `v28.49.0`. Runtime/API: `21.5.1`. Head магазина: `0083_corporate_seats` (новых миграций нет). Support Pro: `0008` / 3.8. Мобильные приложения: 3.4.0. Дата и commit фиксируются тегом выпуска.

## Что изменилось

**Антифрод платежей** — «Фрод → Правила платежей» в админке и карточка в мобильных админках
- Новые правила:
  - подбор карт — много неудачных оплат за сутки;
  - новый аккаунт с крупной суммой;
  - много аккаунтов с одного адреса;
  - чарджбэки;
  - стоп-лист адресов, e-mail, Telegram ID и ID клиентов.
- Пополнение кошелька теперь проходит ту же проверку, что и покупка тарифа.
- Каждый отказ сохраняется в журнале. О проверках и отказах приходит сообщение в Telegram.

**Нагрузка на реальном сервере** — workflow «Load live»
- Нагружает ваш API только запросами на чтение, ступенями до заданного пика. Показывает время ответа и долю ошибок.
- Запускается только вручную. Нужен секрет `LOAD_TARGET_URL`.

**Учения резерва**
- Еженедельное учение горячего резерва теперь всегда заканчивается отчётом в Telegram, и при успехе, и при неудаче. В отчёте — клиенты и платежи в копии базы, отставание репликации и последняя проверка резервной копии.

## Что не вошло

- Регионы внутри стран на карте клиентов. Магазин определяет только страну адреса (данные регистратора RIPEstat), региона в этих данных нет. Для регионов нужна база геолокации вроде MaxMind GeoLite2 с лицензионным ключом. Карта стран работает как прежде.

Подробно — [payment_fraud.md](../modules/payment_fraud.md).
