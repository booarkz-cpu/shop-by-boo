## Что нового

- **Локальный DNS для сайтов напрямую** («Подключение» → «DNS · MTU»): домены, которые идут мимо VPN, — российские сайты в режиме «РФ напрямую» и свои правила «direct» — спрашиваются у него, остальные — у удалённых DNS через туннель. Адреса — как понимает Xray: IP, `localhost`, `https://`, `https+local://`, `tcp://`, `tcp+local://`, `quic+local://`.
- **FakeDNS**: приложения мгновенно получают адрес из `198.18.0.0/15`, сниффинг восстанавливает по нему домен, а настоящий запрос делает сервер. Быстрее первые загрузки, нет утечек DNS. Запросы устройства на порт 53 при этом отвечает DNS-модуль Xray; его собственные запросы к DNS-серверам в петлю не попадают.
- **Стратегия доменов**: «Авто» (как раньше), AsIs, IPIfNonMatch, IPOnDemand.
- **Порядок своих правил**: «блок → прокси → напрямую» одним переключателем в «Маршрутизации».
- Без изменений настроек конфиг тот же, что в 1.6.2.
