- Перенос через `git mv` — история файлов сохраняется.
- Docker: Dockerfile веб-панели и Mini App, контексты сборки в `docker-compose.yml` и в сборке образов выпуска. Внутри
  образа веб-панели общие файлы кабинета лежат так же, как в репозитории, поэтому сборка Next.js находит их по тем же
  относительным путям.
- **Имена служб Docker (`admin`, `cabinet`, `miniapp`), адреса, домены и Caddy не менялись.** Установленный сервер
  обновляется как обычно: новый выпуск приносит новые папки, службы пересобираются из них. Старые папки на сервере не
  используются.
- Нативные приложения больше не попадают в контекст сборки образов (`.dockerignore`).

## Сверка раздела GOV (решение № 19)

Подтверждены файлами и проверками: один репозиторий `shop-by-boo` с прежним именем; статусы реестра, PASS только с
доказательствами (`--check`), статус `SOURCE_UNAVAILABLE`; журнал задач; сверка исходных проектов; PR → зелёный CI →
squash; отчёты на русском. Частично — структура по промпту (этапы 4–5 впереди). Ещё не написаны: матрицы
сбалансированного развития, чек-лист приёмки, финальные отчёты, матрица трассировки источников.

## Выпуск v28.152.0 опубликован неполным

В v28.152.0 — 25 файлов из 33: нет клиента (`corgi-lusi-client.*`), файлов `*.certificate.txt` и `*.package.txt`
Android-приложений и `mobile-production-status.json`. Причина: при первой сборке Maven Central отвечал 403, а при
повторной пересобранный APK панели администратора не совпал с уже прикреплённым, и «Mobile packages» отказалась его
заменять — опубликованные файлы не перезаписываются. Полный набор файлов — в этом выпуске (v28.153.0); установленные
приложения и серверы берут последний выпуск.
