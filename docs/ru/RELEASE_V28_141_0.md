# Релиз v28.141.0 — MASQUE: этапы установки и откат при сбое

Дистрибутив: `v28.141.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8.

Дата: 2026-11-14. Пункт плана MASQUE: «прогресс и откат установки».

## Что было

Установка MASQUE на ноде — один запрос по SSH. Если она срывалась посреди (контейнер не поднялся, у сайта нет
сертификата), на ноде оставались новые файлы и неработающий стек; при переустановке пропадала и прежняя рабочая версия.
Воркер повторял неудачную переустановку каждую минуту.

## Что стало

- Скрипт ноды идёт по этапам: проверка ноды → файлы стека → сертификат сайта → настройки Xray и HAProxy → запуск
  контейнеров → проверка запуска → порт в брандмауэре.
- Перед изменениями файлы работающей установки откладываются. При сбое на любом этапе после изменений:
  - была рабочая установка — она возвращается и запускается снова;
  - это была первая установка — всё, что успели сделать, удаляется (сайт SelfSteal не трогается).
- Ошибка в панели называет этап и что стало с нодой, например: «…(этап «проверка запуска»; изменения отменены:
  работает прежняя установка)». У ноды показаны этапы последней установки.
- Неудачную переустановку (после обновления магазина) воркер повторяет через 15 минут.

## Чем проверено

Настоящий Docker и HAProxy в CI (`scripts/ci/masque-check.sh`): переустановка с настройкой, которую HAProxy не
принимает, откатывается к прежней — туннель и сайт работают, битой настройки на ноде нет; первая установка с ней не
оставляет на ноде ни файлов, ни контейнеров, ни таймера сертификата. `tests/test_masque_panel.py`: разбор этапов, текст
ошибки, пауза между повторами. На живой ноде не проверено.
