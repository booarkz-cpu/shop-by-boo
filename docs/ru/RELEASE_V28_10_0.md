# Выпуск v28.10.0 — переработанная административная панель

Дистрибутив: `v28.10.0`. Runtime/API: `21.5.1`. Head магазина: `0068_network_intel` (без новых миграций). Support Pro: `0007` / 3.7. Дата и commit фиксируются тегом выпуска.

## Что изменено

[Руководство по админ-панели](ADMIN_PANEL_CURRENT.md) описывает все разделы, кнопки и поля.

- **Страница «Все разделы»** — стартовый экран панели: ключевые показатели и все 58 функций в 8 группах (аналитика; пользователи; тарифы и оплата; маркетинг; бот и кабинет; серверы; система; безопасность). У каждой функции — описание в одно предложение; поиск по названию, задаче или синониму, найденное слово подсвечивается.
- **Меню** сгруппировано в том же порядке. Поиск в меню и быстрый поиск (Ctrl+K) ищут и по описаниям; результаты быстрого поиска показывают описание раздела.
- **Заголовок раздела**: путь «Админ-панель › группа» (ссылка ведёт к списку разделов), название и описание. Заголовки внутри разделов, повторяющие название страницы, скрыты.
- **Подписи полей**: 70 полей, которые раньше подписывались только серым текстом внутри, получили видимые подписи с единицами измерения («Цена за 30 дней, ₽», «Срок, дней», «Скидка, %»); внутри полей — примеры значений. Подсказка «?» стоит рядом с подписью, флажки выровнены в одну строку с текстом.
- **Оформление как в личном кабинете**: текст 14 px, подписи 13 px, заголовки без капса; двухколоночные сетки, карточки показателей, строки «параметр — значение» и шапки разделов оформлены единообразно; тарифы показаны карточками с ценой и статусом.
- **Тексты**: английские заголовки («Smart Routing», «Device Management», «Automation Center», «Node Orchestrator», «Corgi Intelligence», «Favicon», «CONTROL CENTER» и др.) заменены русскими; подписи резервных копий, оркестратора и маршрутизации переведены; для всех новых строк добавлен английский перевод интерфейса.
- **Скриншоты** пересняты все: каталог `screenshots/admin_panel/` (61 снимок — «Все разделы», вход, 58 разделов в порядке нового меню, быстрый поиск) и `screenshots/storefront_user/` (20 разделов личного кабинета) с тестовыми данными, раздел «Скриншоты» в README перестроен по новым группам; снимки для документации `docs/screenshots/*-v28-10-0.png` (панель, поиск, разделы, телефон, светлая тема, вход, кабинет, Mini App). Их снимают `admin/scripts/screenshots-catalog.mjs` и `admin/scripts/screenshots.mjs`; `admin/scripts/audit-sections.mjs` снимает каждый раздел и перечисляет поля без подписи. Тестовый стенд `tests/passkey_browser_server.py` может работать на PostgreSQL и Redis (`BROWSER_DATABASE_URL`, `BROWSER_REDIS_URL`).

Раскладка групп и расположение кнопок взяты за образец у проекта [bedolaga-cabinet](https://github.com/BEDOLAGA-DEV/bedolaga-cabinet); код и тексты написаны заново.

## Обновление

Миграций и новых переменных нет. Используйте [проверяемый регламент обновления](DISTRIBUTION_UPGRADE_CURRENT.md); после обновления пересоберите образы `admin`, `cabinet`, `miniapp`. Прямые ссылки на разделы (`#plans`, `#runtimeSettings` и т. п.) продолжают работать; адрес без раздела открывает «Все разделы» вместо «Главной».

```bash
docker compose exec -T backend alembic current
docker compose ps
curl -fsS https://API_DOMAIN/health/ready
```

Ожидаемые head: магазин `0068_network_intel`, Support Pro `0007`.
