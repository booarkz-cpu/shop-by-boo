# Выпуск v28.86.0 — блок «Приложения» только после входа; проверки поведения вместо проверок текста

Дистрибутив: `v28.86.0`. Runtime/API: `21.5.1`. Head магазина: `0093_ssh_key_rotation` (миграций нет). Support Pro: `0008` / 3.8.

Задача владельца от 2026-11-05: убрать информацию о приложениях со страниц входа и регистрации, показывать её только вошедшему покупателю, включать и выключать в админке.

## Что сделано

- На страницах входа и регистрации личного кабинета блока «Приложения» больше нет.
- Вошедший покупатель видит блок на главной странице кабинета, если он включён.
- Админка: «Android и iOS → Блок «Приложения» в личном кабинете → Показывать покупателю после входа». Изменение действует после «Сохранить приложения», без перезапуска, и попадает в журнал действий (`content.apps.updated`). По умолчанию блок включён.
- API: `GET /api/public/apps` и `GET /api/admin/apps` отдают `cabinet_visible`; `PUT /api/admin/apps` принимает `cabinet_visible` (без поля — значение не меняется).
