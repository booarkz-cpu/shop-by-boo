# Выпуск v28.28.0 — семья и статус сервиса в приложениях, main.py по модулям

Дистрибутив: `v28.28.0`. Runtime/API: `21.5.1`. Head магазина: `0076_growth` (без новых миграций). Support Pro: `0008` / 3.8. Дата и commit фиксируются тегом выпуска.

## Что изменилось

**Приложения Android и iOS для клиентов**

- Вкладка **«Семья»**:
  - владелец видит занятые места, создаёт приглашение, делится ссылкой на бота и убирает участников;
  - участник видит владельца и срок подписки и может выйти;
  - любой клиент присоединяется по коду приглашения.
- Вкладка **«Статус сервиса»**: общий статус, серверы онлайн по странам, компоненты и текущие проблемы.
- Новые строки переведены на русский, английский и украинский. Приложение напоминает, что подписка за Telegram Stars управляется в Telegram.
- Если магазин старше v28.25.0, новые вкладки пустые, остальное работает как прежде.
- В магазинах приложений названия «Corgi Lusi» и «Corgi Lusi Admin».

Подробнее — [модуль 16](modules/16-mobile-apps.md#семья-и-статус-сервиса).

**main.py разделён на модули**

- Пять разделов вынесены из `backend/app/main.py` (5790 → 4343 строки) в отдельные модули:
  - `staging_e2e_api.py`;
  - `backups_api.py`;
  - `content_branding_api.py`;
  - `marketing_api.py`;
  - `enterprise_api.py`.
- Код перенесён без изменений поведения:
  - те же 291 маршрут в прежнем порядке сопоставления;
  - имена, принадлежащие main, читаются через `shop.<имя>` в момент вызова, поэтому подмены в `app.main` действуют как раньше.
- Тесты, проверяющие исходный текст, читают его через `tests/main_source.py`: вынесенные разделы подставляются на прежние места. `tests/test_main_split.py` проверяет маршруты и реэкспорт имён.

## Обновление

Миграций нет. Мобильные приложения собираются и подписываются владельцем, как раньше.

```bash
cd /opt/vpn-shop && bash scripts/backup.sh
sudo env APP_DIR=/opt/vpn-shop RELEASE_TAG=v28.28.0 bash /opt/vpn-shop/scripts/update-from-github.sh
```
