# Выпуск v28.54.0 — фильтр рекламы и детский режим, регионы клиентов, проверка доступности из России

Дистрибутив: `v28.54.0`. Runtime/API: `21.5.1`. Head магазина: `0088_filter_and_regions` (колонки `subscriptions.dns_filter` и `vpn_sessions.region`). Support Pro: `0008` / 3.8. Мобильные приложения: 3.4.0. Дата и commit фиксируются тегом выпуска.

## Что изменилось

**Фильтр рекламы и детский режим** — «Ноды → Фильтр рекламы и детский режим» и карточка в мобильных админках
- Клиент выбирает «Без рекламы» или «Детский режим» в кабинете, в боте (`/filter`) или в приложении. Владелец семьи выбирает режим для каждого участника.
- Фильтр работает на нодах: пользователь переходит в сквад с правилами блокировки. Магазин следит, чтобы продление не вернуло сквад тарифа.
- Нужна разовая настройка профиля и сквада в Remnawave. Готовые правила — в документации модуля.

**Регионы клиентов** — «Аналитика → Регионы клиентов» и карточка в мобильных админках
- С бесплатным ключом MaxMind магазин раз в неделю скачивает базу GeoLite2. «География клиентов» показывает регионы внутри стран.

**Проверка доступности из России** — «Ноды → RIPE Atlas — доступность из России» и карточка в мобильных админках
- Адреса API и ноды проверяются с зондов RIPE Atlas у российских провайдеров, своих серверов в России не нужно.
- Результаты идут в монитор блокировок: при блокировке срабатывают те же оповещения, резервные адреса и резервный сквад.

Подробно — [dns_filter_geoip_ripe.md](../modules/dns_filter_geoip_ripe.md).

## Что нужно от владельца

- **Фильтр:** профиль конфигурации с правилами блокировки и сквад в Remnawave, затем сквады в админке магазина.
- **Регионы:** ID аккаунта и лицензионный ключ MaxMind GeoLite2.
- **RIPE Atlas:** ключ API с кредитами на измерения.
