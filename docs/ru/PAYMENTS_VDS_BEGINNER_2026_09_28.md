# Платежи на отдельном VDS — v21.5.1

Актуальная пошаговая инструкция: [Платежи на отдельном VDS](WORKSPACE_PAYMENTS.md). Общий каталог: [DOCUMENTATION.md](../../DOCUMENTATION.md).

Реальные платежи закрыты платёжным gate, пока ваша установка не прошла проверку staging E2E v2 на отдельном стенде ([допуск платежей](STAGING_E2E_V2_IMPLEMENTATION.md)). Используйте текущие три агента: YooKassa, Platega, RollyPay; прежние агенты не принимают новые покупки.

Предыдущая редакция сохранена как [исторический документ](../archive/instructions_before_21_0_1/docs__ru__PAYMENTS_VDS_BEGINNER_2026_09_28.md); её команды и обещания не являются текущей инструкцией.
