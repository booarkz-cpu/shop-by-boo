# Выпуск v28.37.0 — сверка со снимками, модерация, умная корзина, гостевая покупка, конкурс рефералов, качество связи, P&L, приложения 3.3.0

Дистрибутив: `v28.37.0`. Runtime/API: `21.5.1`. Head магазина: `0080_reconciliation`. Support Pro: `0008` / 3.8. Мобильные приложения: 3.3.0. Дата и commit фиксируются тегом выпуска.

Установка с нуля до продакшена: [docs/INSTALLATION.md](../INSTALLATION.md). Архитектура: [docs/modules](../modules/README.md). Что сверено и перенесено: [сверка со снимками](SNAPSHOT_RECONCILIATION.md).

## Что изменилось

**Сверка со снимками для сравнения** — [итог](SNAPSHOT_RECONCILIATION.md)

- Bedolaga Telegram Bot, Bedolaga Cabinet, Remnawave Admin и StepBot прочитаны заново на снимках карты покрытия и на свежих коммитах; найденные расхождения перенесены своей реализацией, без копирования кода. Не перенесены (с причиной): около 20 дополнительных касс, Apple In-App Purchase, чёрный список из чужого репозитория.

**Модерация и доступ** — [модерация](../modules/moderation.md)

- Чёрный список (Telegram ID, email, домены), запрет одноразовых email, регистрация только по приглашениям (`start=inv_…`, `?invite=`), очистка клиентов, заблокировавших бота, массовая блокировка списком.
- Несколько обязательных каналов с областью «все / пробный период / покупка»; проверка в боте, кабинете, Mini App.
- Страж панели: если Remnawave не отвечает, магазин сам включает техработы и выключает их, когда панель вернулась.
- Журнал системных ошибок с отметкой «решено».

**Продажи** — [продажи](../modules/sales_flows.md)

- Умная корзина: не хватает денег — заказ запоминается, после пополнения покупка проходит сама.
- Гостевая покупка по email без Telegram: письмо со ссылкой задать пароль.
- Суточные тарифы с ежедневным списанием из кошелька, льготный доступ после окончания подписки, сброс трафика при оплате.
- Пачки подарочных кодов с выгрузкой CSV, предложения в одно касание и «Моя статистика» в кабинете, Mini App, боте (`/stats`) и приложениях.
- Выбор способа оплаты (СБП, карта, криптовалюта): заказ уходит в кассу, которая принимает выбранный способ.

**Рост** — [рост](../modules/growth_tools.md)

- Конкурс рефералов с таблицей лидеров и призами днями или на баланс (`/contest`).
- Постбэки рекламных сетей и офлайн-конверсии Яндекс Метрики: регистрация, пробный период, покупка.
- Закреплённое сообщение всем клиентам бота; прогноз оттока с промокодом удержания; качество связи по операторам и рекомендуемый сервер.

**Деньги** — [P&L и реселлеры](../modules/pnl.md)

- P&L: выручка, возвраты, комиссии касс, расходы на серверы и рекламу, прибыль по месяцам.
- Оптовые заказы реселлеров по API (`POST /api/reseller/orders`) с оплатой из баланса реселлера.

**Эксплуатация** — [горячий резерв](../modules/hot_standby.md), [автомасштабирование](../modules/node_autoscale.md)

- Живая проверка контракта Remnawave на самой новой панели в CI; по ней исправлены перезапуск нод (`forceRestart`), продление по `id` панели и массовые операции с хостами.
- На резервный сервер теперь реплицируются база Support Pro и медиафайлы; раз в неделю агент проводит учебное переключение на копии и проверяет данные.
- Автомасштабирование учитывает загрузку CPU из агентов нод; ключ новой ноды берётся из панели.
- Нагрузочные тесты k6 и OWASP ZAP baseline (`load-security.yml`) — отчёт, не блокируют выпуск.

**Интерфейсы**

- Веб-админка: 18 новых блоков в разделах «Готовность», «Конфигурация приложения», «Поддержка», «Аналитика», «CRM», «Тарифы», «Серверы», «Контент», «Маркетинг».
- Мобильные админки: универсальные карточки панели с действиями (`GET /api/admin/mobile/panels`).
- Баннеры бота и Mini App: новые разделы «Конкурс друзей», «Моя статистика», «Наш канал», «Покупка без регистрации».
- Приложения 3.3.0 (номер сборки 3300).

## Обновление

Автообновление поставит выпуск само ночью; вручную — «Выпуски → Автообновление → Проверить и обновить сейчас» или

```bash
bash /opt/vpn-shop/scripts/backup.sh
sudo env APP_DIR=/opt/vpn-shop RELEASE_TAG=v28.37.0 bash /opt/vpn-shop/scripts/update-from-github.sh
```

Миграция `0080_reconciliation` только создаёт новые таблицы и совместима с прежней версией — обновление без простоя работает. Новых ключей `.env` нет: все модули включаются и настраиваются в админке и по умолчанию выключены.
