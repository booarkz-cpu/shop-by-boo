# Релиз v28.125.0 — целостность журнала действий администраторов

Дистрибутив: `v28.125.0`. Runtime/API: `21.5.1`. Head магазина: `0094_store_subscriptions` (без новых миграций). Support Pro: `0008` / 3.8.

Дата: 2026-11-12. Задача владельца: все требования реестра — в статус PASS (этап 23). Раздел «Панель администратора», `REQ-ADMIN-0001` – `REQ-ADMIN-0019`.

## Что изменилось

- В разделе «Журнал действий» появился блок **«Целостность журнала»**.
  - Каждые десять минут новые записи журнала запечатываются: по ним считается подпись с секретом сервера, которого нет в базе.
  - Кнопка «Проверить журнал» пересчитывает подписи. Если запись изменили или удалили прямо в базе, проверка покажет диапазон номеров записей.
  - Блок показывает, сколько записей запечатано, сколько ещё нет и когда была последняя проверка.
- Схема базы не менялась.

Подробно, включая пределы защиты: [AUDIT_LOG_INTEGRITY.md](../AUDIT_LOG_INTEGRITY.md).

## Пределы защиты

- Записи моложе последней печати (до десяти минут) ещё не защищены.
- Тот, у кого есть секрет сервера, может поставить печати заново.
- Находится диапазон записей, а не одна запись.
