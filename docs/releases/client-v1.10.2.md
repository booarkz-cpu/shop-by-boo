## Ломающие изменения

У официальных обвязок v26.11.9 и v26.11.26 совпали публичные сигнатуры всех 18 Java-классов. Встроенный движок обновляет обработку сжатых данных и WebSocket.

## Миграции

Установленные профили используют прежний формат. Обновление устанавливается поверх предыдущей сборки с той же подписью.

## Откат

До публикации для отката восстановите прежнюю ревизию AndroidLibXrayLite и соответствующие ей правила сборки и проверки зависимостей. Пересоберите оба приложения. Для доставки исправления пользователям, уже установившим клиент 1.10.2, потребуется подписанная сборка с кодом выше 1102.

## Известные ограничения

Итоговые APK с исправлением Gorilla WebSocket, их нативные библиотеки и VPN/TUN проверяются в CI на коммите кандидата. Проверка на физическом Android-устройстве остаётся открытой.

## Чем проверено

Тег v26.11.26 указывает на `e23aca42e775ea9c31dc4e37a3472927caa3b9cf`. SHA-256 опубликованного AAR совпал с метаданными релиза. Все четыре нативные библиотеки проверены отдельно. Перед заменой Gorilla WebSocket сборка обвязки с Go 1.27.4 и NDK r27d дала AAR с SHA-256 `0755b75775b0cd4d0039cdef83de7d4847094a3113ebd93582b8d78af3474283`. [Релиз обвязки](https://github.com/2dust/AndroidLibXrayLite/releases/tag/v26.11.26) · [Описание исправления](https://github.com/advisories/GHSA-fpmh-frq8-7rj8)

В графе сборки из 117 Go-модулей при замене Gorilla WebSocket изменилась только версия этого модуля. На Go 1.27.4 пройдена передача 4096 байт по WS и WSS в трёх режимах соединения — напрямую, через локальный HTTP CONNECT и через CONNECT с аутентификацией. Два теста прокси из upstream (`TestProxyDial` и `TestProxyAuthorizationDial`) завершились с `unexpected EOF` как на v1.5.3, так и на закреплённой ревизии. [Отчёт Go о зависимости](https://pkg.go.dev/vuln/GO-2026-6278)
