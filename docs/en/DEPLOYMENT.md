Ukrainian) and splits main.py into modules. v28.29.0 lets the administrator write the FAQ, rules, privacy policy and public offer once for the Mini App, cabinet and bot (/faq, /rules, /privacy, moves the shop and Support Pro to PostgreSQL 18 (data is moved from PostgreSQL 16 during the update with row-count checks; the old volume is kept for rollback) and makes the Mini App data-driven (GET v28.19.0 added real-payment admission through staging E2E v2 (a separate APP_ENV=staging server runs a real order through the regular checkout and checks the signed webhook, provider reconciliation, delivery by Remnawave user ID, webhook replay and forgery, refund, revocation and a late success; the Ed25519-signed result is accepted by production with its own run code, the same release and for 24 hours) and anti-fraud decisions with notes. v28.18.0 rewrote the guides (a Russian launch guide from server to first sale and 30 per-module guides checked against the code) and adds a plan editor with Remnawave Internal Squad selection, a combined referrals and partners section, a fix that lets switching incident mode off lift maintenance, and optional client-to-IP observations from the Xray log for abuse checks. v28.17.0 added a receive-only MX for service addresses (DMARC reports into the mail domain section, support mail into Support Pro) with SPF, DKIM and DMARC checks, greylisting, limits, ClamAV and STARTTLS; it never relays and never sends bounces. v28.16.0 added deep traffic analysis on nodes: nDPI when installed, otherwise a built-in classifier of the first packets of each flow (BitTorrent handshake, DHT, uTP, trackers, and a heuristic for encrypted BitTorrent that never affects abuse scoring), attributed to clients via the Xray log in node memory. v28.15.0 added hours and notifies them once a day; encrypted BitTorrent is not detected. v28.14.0 added a node terminal: a full shell on a VPN node through its agent (no SSH, no open ports on the node), enabled on both the shop server and the node, admin-only with 2FA and a password-and-code confirmation per session, time and idle limits, and an encrypted transcript that leaves out secrets typed with echo off. v28.13.0 added a mail domain section (MX, SPF with the 10-lookup limit, DKIM against the panel key, DMARC policy and report addresses) and DMARC aggregate reports from a read-only mailbox or upload, To test locally: clone tag `v28.46.0` and run `bash scripts/test-up.sh`. Loopback ports: API 18080, admin 18081, cabinet 18082, Mini App 18083. The sandbox subscription does not provide a VPN tunnel.

New server installation from a root SSH/Termius terminal:

```bash
curl -fsSL https://raw.githubusercontent.com/booarkz-cpu/shop-by-boo/v28.46.0/install.sh -o /root/shop-install.sh && BRANCH=v28.46.0 bash /root/shop-install.sh
```

Use the update procedure for an existing shop; preserve secrets and verify a consistent backup first.
