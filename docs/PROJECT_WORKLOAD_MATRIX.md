# Работы по компонентам

Указаны проверяемый результат и зависимость, от которой зависит его приёмка. Состав действий CI определяется версиями workflow в проверяемом коммите. [Основной workflow](../.github/workflows/ci.yml) · [Реестр требований](REQUIREMENTS_MASTER_REGISTER.md)

| Область | Реализация | Следующая проверяемая работа | Связь с приёмкой |
| --- | --- | --- | --- |
| Магазин, кабинет, Mini App | [Backend](../services/backend), [кабинет](../apps/user-cabinet), [Mini App](../apps/telegram-mini-app) | Проверить повтор webhook, сумму, валюту и выдачу доступа для каждого незавершённого платёжного провайдера | Официальный контракт и безопасное тестовое окружение провайдера |
| Мобильный магазин | [Android](../apps/vpn-shop/android), [iOS](../apps/vpn-shop/ios) | Сопоставить движок и его происхождение с конечным APK и расширением Packet Tunnel | Отдельные результаты для ABI, устройства и симулятора |
| VPN-клиент | [Android](../apps/vpn-client/android) | Сравнить нативные библиотеки приложения с единственным принятым AAR и проверить TCP, UDP, DNS | Релевантные устройство или эмулятор и журнал трафика |
| Администрирование | [Lucy Admin](../apps/lucy-admin) | Сопоставить основные операции на трёх платформах, затем проверить события полного жизненного цикла инцидента | [Матрица возможностей](ADMIN_FEATURE_PARITY_MATRIX.md) |
| Support Pro и хранение данных | [Support Pro](../services/support-pro), [переход PostgreSQL](../scripts/upgrade-postgres19.sh) | Проверить профили, переход и возврат обеих баз по контрольным суммам | [Issue #392](https://github.com/booarkz-cpu/shop-by-boo/issues/392) |
| Узлы, установщик, Remnawave | [Установщик](../install.sh), [инфраструктура](../infrastructure) | Проверить расхождение фактического и желаемого состояния, повторный запуск и исчерпание попыток | Контракт API и изолированные учения по восстановлению |
| Очередь зависимостей | [Скрипт очереди](../scripts/dependabot-queue.cjs), [регрессионные тесты](../tests/dependabot-queue.test.cjs) | Сверить первоначальные PR с принятым деревом и прогнать изменённые компоненты | [Issue #419](https://github.com/booarkz-cpu/shop-by-boo/issues/419) |
| Производительность | [Испытание магазина](../tests/load/shop.js), [публичные API](../tests/load/live.js) | Повторить сравнимые профили, раздельно оценить задержку, ошибки и верность ответа | [Порог и наблюдение](SLO_BASELINE.md) |
| Сборка и выпуск | [Требования к SBOM](SBOM_AND_LICENSES.md), [контроль выпуска](RELEASE_CHECKLIST.md) | Проверить три графа Android, лицензии, выпуск и SHA-256 каждого вложения | Подтверждённые порог требований, CI и опубликованные артефакты |
