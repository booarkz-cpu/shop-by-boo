# Android и iOS

В проекте сохранены приложения пользователя и администратора для Android и iOS. Исходники находятся в `mobile/`; мобильная авторизация использует отдельный серверный контур. Несколько подписок поддерживаются выбором профиля. Новые наградные акции доступны через общий веб кабинет/Mini App; самостоятельный native-экран для них не добавлен.

В v21.5.1 новые подписанные APK/IPA не опубликованы. Сборка debug Android и iOS simulator в CI проверяет компиляцию, но не подпись, распространение или работоспособность реального VPN на устройстве. Не называйте архив исходников APK/IPA и не устанавливайте случайные бинарники под видом этого релиза.

[Подробное руководство по клиентам, подключению и сборке](docs/ru/MOBILE_GUIDE.md). [Историческая инструкция мобильного выпуска](docs/ru/MOBILE_RELEASE_2_14_1.md) относится к указанной в ней версии. Официальные внешние клиентские ссылки проверяйте на сайте соответствующего клиента перед установкой.

Для собственной сборки нужны Android SDK/JDK или macOS/Xcode, HTTPS адреса своего магазина и, для распространения, собственные signing keys/профили. Секреты подписи не коммитьте. [CI](.github/workflows/ci.yml), [mobile release workflow](.github/workflows/mobile-release.yml), [условия использования](LICENSE), [сторонние уведомления](THIRD_PARTY_NOTICES.md).

Справочники: [ключи доступа администратора](docs/ru/ADMIN_PASSKEYS.md), [метрики, dashboard и alerts](docs/ru/OPERATIONS_MONITORING.md). Мобильный workflow использует версию текущего манифеста; без owner signing secrets APK/IPA не объявляются подписанными production assets.
