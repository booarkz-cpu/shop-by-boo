# Указатель документации — v28.57.0

Дистрибутив `v28.57.0` использует runtime/API `21.5.1`, миграцию магазина `0088_filter_and_regions` и Support Pro `0008`. Актуальная пошаговая инструкция: [Указатель документации](DOCUMENTATION.md). Новый операторский раздел: [настройки без перезапуска](docs/ru/RUNTIME_SETTINGS_CURRENT.md). Отчёт выпуска: [v28.57.0](docs/ru/RELEASE_V28_11_0.md).

Стабильный канал текущего ядра не подтверждает полный перенос функций или production E2E. Реальные платежи открыты с момента установки; администратор может остановить их аварийной кнопкой. Используйте текущие три агента: YooKassa, Platega, RollyPay; прежние агенты не принимают новые покупки.

Предыдущая редакция сохранена как [исторический документ](docs/archive/instructions_before_21_0_1/RELEASE_DOCUMENTATION_INDEX_RU.md); её команды и обещания не являются текущей инструкцией.
