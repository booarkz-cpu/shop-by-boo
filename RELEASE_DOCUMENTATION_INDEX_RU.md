# Указатель документации — v28.11.0

Дистрибутив `v28.11.0` использует runtime/API `21.5.1`, миграцию магазина `0068_network_intel` и Support Pro `0007`. Актуальная пошаговая инструкция: [Указатель документации](DOCUMENTATION.md). Новый операторский раздел: [настройки без перезапуска](docs/ru/RUNTIME_SETTINGS_CURRENT.md). Отчёт выпуска: [v28.11.0](docs/ru/RELEASE_V28_11_0.md).

Стабильный канал текущего ядра не подтверждает полный перенос функций или production E2E. Платёжный gate остаётся закрытым. Используйте текущие три агента: YooKassa, Platega, RollyPay; прежние агенты не принимают новые покупки.

Предыдущая редакция сохранена как [исторический документ](docs/archive/instructions_before_21_0_1/RELEASE_DOCUMENTATION_INDEX_RU.md); её команды и обещания не являются текущей инструкцией.
