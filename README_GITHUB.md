# VPN Shop by Corgi Lucy

[Русский](README.md) · [English](README.en.md) · [Українська](README.uk.md)

В магазине клиент оформляет подписку через Telegram, веб-кабинет или мобильное приложение. Владелец настраивает тарифы, принимает платежи и управляет доступом Remnawave через Lucy Admin.

- [Скачать приложения](README.md#скачать-мобильные-приложения) для покупателей и владельцев магазина на Android и iOS.
- [Установить магазин на VPS](README.md#установить-магазин) и впервые войти в админку.
- [Обновить магазин](docs/wiki/ru/Updates.md) или [восстановить его из полной копии](docs/ru/BACKUP_CURRENT.md).
- [Скачать опубликованный выпуск](https://github.com/booarkz-cpu/shop-by-boo/releases) или [посмотреть историю изменений](CHANGELOG.md).
